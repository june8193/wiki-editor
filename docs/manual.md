# Wiki Editor 사용자 매뉴얼

> **플랫폼 안내**: 아래 단축키는 Windows 기준(`Ctrl`)으로 표기되어 있습니다. macOS에서는 `Ctrl` 대신 `Cmd` 키를 사용하세요.

## 단축키 모음

### 앱 · 탐색

| 단축키 | 동작 | 비고 |
| --- | --- | --- |
| `Ctrl+O` | 폴더 열기 | `File > 폴더 열기...`와 동일 |
| `Ctrl+Shift+F` | 워크스페이스 전체 검색 | 좌측 검색 사이드바를 열고 검색창에 포커스 |
| `Ctrl+T` | 심볼 검색 팔레트 | 현재 워크스페이스 또는 활성 Diff·스냅샷 Git Ref 시점 심볼 선언 검색 |
| ``Ctrl+` `` | 터미널 토글 | `Terminal > 터미널 토글`과 동일 (메인 창 전용) |
| ``Ctrl+Shift+` `` | 새 터미널 | `Terminal > 새 터미널`과 동일 (메인 창 전용) |
| `Esc` | 닫기 | 열린 모달, 팝오버, 찾기 바, 링크 자동완성 닫기 |

### 에디터 · 모드 전환

| 단축키 | 동작 | 비고 |
| --- | --- | --- |
| `Ctrl+S` | 문서 저장 | 수동 저장 (자동 저장이 꺼져 있을 때도 즉시 저장) |
| `Ctrl+1` | Raw 모드 전환 | 마크다운/JSON/텍스트 원본 편집 |
| `Ctrl+2` | 위지윅(WYSIWYG) 모드 전환 | 마크다운 문서 전용 |
| `Ctrl+3` | Preview 모드 전환 | 마크다운 문서 전용 |
| `Ctrl+4` | Split 모드 전환 | Raw + Preview 좌우 분할 (마크다운 문서 전용) |
| `Ctrl+Shift+M` | 에디터 모드 순환 | Raw → 위지윅 → Preview → Split 순서로 순환 |
| `Ctrl+F` | 문서 내 찾기 | 활성 편집기 창에서 찾기 바 열기 |
| `Enter` / `F3` | 다음 찾기 결과 | 문서 내 찾기 바가 열려 있을 때 |
| `Shift+Enter` / `Shift+F3` | 이전 찾기 결과 | 문서 내 찾기 바가 열려 있을 때 |

### 링크 · 표 편집

| 단축키 | 동작 | 비고 |
| --- | --- | --- |
| `Ctrl+K` | 링크 삽입 / 편집 | 마크다운 링크 입력 및 워크스페이스 문서 자동완성 |
| `Ctrl+클릭` | 링크 이동 (Raw 모드) / 정의 이동 (코드·Diff·스냅샷) | 마크다운 Preview/위지윅은 일반 클릭, 코드 심볼은 `Ctrl+클릭`으로 선언부 점프 |
| `Shift+F12` | 레퍼런스 찾기 (코드·Diff·스냅샷) | 우측 사이드바 하단 **레퍼런스** 섹션에 시점 일치 참조 목록 표시 (우클릭 메뉴 지원) |
| `Alt+←` / `Alt+→` | 탐색 히스토리 뒤로 / 앞으로 | 각 편집기 영역별 이전 탭·줄 위치 단계별 이동 (마우스 뒤로/앞으로 버튼 지원) |
| `Ctrl+Alt+T` | 표 삽입 (Raw 모드) | 커서 위치에 기본 마크다운 표 삽입 |
| `Ctrl+Alt+↑` / `↓` | 위 / 아래 행 추가 | Raw 모드 표 내부에서 동작 |
| `Ctrl+Alt+←` / `→` | 좌 / 우 열 추가 | Raw 모드 표 내부에서 동작 |
| `Ctrl+Alt+Backspace` | 현재 행 삭제 | Raw 모드 표 내부에서 동작 |
| `Ctrl+Alt+Delete` | 현재 열 삭제 | Raw 모드 표 내부에서 동작 |
| `Ctrl+Alt+F` | 표 정렬 / 포맷팅 | Raw 모드 표 열 너비 자동 맞춤 |

### 폴더 트리 · Git · Mermaid

| 영역 | 단축키 | 동작 |

| 폴더 트리 | `Delete` | 선택한 파일/폴더 삭제 |

## 워크스페이스와 창 관리

### 폴더 열기와 최근/즐겨찾기 워크스페이스
- 상단 통합 타이틀/메뉴 바의 `File > 폴더 열기...` (`Ctrl+O`) 또는 좌측 **워크스페이스** 사이드바에서 로컬 폴더를 열 수 있습니다.
- 상단 타이틀 바 중앙에는 현재 앱 이름과 버전(`Wiki Editor vX.Y.Z`, 보조 창은 `<문서명> - Wiki Editor vX.Y.Z`)이 표시되며, 우측 창 제어 버튼은 라이트/다크 테마에 맞춰 자동 동기화됩니다.
- 최근에 연 워크스페이스 목록이 자동으로 저장되며, 자주 쓰는 폴더는 별표(즐겨찾기)로 고정할 수 있습니다.
- 워크스페이스 항목의 **새 창에서 열기**를 사용하면 현재 작업 창을 유지한 채 다른 폴더를 별도 창으로 열 수 있습니다.

### 탐색기와 파일 관리
- 좌측 액티비티 바의 **탐색기**에서 새 파일/폴더 생성, 이름 변경(`F2`), 삭제(`Delete`), 드래그 앤 드롭 이동을 할 수 있습니다.
- `Ctrl+클릭` 또는 `Shift+클릭`으로 여러 파일·폴더를 선택해 한꺼번에 이동하거나 삭제할 수 있습니다.

### 탭, 분할 창(Split), 탭 창 분리
- 상단 탭 바에서 탭을 드래그해 순서를 바꾸거나, 편집 영역의 분할 아이콘/드롭 존으로 좌우·상하 화면 분할을 만들 수 있습니다.
- 탭을 메인 창 바깥으로 분리해 **보조 창(독립 창)**으로 띄울 수 있으며, 보조 창의 변경 사항도 메인 창과 실시간으로 동기화됩니다.
- 열려 있던 탭, 분할 레이아웃, 사이드바 폭과 펼침 상태는 워크스페이스별로 자동 저장되어 다음 실행 시 복원됩니다.

## 에디터 모드와 문서 편집

### 4가지 편집 모드
마크다운 문서(`.md`, `.markdown` 및 확장자 없는 문서)는 상단 모드 버튼이나 단축키(`Ctrl+1`~`4`, `Ctrl+Shift+M`)로 모드를 전환할 수 있습니다.

1. **Raw (`Ctrl+1`)**: 마크다운 원문을 코드 에디터로 직접 편집합니다.
2. **위지윅 (`Ctrl+2`)**: 서식이 적용된 리치 텍스트 화면에서 바로 편집합니다.
3. **Preview (`Ctrl+3`)**: 렌더링된 읽기 전용 문서를 확인합니다.
4. **Split (`Ctrl+4`)**: 왼쪽 Raw 에디터와 오른쪽 Preview를 나란히 보며 편집하고 스크롤이 동기화됩니다.

> `.json`, `.txt`, `.ts`/`.tsx`/`.js`/`.py`/`.go`/`.rs`/`.cpp`/`.java` 등 비마크다운 문서는 Raw 모드로 열리며 파일 확장자별 신택스 하이라이팅이 적용됩니다. 이미지 파일은 전용 이미지 뷰어로 표시됩니다.

### 저장과 자동 저장
- **자동 저장(Auto-save)**이 켜져 있으면 편집 후 잠시 뒤 자동으로 디스크에 저장됩니다.
- 자동 저장 상태와 무관하게 `Ctrl+S`로 언제든 즉시 저장할 수 있습니다.
- 저장되지 않은 변경 사항이 있는 탭에는 표시가 남으며, 탭이나 창을 닫을 때 저장 여부를 확인합니다.

### 문서 인코딩 (`UTF-8` / `EUC-KR`)
- **자동 감지 및 인코딩 유지**: 문서를 열 때 UTF-8 유효성을 먼저 확인하고, 유효하지 않은 바이트가 포함된 레거시 한글 문서는 `EUC-KR`(Windows 확장 완성형 CP949 포함)로 자동 인식해 깨짐 없이 표시합니다. 저장 시에도 열려 있던 인코딩이 그대로 유지됩니다.
- **에디터 헤더 인코딩 메뉴**: 에디터 헤더 우측의 인코딩 버튼(`UTF-8` 또는 `EUC-KR`)을 클릭해 두 가지 동작을 선택할 수 있습니다.
  - **인코딩으로 다시 열기**: 디스크의 원본 파일을 선택한 인코딩으로 다시 디코딩해 엽니다. 저장하지 않은 변경 사항이 있으면 **확인 다이얼로그**로 손실 여부를 확인합니다.
  - **인코딩 변경**: 현재 편집 중인 본문을 유지한 채 저장 인코딩만 전환합니다. 전환 시 미저장(`●`) 상태가 되며 `Ctrl+S` 또는 자동 저장 시 새 인코딩으로 저장됩니다(저장 전 원래 인코딩으로 되돌리면 본문 변경이 없을 때 미저장 상태가 해제됩니다).
- **표현할 수 없는 문자 저장 보호 (`EUC-KR`)**:
  - `EUC-KR`로 저장할 때 이모지 등 CP949로 표현할 수 없는 문자가 포함된 경우, 수동 저장(`Ctrl+S`)에서는 **확인 다이얼로그**가 열려 손실될 문자 개수·예시를 확인한 뒤 `'?'로 대체하여 저장` 또는 취소를 선택할 수 있습니다.
  - **자동 저장**이 켜져 있을 때 표현할 수 없는 문자가 감지되면 무음 손실을 막기 위해 저장을 보류하고 상단 **오류 배너**로 안내합니다.
- **인코딩 고정 및 검색·Git 연동**: `config.json`과 `.wiki-editor/frontmatter.json`은 `UTF-8`로 고정(버튼 비활성화)되며 이미지 미리보기 탭에서는 인코딩 버튼이 숨겨집니다. **검색 패널**의 본문·속성 색인과 **Git Diff 뷰어**도 EUC-KR 문서 및 `UTF-8 ↔ EUC-KR` 인코딩 전환 커밋을 깨짐 없이 표시합니다.

### Raw 모드 표 편집 단축키
Raw 모드에서 마크다운 표 안에 커서를 두면 `Ctrl+Alt+방향키`로 행/열을 빠르게 추가하고, `Ctrl+Alt+Backspace`/`Delete`로 삭제하며, `Ctrl+Alt+F`로 파이프(`|`) 열 정렬을 맞출 수 있습니다.

## 링크와 이미지 삽입

### 마크다운 링크와 자동완성
- 에디터에서 `Ctrl+K`를 누르거나 `[` 입력 후 자동완성을 통해 워크스페이스 내 다른 문서로의 상대 경로 링크를 손쉽게 삽입할 수 있습니다.
- `[[문서]]`나 `[텍스트](경로.md#헤딩)` 형태의 문서·헤딩 앵커 링크를 클릭해 바로 이동할 수 있습니다.
  - **Preview / 위지윅**: 일반 클릭으로 이동
  - **Raw**: `Ctrl+클릭`으로 이동

### 이미지 붙여넣기와 드래그 앤 드롭
- 클립보드에 복사한 이미지나 로컬 이미지 파일을 에디터에 붙여넣기(`Ctrl+V`) 또는 드래그 앤 드롭하면 워크스페이스 자산 폴더에 저장되고 마크다운 이미지 문법이 자동 삽입됩니다.
- 삽입된 이미지는 Preview·위지윅·Split 모드에서 바로 렌더링되며, 탐색기에서 이미지 파일을 직접 클릭해 미리볼 수도 있습니다.

## Mermaid 다이어그램

````markdown
```mermaid
flowchart LR
  A[작성] --> B[미리보기] --> C[내보내기]
```
````

- 코드 블록 언어를 `mermaid`로 지정하면 Preview와 Split 모드에서 다이어그램이 실시간으로 렌더링됩니다.
- **확대/축소 및 이동**: 다이어그램 위에서 `Ctrl+휠`로 확대/축소하고 드래그로 이동(팬)할 수 있습니다.
- **높이 조절**: 다이어그램 하단 리사이즈 핸들을 드래그해 표시 높이를 조절할 수 있으며, 탭별로 높이가 기억됩니다.
- **내보내기**: 다이어그램 상단 컨트롤에서 SVG/PNG 파일로 저장하거나 클립보드로 복사할 수 있습니다.

## 문서 속성(Frontmatter)과 스키마

### 문서 속성 편집
- 우측 사이드바 상단의 **문서 속성(Properties)** 섹션에서 YAML Frontmatter 필드(제목, 태그, 날짜, 상태 등)를 폼 UI로 바로 편집할 수 있습니다.
- Frontmatter가 없는 문서에도 필드를 추가하면 상단 YAML 블록이 자동으로 생성됩니다.

### 스키마 정의 (`wiki.schema.json`)
- 문서 속성 영역의 **스키마 관리** 버튼을 열면 워크스페이스 공통 속성 스키마 모달에서 필드 타입, 기본값, 선택 옵션을 정의하거나 원본 `wiki.schema.json` 파일을 직접 열 수 있습니다.

### Frontmatter 필터링
- 좌측 **검색** 사이드바 상단의 필터 바에서 Frontmatter 속성 조건(예: 특정 태그나 상태 값)을 조합해 문서를 빠르게 걸러낼 수 있습니다.

## 검색과 목차(아웃라인)

### 문서 내 찾기 (`Ctrl+F`)
- 활성 편집기 창(마크다운·코드 문서, **Diff 탭**, **`🔒 <ref>` 스냅샷 탭** 포함)에서 `Ctrl+F`를 누르면 상단 우측에 찾기 바가 열립니다(단일 줄 선택 텍스트가 있으면 검색어로 자동 채워집니다).
- **대소문자 구분**(`Aa`), **단어 단위**(`ab`), **정규식**(`.*`) 옵션을 지원하며 `Enter`/`F3`으로 다음 결과, `Shift+Enter`/`Shift+F3`으로 이전 결과(가상 스크롤이 활성화된 대용량 Diff 포함)로 이동하고 `Esc`로 닫으며 강조를 해제합니다.

### 심볼 검색 팔레트 (`Ctrl+T`)
- `Ctrl+T`(`Cmd+T`)를 누르면 플로팅 **심볼 검색 팔레트**가 열립니다.
- 일반 문서 탭에서는 현재 **워킹트리**를, **Diff 탭**·**스냅샷 탭**에서는 해당 **Git Ref** 시점을 자동 반영해 함수·클래스·타입·변수 선언부를 온디맨드 검색하며, 현재 Diff/Compare 변경 파일의 심볼을 상단에 우선 표시합니다.
- 한글 IME 조합에 안전한 디바운스와 `Enter` 즉시 검색, `↑`/`↓`/`Esc` 키보드 내비게이션을 지원하며, 항목 선택 시 시점 일치 위치로 이동하고 **탐색 히스토리**(`←`/`→`)에 기록됩니다.

### 워크스페이스 전체 검색 (`Ctrl+Shift+F`)
- 좌측 **검색** 사이드바에서 워크스페이스 내 모든 마크다운 문서를 대상으로 텍스트 검색을 수행합니다.
- 검색 결과를 클릭하면 해당 문서와 줄 위치로 바로 이동해 강조 표시됩니다.

### 문서 목차(아웃라인)
- **마크다운 문서**: 우측 사이드바의 **문서 목차** 패널에 현재 문서의 헤딩(`#`~`######`) 구조가 표시되며, 현재 스크롤 위치에 해당하는 헤딩이 자동으로 강조됩니다. 목차 상단 토글로 **헤딩 번호 표시**를 켜거나 끌 수 있습니다.
- **코드 문서, Diff 탭 및 스냅샷 탭**: 비마크다운 코드 문서, **Diff 탭**, 또는 과거 시점 **`🔒 <ref>` 스냅샷 탭**이 활성화되면 **문서 목차**가 현재 파일의 함수·클래스·메서드·타입·인터페이스·변수 **심볼 목록**으로 전환됩니다. 상단 **심볼 필터** 입력창으로 이름을 즉시 검색할 수 있으며, **Diff 탭**에서는 추가된 심볼(`+`)과 수정된 심볼(`M`) 배지가 구분 표시됩니다. 코드·Diff·스냅샷에서 `Ctrl+클릭`으로 심볼 정의(선언부)로 이동하면 Diff의 삭제(`-`) 줄은 이전 Ref, 추가·문맥(`+`) 줄은 대상 Ref 기준으로 해석되어 변경 Hunk 내부는 Diff 탭으로, 그 외의 과거/비교 시점은 읽기 전용 `🔒 <ref>` **스냅샷 탭**(`[로컬 파일 열기]` 버튼 제공)으로 열리며, 각 편집기 영역 좌측 `←`/`→`(`Alt+←`/`Alt+→` 및 마우스 뒤로/앞으로 버튼)으로 이전 위치로 복귀할 수 있습니다.
- **레퍼런스 찾기 (`Shift+F12` / 우클릭)**: 코드·Diff·스냅샷 탭이 활성화된 동안 우측 사이드바 하단이 **레퍼런스** 섹션으로 전환됩니다(마크다운 문서 전환 시 기존 **문서 속성** 섹션 복원). 식별자를 우클릭해 **레퍼런스 찾기**를 선택하거나 `Shift+F12`를 누르면 우측 사이드바가 자동으로 펼쳐지며 시점 일치 참조 목록(현재 Diff/Compare 변경 파일 우선)을 클릭해 닫힘 없이 순회할 수 있습니다. `Ctrl+클릭` 시 명확한 선언부가 없으나 다른 참조가 존재하면 **레퍼런스** 섹션으로 자동 연결되며, 다른 참조도 없는 외부 심볼은 커서 근처 안내 툴팁(`Esc`로 닫기)만 표시합니다.

## Git 버전 관리

좌측 액티비티 바의 **Git** 아이콘을 열면 현재 워크스페이스의 Git 상태를 관리할 수 있습니다.

- **변경 사항 관리**: 변경된 파일 목록을 확인하고 개별 또는 전체 스테이징(`+`)·언스테이징(`-`)을 수행합니다.
- **Diff 뷰어 및 다중 Diff 탭**: 변경·커밋·Stash·Compare 파일 목록에서 파일을 클릭하면 임시 **Preview Diff 탭**(탭 제목 이탤릭체 표시, 영역당 최대 1개 재사용)으로 열립니다. `Shift+클릭`, 파일 행 더블클릭, Git 변경 목록·Compare 파일 트리의 우클릭 **새 탭에서 Diff 열기**, 또는 탭 바의 Preview 탭 더블클릭으로 탭을 **고정(Pinned)** 하면 여러 Diff 탭을 동시에 열어두고 비교할 수 있습니다. Git 변경 목록(리스트·트리)과 Compare 파일 트리에서는 파일 우클릭(`새 탭에서 Diff 열기`, `상대 경로 복사`, `절대 경로 복사`) 및 폴더 우클릭(`상대 경로 복사`, `절대 경로 복사`) 컨텍스트 메뉴도 지원합니다. **좌우 비교** 또는 **인라인** 모드로 전환할 수 있으며, 수정된 줄 내 변경 단어 강조(Intra-line diff)와 파일 확장자별 신택스 하이라이팅을 지원합니다.
- **변경 취소(Discard)**: 작업 트리의 수정 사항이나 추적되지 않은 파일을 되돌릴 수 있습니다. (실행 전 확인 대화상자 표시)
- **커밋 · Push · Pull**: 커밋 메시지를 입력하고 `Ctrl+Enter` 또는 커밋 버튼으로 커밋하며, 상단 액션으로 원격 저장소와 Pull/Push를 진행합니다.
- **Stash 관리**: 현재 변경 사항을 임시 저장(Stash)하고 목록에서 적용(Apply/Pop)하거나 삭제할 수 있습니다.
- **커밋 그래프**: 하단 그래프 섹션에서 브랜치 흐름과 커밋 상세 내역·변경 파일 목록을 확인할 수 있습니다.
- **브랜치·워크트리 비교 (Compare 뷰)**: 좌측 액티비티 바의 **Compare** 아이콘을 열면 `Base`와 `Compare` Ref(Worktrees, Local Branches, Remote Branches)를 검색·선택하거나 `⇄` 버튼으로 맞바꾸고, `3-dot (PR 방식)` ↔ `2-dot (직접 비교)` 모드를 전환하며 **Files**/**Commits** 서브 탭으로 비교 결과를 탐색할 수 있습니다. **Files** 탭에서 변경 파일 통계(`+N -M`)·경로 압축 트리·파일 필터를 탐색하고 파일을 클릭(Preview)하거나 `Shift+클릭`·더블클릭·우클릭 **새 탭에서 Diff 열기**(고정)로 읽기 전용 Diff 탭을 열 수 있으며, 파일·압축 폴더 우클릭 메뉴로 상대·절대 경로를 복사하고 헤더의 `↑`/`↓` 버튼으로 필터된 변경 파일을 순서대로 순회할 수 있습니다. Base/Compare Ref나 비교 모드를 변경하면 고정 여부를 포함해 열려 있는 모든 Compare Diff 탭이 새 기준으로 일괄 갱신(범위 밖 파일은 닫기)됩니다. **Commits** 탭에서는 비교 범위에 포함된 커밋 목록을 확인하고, 커밋을 클릭해 인라인 상세(해시 복사, 본문, 변경 파일 목록)를 펼친 뒤 파일 클릭·`Shift+클릭`·더블클릭으로 해당 커밋의 Diff 탭을 열 수 있습니다. 다른 저장소 코드베이스를 비교할 때는 **워크스페이스** 사이드바의 **새 창에서 열기**로 별도 창에서 해당 폴더를 열어 비교하세요.

## 통합 터미널 (`Terminal` 메뉴)

메인 창의 중앙 편집 공간 하단에 내장 **터미널 패널**을 열어 빌드·테스트·CLI 작업을 수행할 수 있습니다. (보조 창에서는 제공되지 않습니다.)

- **열기/접기**: 상단 메뉴 `Terminal > 터미널 토글` 또는 ``Ctrl+` `` 단축키로 패널을 토글합니다. 패널을 접어도 실행 중이던 프로세스와 출력은 백그라운드에서 유지됩니다.
- **다중 탭 및 셸 프로필**: 상단 메뉴 `Terminal > 새 터미널`, ``Ctrl+Shift+` `` 단축키 또는 패널 헤더의 `+` 버튼으로 새 **터미널 탭**을 추가하고, `+ ▾` 드롭다운에서 감지된 셸 프로필(`pwsh.exe`, `powershell.exe`, `cmd.exe`, Git Bash 등)을 선택해 열 수 있습니다. 탭 클릭으로 전환하거나 `×` 버튼으로 종료할 수 있습니다.
- **높이 조절**: 터미널 패널 상단 경계선(리사이저)을 드래그하거나 포커스 후 `↑`/`↓` 방향키로 높이를 조절하고, 더블클릭으로 기본 높이를 복원합니다.
- **스마트 복사·붙여넣기 및 링크 열기**: 선택 영역이 있는 상태에서 `Ctrl+C`를 누르면 선택 텍스트를 클립보드에 복사하고, 선택 영역이 없을 때만 실행 중인 명령에 중단 신호(`SIGINT`)를 보냅니다. `Ctrl+V` 또는 터미널 본문 우클릭으로 클립보드 내용을 붙여넣을 수 있으며, 터미널 출력의 `http`/`https` URL이나 워크스페이스 내 파일 경로(`path`, `path:line`, `path:line:col`)를 `Ctrl+클릭`하면 기본 브라우저 또는 활성 편집기 영역 탭으로 바로 엽니다.
- **테마 및 워크스페이스 전환**: 라이트/다크 테마 전환 시 터미널 색상이 자동 동기화되며, 다른 워크스페이스로 전환하면 기존 터미널 탭과 프로세스가 자동으로 정리됩니다.
