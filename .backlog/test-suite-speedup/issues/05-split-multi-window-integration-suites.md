# 05 — 다중 창 `<App />` 통합 스위트 도메인 분할 및 전체 스위트 성능 검증

**Spec:** [spec.md](../spec.md)

**What to build:** 단일 파일에서 약 73초간 직렬 실행되던 다중 창(**메인 창**·**보조 창**) `<App />` 통합 스위트(44개 테스트)의 창 간 드래그/버퍼 보조 함수를 공용 헬퍼로 정리하고, 공유 **문서 버퍼** 동기화 · **보조 창** 탭 분리/병합/창 닫기 보호 및 Git 롤백 연동 · 다중 **메인 창** 워크스페이스 세션 격리의 3개 도메인 스위트로 분할한 뒤 전체 테스트 스위트 실행 시간 단축을 최종 검증합니다.

**Blocked by:** `01-vitest-runtime-and-node-unit-routing`, `03-split-app-shell-workspace-panes-git-suites`

**Status:** resolved

- [x] 다중 창 테스트 전용 드래그 종료 디스패처, 창 간 `DataTransfer` 스텁, 버퍼 비동기 지연 플러시 헬퍼 및 창 내 문서 열기·탭 분리 보조 함수가 공용 다중 창 테스트 헬퍼로 정리되어 중복 없이 재사용됩니다.
- [x] 기존 다중 창 `<App />` 통합 스위트가 (1) 공유 **문서 버퍼** 실시간 동기화·자동 저장 중복 제거·이름 변경/삭제/외부 변경 정합성·마지막 참조 닫기 경합, (2) **보조 창** 셸·탭 분리 및 창 간 병합/분할 드롭·**메인 창**/**보조 창** 닫기 보호 및 `workspace-state.json` 배제·다중 창 Git 변경 사항 롤백(`discard`/`discardAll`), (3) 다중 **메인 창** 워크스페이스 열기·기존 창 포커스 전환·세션 격리 및 전역 설정 동기화의 3개 스위트로 분할되고 원본 거대 파일이 삭제됩니다.
- [x] 기존 44개 다중 창 통합 테스트의 모든 시나리오·단언 및 활성 하네스 `dispose` 정리가 누락 없이 보존되며 테스트 간 창/문서 제목·테마 오염이 발생하지 않습니다.
- [x] 전체 테스트 스위트(`npm test`) 실행 시 기준선(`741`개 이상)의 모든 테스트가 실패 없이 통과하고 전체 Wall-clock 소요 시간이 기존 약 195.7초 대비 대폭 단축되며, `npm run typecheck` 및 `npm run build`가 정상 성공합니다.
