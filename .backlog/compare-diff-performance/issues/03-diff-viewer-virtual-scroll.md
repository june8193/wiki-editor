# 03 — 공통 Diff 뷰어 대용량 패치 가상 스크롤 및 파일 전환 스크롤 초기화

**Spec:** [spec.md](../spec.md)

**What to build:** **Diff 뷰어**에서 수백~수천 줄 규모의 대용량 패치를 열 때 현재 스크롤 영역 주변 행만 DOM과 구문 강조 대상으로 마운트하는 뷰포트 가상 스크롤(Windowing)을 적용하고, 다른 파일로 **Diff 탭** 대상이 전환될 때 스크롤 위치를 최상단으로 초기화합니다.

**Blocked by:** 02-diff-viewer-fast-syntax-and-memo

**Status:** ready-for-agent

- [ ] 행 수 임계치 이하의 소규모 Diff는 스페이서 행 없이 모든 행을 직접 렌더링해 기존 동작과 오버헤드 제로를 유지한다.
- [ ] 임계치를 초과하는 대용량 Diff(**좌우 비교** 및 **인라인** 모두 포함)에서는 현재 스크롤 위치와 오버스캔 범위 안의 행만 실제 `<tr>` 및 구문 강조 계산 대상으로 렌더링하고, 상·하단 스페이서 행으로 전체 스크롤 높이를 보존한다(컨테이너 높이가 `0`인 초기/헤드리스 환경에서는 기본 뷰포트 높이 폴백으로 첫 구간을 안전하게 표시).
- [ ] 긴 줄 자동 줄바꿈(`pre-wrap`)으로 실제 행 높이가 기본 추정 높이와 달라질 때 측정된 행 높이를 반영해 스크롤 이동 시 레이아웃 점프 없이 행 윈도우가 매끄럽게 갱신된다.
- [ ] **Diff 탭**의 대상 파일 식별 키가 다른 파일로 바뀌면 스크롤 컨테이너의 `scrollTop`을 `0`으로 초기화하되, 동일 파일 내 **좌우 비교** ↔ **인라인** 보기 전환 시에는 강제 초기화하지 않는다.
- [ ] `GitDiffViewer` 컴포넌트 테스트 심(JSDOM `ResizeObserver` 및 스크롤 컨테이너 레이아웃 스텁 활용)에서 대용량 패치 마운트 시 렌더링된 DOM 행 수 제한, 스크롤 이동에 따른 가시 행 갱신, 줄바꿈 행 높이 보정, 파일 전환 시 `scrollTop` 초기화를 검증한다.
