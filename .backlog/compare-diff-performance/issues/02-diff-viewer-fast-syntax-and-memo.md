# 02 — 공통 Diff 뷰어 단일 패스 구문 강조·줄 메모이제이션 및 리렌더 격리

**Spec:** [spec.md](../spec.md)

**What to build:** 모든 Git 화면(**Compare 패널**·**Changes 섹션**·**Stashes 섹션**·**Graph 섹션**·**보조 창**)이 공유하는 **Diff 뷰어**에서 비동기 파서 로드로 인한 이중 전체 렌더링과 셀 단위 중복 Lezer 파싱을 제거하고, 상위 셸 상태 변경으로부터 **Diff 뷰어**를 메모이제이션으로 격리합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 번들 기본 언어 및 이미 캐시된 `@codemirror/language-data` 언어 파서를 첫 렌더에서 동기적으로 즉시 해석해 비동기 상태 갱신에 의한 2차 전체 리렌더링 없이 단일 패스로 신택스 하이라이팅을 표시한다(미캐시 동적 파서 비동기 로드 중에는 중복 정적 폴백 파싱을 생략).
- [ ] 파싱된 패치당 단어 단위(Intra-line) 하이라이트를 1차원 LCS 버퍼로 1회만 계산하여 **좌우 비교(Side-by-Side)**와 **인라인(Inline)** 모드 전환 시 재계산 없이 재사용한다.
- [ ] 줄 텍스트와 활성 파서를 기준으로 구문 강조 스팬을 상한 있는 캐시에 메모이제이션하여, **좌우 비교**의 좌·우 동일 `context` 줄이 1회만 파싱되고 리렌더 시 재파싱되지 않도록 한다.
- [ ] **Diff 뷰어**에 `React.memo`를 적용하고 상위 **편집기 영역**·**메인 창**의 콜백 및 이전/다음 파일 네비게이션 props 참조를 안정화해, **Compare 패널** 파일 필터 타이핑·폴더 접기/펼치기·서브 탭 전환·**사이드바 리사이저** 드래그 시 열린 **Diff 뷰어**가 재렌더링되지 않도록 한다.
- [ ] `GitDiffViewer` 컴포넌트 테스트 심 및 `App` 하네스 테스트에서 단일 패스 파서 적용, 동일 컨텍스트 줄 중복 파싱 방지, 모드 전환 시 단어/구문 강조 정합성, 상위 상태 변경 시 리렌더 격리를 검증한다.
