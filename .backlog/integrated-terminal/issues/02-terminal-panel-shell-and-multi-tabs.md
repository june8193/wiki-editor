# 02 — 터미널 패널 UI, 다중 탭 및 메뉴·단축키 통합

**Spec:** [spec.md](../spec.md)

**Blocked by:** 01-terminal-pty-backend-and-packaging

**Status:** ready-for-agent

**What to build:** **메인 창**의 중앙 **편집 공간** 하단에 `@xterm/xterm` 기반 **터미널 패널**을 배치하고, **터미널 리사이저**(드래그·키보드·더블클릭), **다중 터미널 탭**(`+` 추가·전환·닫기·실행/종료 상태), **애플리케이션 메뉴 바**(`터미널 토글`, `새 터미널`) 및 단축키(`Ctrl+`` / `Ctrl+Shift+``), 테마 동기화, 접힘 중 백그라운드 프로세스 유지 및 워크스페이스 전환 시 세션 초기화를 구현합니다.

- [ ] **메인 창**의 **왼쪽 사이드바**와 **우측 사이드바** 사이 중앙 **편집 공간** 하단에 **터미널 패널**을 렌더링하며, **보조 창**에는 노출하지 않는다.
- [ ] 상단 **터미널 리사이저**의 포인터 드래그, `ArrowUp`/`ArrowDown` 키보드 조절, 더블클릭 기본 높이 복원과 최소·최대 높이 제한이 동작하고, 크기 변경 시 활성 `xterm.js` 터미널이 자동 맞춤(`fit`) 및 PTY `resize` 동기화된다.
- [ ] 헤더 `+` 버튼으로 기본 셸 **터미널 탭**을 추가하고 탭 클릭 전환·상태 표시(실행 중/종료 코드)·`×` 닫기(PTY 종료)가 동작하며, 패널을 접었다가 다시 열어도 실행 중인 프로세스와 출력이 유지된다.
- [ ] **애플리케이션 메뉴 바**(`터미널 토글`, `새 터미널`)와 `Ctrl+``(`Cmd+``) / `Ctrl+Shift+``(`Cmd+Shift+``) 단축키가 동작하고, 라이트/다크 테마 전환 시 `xterm.js` 팔레트가 동기화되며, 워크스페이스 전환 시 기존 탭·세션이 깔끔하게 초기화된다.
- [ ] `App` + 인메모리 `WikiApi` 통합 테스트 및 `TerminalPanel` 컴포넌트 테스트(리사이저·다중 탭·테마 동기화)가 모두 통과한다.
