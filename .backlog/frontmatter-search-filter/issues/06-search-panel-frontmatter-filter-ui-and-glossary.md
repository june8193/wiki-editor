# 06 — 검색 패널 프론트매터 필터 바 · 요약 배지 · 정렬 · 배지 클릭 연동 및 도메인 문서 동기화

**Spec:** [spec.md](../spec.md)

**What to build:** **검색 뷰**(**검색 패널**, `Ctrl+Shift+F`)에 세션 비영속 **프론트매터 필터 바**, 결과 요약 배지, 스키마 필드 정렬, 배지 클릭 즉시 필터 추가 및 `allowCustom` 커스텀 값 제안(검색 피커 및 **문서 속성 섹션** 연동)을 구현하고, `CONTEXT.md` 도메인 용어집을 최신 공식 어휘로 동기화합니다.

**Blocked by:** `04-schema-management-modal-and-raw-json-sync`, `05-frontmatter-search-filter-engine-and-ipc`

**Status:** ready-for-agent

- [ ] **검색 패널**의 기존 텍스트 검색창(`Aa`/`ab`/`.*` 옵션 포함) 아래에 **프론트매터 필터 바**가 배치되어, `'+ 필터 추가'` 키보드 검색 팝오버로 스키마 필드 → 연산자 → 값을 선택해 활성 필터 칩을 추가·수정·개별 제거·전체 초기화할 수 있습니다.
- [ ] `allowCustom` `multi-select` 필드(예: `labels`)의 필터 피커와 **문서 속성 섹션** 제안 목록 모두 스키마 정의 옵션과 워크스페이스 문서(미저장 **문서 버퍼** 포함)에서 실사용된 커스텀 값을 함께 제안합니다.
- [ ] 텍스트 검색어 없이 프론트매터 필터만으로 문서를 조회할 수 있고, 텍스트/정규식 검색어와 결합해 즉시 필터링·재검색(새로고침 버튼 및 `Enter` 포함)할 수 있습니다.
- [ ] 검색 결과 파일 행에 주요 프론트매터 요약 배지가 컴팩트하게 표시되며(본문 일치 스니펫 및 기존 모드 유지 검색 점프와 공존), 결과 배지를 클릭하면 해당 필드·값 조건이 **프론트매터 필터 바**에 즉시 추가/적용됩니다.
- [ ] 정렬 드롭다운으로 기본 경로순 및 스키마 필드별 오름/내림차순 정렬을 전환할 수 있으며, 워크스페이스 스키마가 없을 때는 필터 영역에 `'스키마 생성'` 안내가 표시됩니다.
- [ ] 필터·정렬 상태는 다른 **왼쪽 사이드바** 뷰 전환·접기 시 세션 메모리에 유지되고 워크스페이스 전환 시 깨끗하게 초기화되며, `workspace-state.json`에 영속 저장되지 않습니다.
- [ ] `CONTEXT.md`에 **프론트매터 스키마**, **문서 속성 섹션**, **스키마 관리 모달**, **프론트매터 필터 바** 공식 어휘를 등록하고 **우측 사이드바**, **검색 패널**, **문서 편집기**, **섹션 리사이저**, **보조 창** 설명을 동기화합니다.
- [ ] `<App />` 통합 · 멀티윈도우 및 `<DocumentEditor />` 공개 UI 테스트 심이 위 동작들을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
