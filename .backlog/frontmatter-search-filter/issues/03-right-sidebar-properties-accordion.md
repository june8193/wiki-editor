# 03 — 우측 사이드바 2단 아코디언(목차 · 문서 속성 섹션) 및 실시간 프론트매터 작성 UI

**Spec:** [spec.md](../spec.md)

**What to build:** **우측 사이드바**를 기존 **Git 패널**과 동일한 2단 아코디언(**문서 목차** 상단 · **문서 속성 섹션** 하단)과 수평 **섹션 리사이저** 구조로 확장하고, 모든 **에디터 모드**와 **메인 창**·**보조 창**에서 6종 스키마 필드를 편집·검증하며 `Raw`/`Split` YAML 및 **문서 버퍼**와 실시간 양방향 동기화하는 작성 UI를 구현합니다.

**Blocked by:** `01-frontmatter-engine-and-schema-ipc`, `02-markdown-pipeline-frontmatter-integration`

**Status:** resolved

- [x] **우측 사이드바**에서 **문서 목차**(상단)와 **문서 속성 섹션**(하단)을 각각 독립적으로 접고 펼칠 수 있으며, 두 섹션이 모두 펼쳐졌을 때만 수평 **섹션 리사이저**(`20%~80%` 포인터 드래그, `ArrowUp`/`ArrowDown` 키보드 조절, 더블클릭 `50%` 복원)가 표시되고 한쪽을 접으면 펼쳐진 섹션이 전체 높이를 채웁니다.
- [x] 기존 **우측 사이드바** 좌측 경계 **사이드바 리사이저**(`180px~500px`)와 우측 접기/펼치기 탭이 그대로 유지되며, **보조 창**에서도 동일한 아코디언 동작과 세션 공유 **문서 버퍼** 동기화가 이루어집니다.
- [x] **문서 속성 섹션** 헤더에 채워진 필드 수 배지(`n/m`)와 유효성 경고 배지(`⚠ k`)가 표시되고, 헤더 내 보조 버튼 클릭 시 아코디언 접기/펼치기가 의도치 않게 토글되지 않습니다.
- [x] 6종 타입(`text`, `number`, `boolean`, `date`, `select`, `multi-select` 칩·Enter 추가·제안 버튼, `allowCustom` 제어) 위젯으로 속성을 편집하면 즉시 **문서 버퍼**가 갱신(`dirty` 표시·저장/자동 저장 연동)되고 `Raw`/`Split` YAML 원문과 양방향 실시간 동기화됩니다(`Raw` 타이핑 중 포커스·커서 유지).
- [x] 스키마 미정의 키는 접이식 `'미정의 필드 (N) · 보존'` 영역에 참고 표시되며 편집·저장 시 삭제되지 않고, 필수 누락·허용 외 옵션·타입 불일치·날짜 오류·YAML 구문 오류는 저장을 막지 않는 소프트 경고로 표시됩니다(YAML 구문 오류 시 미파싱 원문 보호 안내).
- [x] 프론트매터가 없는 마크다운 문서에서는 `'+ 속성 추가'`로 생성하고, 있는 문서에서는 `'프론트매터 제거'`로 제거할 수 있으며, 워크스페이스 스키마가 없을 때는 `'스키마 생성'` 버튼으로 즉시 초기화할 수 있습니다.
- [x] 비마크다운 파일(`config.json`, `.txt`), **Diff 탭**, 이미지 미리보기 탭에서는 **문서 속성 섹션**에 마크다운 전용 안내가 표시됩니다.
- [x] `<App />` 통합 · 멀티윈도우 및 `<DocumentEditor />` 공개 UI 테스트 심이 위 동작들을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
