# 01 — 앱 셸 뷰포트 스크롤 고정 및 Git 패널 고정 헤더 정리

**Spec:** [spec.md](../spec.md)

**What to build:** 긴 문서를 열었을 때 브라우저 창 전체가 스크롤되어 **액티비티 바**·**왼쪽 사이드바**·**우측 사이드바**·**탭 바**·**에디터 헤더**·**서식 툴바**가 화면 밖으로 밀려나지 않도록 앱 셸과 **편집기 영역**·**문서 편집기** 플렉스 높이 및 오버플로우 체인을 격리합니다. 아울러 **Git 뷰**의 **Git 패널** 헤더에 남아 있던 레거시 내부 접기 토글(`▾`/`▸`)을 제거하고 다른 사이드바 뷰와 일관된 상시 표시 고정 헤더로 통일합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 루트(`html`, `body`, `#root`)와 앱 셸, 본문 레이아웃에 오버플로우 격리가 적용되어 긴 문서를 열어도 창 전체 스크롤이 발생하지 않습니다.
- [ ] **편집기 영역**과 **문서 편집기** 세로 플렉스 체인에 최소 높이 제약 해제(`min-height: 0`) 및 오버플로우 격리가 적용되고, **탭 바**·**에디터 헤더**·**서식 툴바**·상단 **표 편집 툴바**와 각 사이드바 헤더에 축소 방지(`flex-shrink: 0`)가 보장되어 단일 및 **화면 분할 모드**(`좌우 분할`, `상하 분할`) 모두에서 문서 본문(**Raw**·**위지윅**·**Preview**)과 각 사이드바 본문만 독립 스크롤됩니다.
- [ ] **왼쪽 사이드바** 내부 뷰(**폴더 트리**, **Git 패널**, **워크스페이스 뷰**)의 오버플로우 정리 후에도 **폴더 트리** 우클릭 컨텍스트 메뉴와 브랜치 선택 조작이 정상 동작합니다.
- [ ] **Git 패널**에서 내부 접기 상태와 헤더 접기/펼치기 버튼(`aria-expanded`)이 제거되고, 정적 제목(`Git`), 현재 브랜치 배지, Ahead/Behind 배지, 새로고침 버튼만 갖춘 고정 헤더와 상시 표시 본문으로 렌더링됩니다.
- [ ] `<GitSidebarPanel />` 테스트에서 내부 접기 버튼이 존재하지 않고 본문이 항상 표시됨을 검증하며 기존 스테이징·커밋·브랜치 전환·동기화 동작이 회귀 없이 통과합니다.
- [ ] `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
