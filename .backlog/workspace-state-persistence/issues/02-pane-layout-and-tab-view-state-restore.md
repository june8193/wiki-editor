# 02 — 메인 창 편집 공간 레이아웃(탭·화면 분할) 및 탭별 뷰 상태 저장·복원

**Spec:** [spec.md](../spec.md)

**What to build:** 앱 시작 시 및 워크스페이스 전환 시 **메인 창**의 **편집 공간** 레이아웃(**화면 분할 모드**, **분할 구분선** 비율, 활성 **편집기 영역**, **주 편집기 영역**·**보조 편집기 영역** 각각의 워크스페이스 문서 탭 목록·순서·활성 탭)과 각 문서 탭의 뷰 상태(**에디터 모드**, 커서 선택 범위, 스크롤 위치, `Split` 내부 비율)를 워크스페이스별로 저장·복원하고, 누락 파일 제외 및 빈 **편집기 영역** 자동 단일 모드 축소를 완성합니다.

**Blocked by:** 01-workspace-state-storage-and-tree-restore

**Status:** ready-for-agent

- [ ] **메인 창**에서 워크스페이스 문서 탭(마크다운 문서 및 읽기 전용 이미지 미리보기 탭) 열기·닫기·순서 이동·영역 간 이동·복제, **화면 분할 모드**(`single` / `horizontal` / `vertical`) 및 **분할 구분선** 비율(`splitRatio`) 변경, 활성 **편집기 영역**(`activePaneId`) 및 영역별 활성 탭 전환, 탭별 뷰 상태(`mode`, `cursor`, `scrollTop`, `splitPreviewRatio`) 변경, 파일·폴더 이름 변경·이동·삭제 시 해당 워크스페이스의 편집 공간 상태가 저장되며, 다른 워크스페이스로 전환하기 직전에도 이전 워크스페이스의 상태가 빈 탭으로 덮어써지지 않고 보존됩니다.
- [ ] 일시적인 Git **Diff 탭**, 전역 `config.json` 탭, 분리된 **보조 창**의 탭은 워크스페이스별 상태 저장·복원 대상에서 제외됩니다(단, 워크스페이스 전환 시 이미 열려 있던 `config.json` **문서 버퍼** 보존 동작은 기존과 동일하게 유지).
- [ ] 앱 시작 시 마지막 워크스페이스가 열릴 때와 워크스페이스 A↔B 전환 시, 저장된 **주 편집기 영역**·**보조 편집기 영역**의 문서 탭 목록·순서·활성 탭, **화면 분할 모드**·`splitRatio`·`activePaneId`, 각 탭의 **에디터 모드**(`raw` / `wysiwyg` / `preview` / `split`)·`cursor`·`scrollTop`·`splitPreviewRatio`가 그대로 복원됩니다.
- [ ] 복원 시점에 외부에서 삭제·이동되어 디스크에 존재하지 않는 파일 탭은 **오류 배너** 없이 조용히 건너뛰고 존재하는 파일 탭만 복원합니다.
- [ ] 파일 누락 등으로 인해 분할 모드(`horizontal` / `vertical`)에서 한쪽 **편집기 영역**의 복원된 탭이 `0`개가 되면 자동으로 `single` 모드로 전환되며(**주 편집기 영역**이 비고 **보조 편집기 영역**에만 탭이 남은 경우 **주 편집기 영역**으로 승격), 저장된 활성 탭이 누락된 경우 해당 영역의 남은 유효 탭을 활성화합니다.
- [ ] `<App />` 통합 테스트 심과 워크스페이스 상태 저장소·복원 테스트 심에서 위 동작을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
