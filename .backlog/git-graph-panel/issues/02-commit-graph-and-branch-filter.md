# 02 — 커밋 히스토리 조회, 레인 그래프 렌더링 및 브랜치 필터·페이지네이션

**Spec:** [spec.md](../spec.md)

**What to build:** Git 서비스와 `git:log` IPC 브리지를 통해 저장소의 커밋 히스토리와 브랜치·태그 참조 정보를 페이지 단위로 조회하고, 순수 레인 배치 알고리즘으로 계산한 컬러 SVG 분기·병합 그래프와 참조 배지, 커밋 제목·작성자를 **Graph 섹션**에 렌더링합니다. 헤더 우측의 `전체` / `현재 브랜치` 범위 필터 전환과 `더 보기` 페이지네이션, 저장소 상태 변경 시 자동 갱신을 지원합니다.

**Blocked by:** 01-git-panel-changes-graph-split

**Status:** ready-for-agent

- [ ] 공유 스키마, `git:log` IPC 채널(활성 워크스페이스 일치 검증 포함), Preload `window.wikiApi.git.log` 브리지가 연결되고 경계 단위 테스트가 있습니다.
- [ ] Git 서비스의 커밋 로그 조회가 `전체`(`scope: 'all'`, 모든 로컬 브랜치·원격 추적 브랜치·태그, `refs/stash` 및 중복 `*/HEAD` 제외)와 `현재 브랜치`(`scope: 'current'`, `HEAD` 및 연결된 upstream)를 `--topo-order`로 조회하며, 기본 `100`개 페이지네이션(`skip`, `limit`, `hasMore`)과 첫 커밋 전(`isUnborn`) 빈 결과(`commits: [], hasMore: false`)를 격리된 임시 Git 저장소 통합 테스트로 검증합니다.
- [ ] 순수 레인 배치 모듈이 커밋 배열(선형, 분기, 2부모 이상 머지, 페이지 경계 밖 미등장 부모 레인 포함)로부터 각 행의 활성 레인, 노드 열, 분기·병합 연결 패스, 색상 인덱스, `HEAD` 및 머지 여부를 계산하며 단위 테스트가 있습니다.
- [ ] **Graph 섹션** 헤더 우측에 `전체`(기본값) / `현재 브랜치` 전환 토글이 제공되며, 필터 클릭 시 섹션 접힘 상태에 영향을 주지 않고 해당 범위의 그래프를 다시 불러옵니다.
- [ ] **Graph 섹션** 본문에 첫 커밋 전 저장소일 때 `"아직 커밋된 내역이 없습니다."` 안내가 표시되고, 커밋이 있을 때 각 행에 컬러 SVG 레인·노드(`HEAD` 강조 포함), 참조 배지(`HEAD`, 로컬 브랜치, 원격 브랜치, 태그), 커밋 제목·작성자 및 호버 툴팁(단축 해시·작성자·일시·제목)이 렌더링됩니다.
- [ ] `hasMore === true`일 때 목록 하단에 `더 보기` 버튼이 표시되고 클릭 시 다음 페이지 커밋들이 기존 목록 뒤에 누적되며, Commit·Pull·Push·Sync·브랜치 전환·새로고침·워크스페이스 파일 변경 시 최신 첫 페이지로 자동 갱신됩니다(이전 워크스페이스/필터의 지연 응답 무시 포함).
- [ ] `<App />` 통합 테스트가 커밋 그래프 및 참조 배지 표시, 첫 커밋 전 빈 상태, `전체`/`현재 브랜치` 필터 전환, `더 보기` 페이지네이션, Commit 실행 후 그래프 자동 갱신을 검증합니다.
- [ ] `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
