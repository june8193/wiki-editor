# 03 — 탭 세션 뷰 상태 기반 다이어그램 높이 유지 및 도메인 용어집 동기화

**Spec:** [spec.md](../spec.md)

**What to build:** 열린 문서 탭의 메모리 내 뷰 상태에 문서 내 **Mermaid 다이어그램 블록** 순번별 수동 높이를 보존하여 `위지윅` ↔ `Preview` ↔ `Split` **에디터 모드** 전환, 탭 간 이동, 실시간 코드 수정 시에도 조절한 높이가 그대로 유지되게 하고(마크다운 원문 및 디스크 `workspace-state.json` 비오염 보장), 도메인 용어집(`CONTEXT.md`)의 **Mermaid 다이어그램 블록** 정의를 최신화합니다.

**Blocked by:** `02-document-coords-and-edge-autoscroll`

**Status:** ready-for-agent

- [ ] 각 열린 문서 탭이 메모리 전용 뷰 상태로 문서 내 0-기반 **Mermaid 다이어그램 블록** 순번별 수동 높이 맵(`mermaidHeights`)을 보유하며, 동일 문서 내에 동일한 원문 코드를 가진 여러 블록이 있어도 순번별로 독립적인 높이가 유지됩니다.
- [ ] 하나의 탭에서 다이어그램 높이를 조절한 뒤 `위지윅` ↔ `Preview` ↔ `Split` **에디터 모드**를 전환하거나 다른 문서 탭으로 이동했다가 돌아왔을 때, 그리고 `Split`·`위지윅`에서 해당 다이어그램 코드를 실시간 편집할 때도 수동 높이가 초기화되지 않고 유지됩니다.
- [ ] 핸들 더블클릭 또는 액션 바의 통합 `뷰 초기화` 버튼으로 높이를 초기화하면 해당 블록 순번의 저장 높이가 탭 메모리에서도 즉시 제거되어 이후 모드·탭 전환 시에도 자동 높이 상태를 유지합니다.
- [ ] 다이어그램 높이 조절 및 탭 내 보존이 마크다운 **문서 버퍼** 본문이나 미저장(dirty) 상태를 변경하지 않으며, 디스크 `workspace-state.json` 저장 페이로드에도 포함되지 않습니다.
- [ ] 도메인 용어집(`CONTEXT.md`)의 **Mermaid 다이어그램 블록** 항목이 비율 유지 자동 스케일링 기반 하단 경계선 높이 조절 및 뷰 초기화 동작을 반영하도록 갱신됩니다.
- [ ] 사전 합의된 `<DocumentEditor />` 및 `<App />` 통합 심에서 모드 전환·탭 전환·동일 코드 다중 블록 독립성·초기화 연동·`workspace-state.json` 비포함 불변식을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
