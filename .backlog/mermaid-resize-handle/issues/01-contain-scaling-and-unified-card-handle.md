# 01 — Contain 자동 스케일링·동적 높이 범위·단일 카드 경계선 핸들 및 통합 뷰 초기화

**Spec:** [spec.md](../spec.md)

**What to build:** **Mermaid 다이어그램 블록**의 하단 리사이즈를 `Contain` 비율 유지 자동 스케일링과 동적 높이 범위(`min(64px, 자동 높이) ~ max(1600px, 자동 높이)`)로 전환해 잘림·빈 공간·첫 `1px` 점프 문제를 해결하고, 카드 하단 테두리 전체 폭 히트존(하단 선 하이라이트 + 드래그 중 높이 배지)과 `위지윅` 단일 카드 통합 레이아웃 및 액션 바 통합 `뷰 초기화` 버튼을 완성합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 기본 상태에서는 SVG 원본 논리 크기(`viewBox` 또는 `width`/`height`)와 가용 가로 폭을 기준으로 초기 자동 크기를 유지하며, 수동 높이가 설정되면 `<svg>` 인라인 `max-width` 제약을 해제하고 가용 가로·세로 안에 비율을 유지하며 함께 확대·축소(`Contain` 피팅)됩니다(높이 축소 시 상·하단 잘림 없음, 좁은 다이어그램 확대 시 비율 유지 성장, 가로 폭 `100%` 도달 후 아래로 드래그 시 가로 잘림 없이 뷰포트 창 높이만 확장, 컨테이너 폭 변경 시 `ResizeObserver`로 즉시 재계산).
- [ ] 높이 허용 범위가 동적 `[Math.min(64, autoViewportHeightPx), Math.max(1600, autoViewportHeightPx)]`로 동작하여 `120px` 미만 소형 다이어그램이나 `1200px` 초과 대형 다이어그램에서도 첫 `1px` 드래그 시 크기가 튀지 않고 연속적으로 조절됩니다.
- [ ] 전역 포인터 드래그 세션에서 `pointerdown` 시작 시 `pointer*` 이벤트만, 레거시 `mousedown` 시작 시 `mouse*` 이벤트만 구독하여 동일 드래그 이동에서 콜백이 중복 실행되지 않습니다.
- [ ] 리사이즈 핸들이 카드 하단 테두리 전체 가로 폭을 덮는 `14px` 히트존(`role="separator"`, `aria-orientation="horizontal"`, 키보드 `ArrowUp`/`ArrowDown` `±24px`)으로 배치되어 호버·포커스·드래그 시 하단 경계선과 그립이 강조되고, 포인터 드래그 중에는 실시간 높이 배지(`{height}px`)가 표시되며, `위지윅` **에디터 모드**의 중첩 이중 테두리가 단일 카드 구조로 통합됩니다.
- [ ] 공용 액션 바의 `확대` 버튼 옆에 통합 `뷰 초기화` 아이콘 버튼(`aria-label="뷰 초기화"`)이 추가되어 배율·패닝·수동 높이 중 하나라도 변경된 상태에서 활성화되고 클릭 시 세 가지를 모두 초기 상태로 복원하며, 기존 `배율 초기화`(`100%` 버튼: 배율·패닝만 복원) 및 핸들 더블클릭(수동 높이만 복원)과 역할이 정확히 구분되고 PNG·SVG 내보내기는 변형 없는 원본 비율을 유지합니다.
- [ ] 사전 합의된 `<MermaidDiagram />` 컴포넌트 심과 `<WysiwygMarkdownEditor />` 통합 심에서 위 동작과 마크다운 무변이를 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
