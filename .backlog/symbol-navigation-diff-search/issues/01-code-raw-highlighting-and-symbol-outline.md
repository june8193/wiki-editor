# 01 — 일반 코드 Raw 신택스 하이라이팅, Lezer 심볼 추출기 및 우측 심볼 목차 구현

**Spec:** [spec.md](../spec.md)

**What to build:** 비마크다운 코드 문서(`Raw` **에디터 모드**)에 파일 확장자별 Lezer 신택스 하이라이팅을 적용하고, 온디맨드 Lezer 구문 트리 기반 심볼·식별자 추출기를 구축하여 일반 코드 탭·**Diff 탭** 활성 시 **우측 사이드바** 상단 **문서 목차**에 현재 파일의 심볼 목록(종류 표기, **Diff 탭** 내 추가 `+`·수정 `M` 배지, 실시간 필터 입력창)과 클릭 시 줄 점프(가상 스크롤 **Diff 뷰어** 원거리 줄 스크롤·강조 포함)를 엔드투엔드로 구현합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 비마크다운 코드 문서(`.ts`, `.tsx`, `.js`, `.py`, `.go`, `.rs`, `.cpp`, `.java` 등)를 `Raw` **에디터 모드**로 열 때 기존 마크다운·JSON 동작을 유지하면서 지연 로드된 Lezer 언어 파서로 신택스 하이라이팅이 적용된다.
- [ ] 내장 Lezer 구문 트리 순회 기반 심볼·식별자 추출기가 주요 언어의 함수·클래스·메서드·타입·인터페이스·변수 선언 심볼 목록과 특정 위치의 식별자 토큰을 정확히 판별하며, 주석·문자열 내부의 동명 단어는 제외한다.
- [ ] 일반 코드 탭 또는 **Diff 탭** 활성 시 **우측 사이드바** 상단 **문서 목차**가 현재 파일의 심볼 목록을 표시하고, 이름 필터 입력창으로 즉시 필터링할 수 있으며, **Diff 탭**에서는 변경된 범위에 속한 심볼에 `+`/`M` 배지를 구분 표시한다.
- [ ] **문서 목차**의 심볼 항목을 클릭하면 일반 코드 탭은 해당 줄로 커서·스크롤 이동 및 임시 강조되고, **Diff 뷰어**(**좌우 비교**·**인라인** 및 가상 스크롤 활성 상태 포함)는 대상 줄로 스크롤 이동·강조된다.
- [ ] 마크다운 문서 탭으로 전환하면 **문서 목차**가 기존 헤딩 목차로 즉시 복귀하며, Lezer 심볼 추출기, 가상 스크롤 **Diff 뷰어**, **App** 통합 테스트가 모두 통과한다.
