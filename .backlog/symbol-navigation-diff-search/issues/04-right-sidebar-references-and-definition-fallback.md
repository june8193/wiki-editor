# 04 — 우측 사이드바 레퍼런스 섹션 및 Ctrl+클릭 미선언 폴백 구현

**Spec:** [spec.md](../spec.md)

**What to build:** 코드 탭·**Diff 탭**·**스냅샷 탭** 활성 시 **우측 사이드바** 하단(**문서 속성 섹션** 위치)을 **레퍼런스 섹션**(`References`)으로 전환하여 우클릭 컨텍스트 메뉴 `'레퍼런스 찾기'` 및 `Shift+F12`로 조회한 시점 일치 참조 목록을 파일별로 그룹화해 닫힘 없이 클릭 순회하게 하고, `Ctrl+클릭` 시 저장소 내 명확한 선언부를 찾지 못했을 때 **레퍼런스 섹션**으로 부드럽게 폴백하는 흐름을 엔드투엔드로 구현합니다.

**Blocked by:** 03-snapshot-tab-history-and-ctrl-click-definition

**Status:** ready-for-agent

- [ ] 비마크다운 코드 탭·**Diff 탭**·**스냅샷 탭**이 활성화된 동안 **우측 사이드바** 하단이 **레퍼런스 섹션**으로 표시되고, 마크다운 문서 탭이 활성화되면 기존 **문서 속성 섹션**이 그대로 복원된다.
- [ ] **Diff 뷰어**·**스냅샷 뷰어**·코드 `Raw` 편집기에서 식별자 우클릭 `'레퍼런스 찾기'` 또는 `Shift+F12` 실행 시 접혀 있던 **우측 사이드바**와 하단 섹션이 자동으로 펼쳐지며, 주석·문자열 오탐을 거른 시점 일치 참조 목록을 파일별 그룹(현재 Diff/Compare 변경 파일 상단 우선, 시점 배지 포함)으로 표시한다.
- [ ] **레퍼런스 섹션**의 일치 줄을 클릭하면 시점 일치 규칙(변경 Hunk 내부는 **Diff 탭**, 그 외는 로컬 또는 **스냅샷 탭**)에 따라 대상 줄로 이동·강조하고 **탐색 히스토리**에 기록하며, 목록은 닫히지 않고 유지되어 여러 호출부를 연속 순회할 수 있다.
- [ ] `Ctrl+클릭` 시 저장소 내에서 명확한 선언부를 찾지 못했으나 다른 참조가 존재하면 **레퍼런스 섹션**을 자동으로 열어 참조 목록과 안내 메시지("명확한 선언부를 찾지 못해 참조 N건을 표시합니다")를 보여준다.
- [ ] 다른 참조도 존재하지 않는 외부 심볼 등에서는 **레퍼런스 섹션**을 덮어쓰지 않고 커서 근처에 짧은 인라인 안내 툴팁만 표시하며 `Esc` 또는 다른 클릭 시 자연스럽게 닫힌다.
