# 03 — 에디터 헤더 인코딩 메뉴 및 확인 다이얼로그 UI

**Spec:** [spec.md](../spec.md)

**What to build:** **에디터 헤더**에 현재 인코딩 표시 버튼과 VS Code 스타일 인코딩 메뉴(`인코딩으로 다시 열기` / `인코딩 변경`)를 추가하고, 미저장 재열기·표현 불가 문자 저장 **확인 다이얼로그**, 자동 저장 보류 **오류 배너**, JSON/이미지 탭 보호 및 멀티 창 동기화를 완성합니다.

**Blocked by:** 02-shared-buffer-encoding-and-ipc

**Status:** ready-for-agent

- [ ] **에디터 헤더**에 현재 **문서 버퍼**의 인코딩(`UTF-8` 또는 `EUC-KR`)을 표시하는 버튼이 노출되고, 이미지 미리보기 탭에서는 숨겨지며, `config.json` 및 `.wiki-editor/frontmatter.json` 탭에서는 `UTF-8` 고정(전환 비활성화) 상태로 동작한다.
- [ ] 인코딩 버튼 클릭 시 메뉴에서 **인코딩으로 다시 열기(Reopen)**(`UTF-8` / `EUC-KR`)와 **인코딩 변경(변환)**(`UTF-8` / `EUC-KR`)이 명확히 구분되어 선택 가능하다.
- [ ] 미저장(`isDirty`) 상태에서 **인코딩으로 다시 열기**를 선택하면 **확인 다이얼로그**로 변경 사항 손실 경고를 띄우고, 확인 시에만 디스크에서 재디코딩한다.
- [ ] **인코딩 변경** 선택 시 본문 텍스트를 유지한 채 대상 인코딩만 변경되어 미저장(`●`) 배지가 표시되고, `Ctrl+S`/저장 버튼(또는 자동 저장) 시 해당 인코딩으로 저장된다.
- [ ] `EUC-KR` 수동 저장 시 표현 불가 문자가 감지되면 **확인 다이얼로그**에 손실 가능 문자 예시를 안내하고, 확인 시 `?` 대체 저장(`allowLossy: true`)을 수행하며 취소 시 미저장 상태를 유지한다.
- [ ] 자동 저장 중 `EUC-KR` 표현 불가 문자로 보류되면 **오류 배너**에 원인이 표시되고 디스크 파일은 손상되지 않는다.
- [ ] **메인 창**, **보조 창**, 분할 **편집기 영역**에 동일 문서가 열려 있을 때 인코딩 변경 및 재열기 상태가 실시간 동기화되며, 앱 통합 테스트가 통과한다.
