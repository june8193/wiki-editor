# 03 — 다중 메인 창 간 중복 워크스페이스 오픈 방지(기존 창 포커스) 및 도메인 문서 갱신

**Spec:** [spec.md](../spec.md)

**What to build:** 다른 **메인 창**에 이미 열려 있는 워크스페이스를 `'새 창에서 열기'` 버튼, 목록 항목 일반 클릭(현재 창 전환), 또는 `'폴더 열기...'`(메뉴 명령 포함)로 선택했을 때 중복 창 생성이나 현재 창 전환 없이 기존 **메인 창**을 즉시 복원·포커스하도록 연결하고, 다중 **메인 창** 간 전역 설정 실시간 동기화 검증 및 `CONTEXT.md` 도메인 용어 갱신을 완료합니다.

**Blocked by:** 02-workspace-view-open-in-new-window-button

**Status:** ready-for-agent

- [ ] 다른 **메인 창**에 이미 열려 있는 워크스페이스 항목의 `'새 창에서 열기'` 버튼을 클릭하면, 새 **메인 창**을 추가로 생성하지 않고 해당 워크스페이스가 열려 있는 기존 **메인 창**을 복원(`restore`)·포커스(`focus`)합니다.
- [ ] 현재 창에 미저장 **문서 버퍼**가 있는 상태에서 다른 **메인 창**에 이미 열려 있는 워크스페이스 항목 본문을 클릭(현재 창 전환)하거나 `'폴더 열기...'` 다이얼로그(및 메뉴 `open-folder`)로 해당 폴더를 선택하면, 미저장 **확인 다이얼로그**를 띄우거나 현재 창의 워크스페이스를 교체하지 않고 기존 **메인 창**을 즉시 복원·포커스합니다.
- [ ] 여러 **메인 창**이 열려 있을 때 한 창에서 전역 설정(테마 전환, 자동 저장 토글, 즐겨찾기 추가·해제, 최근 워크스페이스 갱신, `config.json` 직접 편집 저장)을 변경하면 열려 있는 모든 **메인 창**과 **보조 창**에 실시간으로 반영되며, 각 **메인 창**의 **워크스페이스 뷰** 활성 표시 및 `'새 창에서 열기'` `disabled` 상태는 각 창 자신의 활성 워크스페이스를 기준으로 독립 유지됩니다.
- [ ] `CONTEXT.md`의 **메인 창 (Main Window)**, **보조 창 (Auxiliary Window)**, **워크스페이스 뷰 (Workspace View)**, **문서 버퍼 (Document Buffer)**, **확인 다이얼로그 (Confirm Dialog)** 정의를 다중 **메인 창** 워크스페이스 세션 모델에 맞게 갱신합니다.
- [ ] 멀티윈도우 `<App />` 통합 테스트 심과 메인 프로세스 다중 창 테스트 심이 위 동작들을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
