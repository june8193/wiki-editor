# 04 — 위지윅 · Preview 에디터 모드 문서 내 찾기 및 Split 동시 강조 통합

**Spec:** [spec.md](../spec.md)

**What to build:** **문서 내 찾기 바**의 일치 강조·매치 카운트(`n / m`)·이전/다음 순환 이동 및 자동 스크롤을 `위지윅`(TipTap/ProseMirror 문서 텍스트 데코레이션)과 `Preview`(마크다운 렌더링 DOM 텍스트 강조, UI 크롬 제외) 모드까지 완전히 확장하고, `Split` 모드의 우측 `Preview`에도 동일한 Preview 하이라이트를 동시 적용하며, 4개 **에디터 모드** 간 전환 시 끊김 없는 재검색을 완성합니다.

**Blocked by:** 03-in-document-find-bar-raw-and-split

**Status:** ready-for-agent

- [ ] `위지윅` 모드에서 **문서 내 찾기 바**의 검색어와 `Aa`·`ab`·`.*` 옵션에 따라 문단·헤딩·목록·표 셀·코드 블록 본문의 모든 일치 구간과 현재 활성 일치 구간이 구분 강조되고, 이전/다음 이동 시 활성 일치로 스크롤되며, 본문을 직접 편집해도 일치 강조와 카운트가 실시간 동기화됩니다(찾기 강조가 마크다운 **문서 버퍼** 내용이나 미저장 상태를 오염시키지 않음).
- [ ] `Preview` 모드에서 렌더링된 마크다운 텍스트(문단·헤딩·목록·표·코드 블록 본문)의 모든 일치 구간과 현재 활성 일치 구간이 구분 강조되고, 이전/다음 이동 시 활성 일치 요소로 스크롤됩니다.
- [ ] `Preview` 및 `위지윅` 검색·강조 시 코드 블록 헤더(`코드 복사` 버튼·언어 배지)와 **Mermaid 다이어그램 블록** 내부 `<svg>`·액션 바 등 에디터 UI 크롬 텍스트는 일치 대상에서 제외합니다.
- [ ] `Split` 모드에서 좌측 `Raw` 편집기에서 매치를 탐색하는 동안 우측 `Preview`에도 동일한 검색어·옵션의 일치 항목이 동시 강조됩니다.
- [ ] `위지윅` 및 `Preview` 모드에서 텍스트를 드래그 선택한 상태로 `Ctrl+F`를 누르면 선택된 단일 줄 텍스트가 검색 입력창에 자동 채워집니다.
- [ ] 동일 탭에서 `Raw` ↔ `위지윅` ↔ `Preview` ↔ `Split` 간 **에디터 모드**를 전환해도 **문서 내 찾기 바**와 검색어·옵션이 유지되며 새 모드에서 즉시 재검색·강조됩니다.
- [ ] `<App />` 통합 및 `<DocumentEditor />` 공개 UI 테스트 심이 4개 **에디터 모드** 전체의 문서 내 찾기·모드 전환·크롬 제외·비오염 동작을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
