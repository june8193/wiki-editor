# 03 — 문서 내 찾기 바 · 에디터 헤더 버튼 · Pane 상태 유지 및 Raw·Split 검색

**Spec:** [spec.md](../spec.md)

**What to build:** **문서 편집기** 우상단의 플로팅 **문서 내 찾기 바**와 **에디터 헤더**의 찾기(`🔍`) 버튼, `Ctrl+F`(선택 텍스트 자동 채움)·`Enter`/`Shift+Enter`·`F3`/`Shift+F3`·`Esc` 단축키, **편집기 영역(Pane)** 단위 찾기 상태 유지(**메인 창**·**보조 창** 모두 지원, **Diff 탭**·이미지 탭 숨김/비활성화)를 구축하고, `Raw` 모드(CodeMirror 6 일치 강조·활성 일치 스크롤)와 `Split` 모드(`Raw` 기준 매치 탐색·카운트 및 우측 `Preview` 줄 동기화 연동)에서 완전히 동작하게 만듭니다.

**Blocked by:** 01-workspace-search-service-and-ipc

**Status:** resolved

- [x] **에디터 헤더**에 찾기(`🔍`, 툴팁 `"문서 내 찾기 (Ctrl+F)"`) 버튼이 표시되며, 클릭 시 해당 **편집기 영역**의 **문서 내 찾기 바**를 여닫고 이미지 미리보기 탭에서는 비활성화됩니다.
- [x] **메인 창**과 **보조 창**의 활성 **편집기 영역**에서 `Ctrl+F`를 누르면 텍스트 문서 탭에서 **문서 내 찾기 바**가 열리고 검색 입력창에 포커스됩니다. 에디터에 단일 줄 텍스트가 선택되어 있으면 해당 텍스트로 검색어를 자동 채우고, 모달(**확인 다이얼로그**, **전역 설정 패널**)이 열려 있거나 활성 탭이 **Diff 탭**·이미지 탭이면 `Ctrl+F`를 억제합니다.
- [x] **문서 내 찾기 바**가 검색 입력창, `Aa` · `ab` · `.*` 옵션 3종, 매치 카운트(`n / m` 또는 `결과 없음`), 이전(`Shift+Enter` / `Shift+F3` / 버튼)·다음(`Enter` / `F3` / 버튼) 순환 이동, 닫기(`Esc` / 버튼), 잘못된 정규식 인라인 오류 안내를 제공합니다.
- [x] **문서 내 찾기 바**의 열림 상태·검색어·옵션이 **편집기 영역(Pane)** 단위로 유지되어, 같은 영역 내 다른 텍스트 탭으로 전환하면 동일 검색어로 즉시 재검색하고, **Diff 탭**·이미지 탭으로 전환 시 일시 숨겼다가 텍스트 탭으로 돌아오면 다시 표시합니다(화면 분할 시 주·보조 편집기 영역은 독립 상태를 유지).
- [x] `Raw` 모드(마크다운 및 `config.json`/`.json`/`.txt` 등 모든 텍스트 문서)에서 전체 일치 구간과 현재 활성 일치 구간이 구분 강조되고, 이전/다음 이동 시 활성 일치 위치가 뷰포트에 보이도록 스크롤되며, 본문 수정 시 매치 목록과 카운트가 실시간 갱신됩니다.
- [x] `Split` 모드에서 좌측 `Raw` 편집기를 기준으로 매치 카운트(`n / m`)와 순환 이동이 동작하고, 우측 `Preview`가 활성 일치 위치에 맞춰 줄 동기화 스크롤됩니다.
- [x] `<App />` 통합 · 멀티윈도우 및 `<DocumentEditor />` 공개 UI 테스트 심이 위 동작들을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
