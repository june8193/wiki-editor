# 02 — 액티비티 바 검색 뷰 · 검색 패널 UI 및 워크스페이스 검색 결과 목록

**Spec:** [spec.md](../spec.md)

**What to build:** **액티비티 바**에 전용 **검색 뷰**(`탐색기` · `검색` · `Git` · `워크스페이스`)와 **검색 패널**을 추가하고 `Ctrl+Shift+F` 단축키 진입, `200ms` 디바운스 자동 검색(한글 IME 조합 안전 처리)·`Enter` 즉시 재실행·수동 새로고침 버튼, `Aa`·`ab`·`.*` 옵션 토글, 파일별 통합 접기/펼치기 결과 목록(파일명 일치 강조 및 상위 정렬, 본문 줄 번호·스니펫 강조), 항목 클릭 시 활성 **편집기 영역**에서 문서 열기까지 엔드투엔드로 동작하게 만듭니다.

**Blocked by:** 01-workspace-search-service-and-ipc

**Status:** ready-for-agent

- [ ] **액티비티 바**에 `탐색기` · `검색` · `Git` · `워크스페이스` 순서로 `검색` 아이콘이 표시되며, 클릭 시 **왼쪽 사이드바**에 **검색 뷰**(**검색 패널**)를 단독 표시하고 활성 아이콘 재클릭 시 접고 펼칩니다.
- [ ] **메인 창**에서 `Ctrl+Shift+F`를 누르면 **왼쪽 사이드바**가 접혀 있거나 다른 뷰여도 **검색 뷰**를 펼치고 검색 입력창에 포커스(기존 검색어 존재 시 전체 선택)합니다. **확인 다이얼로그**나 **전역 설정 패널**이 열려 있을 때는 단축키를 억제하고, **보조 창**에서는 `Ctrl+Shift+F`를 무시하며, **애플리케이션 메뉴 바**는 기존 `File` · `Settings` · `Help` 3개 구성을 유지합니다.
- [ ] 검색어 입력 시 한글 IME 조합 중에는 검색을 실행하지 않고 조합 완료 및 `200ms` 디바운스 후 자동 검색을 실행하며, `Enter` 키 또는 상단 `새로고침` 버튼으로 즉시 재실행할 수 있습니다(문서 편집 중 자동 재검색으로 결과 목록이 흔들리지 않음).
- [ ] 검색 입력창에 `Aa`(대소문자 구분) · `ab`(단어 단위) · `.*`(정규식) 토글 버튼이 제공되며, 잘못된 정규식 입력 시 **오류 배너**가 아니라 **검색 패널** 내 인라인 오류 메시지를 표시하고, 결과 상한(`truncated`) 초과 시 안내 배너를 표시합니다.
- [ ] 열린 워크스페이스가 없거나 검색어가 비어 있거나 결과가 0건일 때 각각 명확한 빈 상태 안내를 표시합니다.
- [ ] 검색 결과가 파일별 통합 그룹(접기/펼치기, 파일당 일치 수 배지)으로 표시되며, 파일명·경로 일치 시 헤더에 일치 구간을 강조하고 본문 일치 항목은 1-기반 줄 번호와 일치 텍스트가 강조된 스니펫으로 표시합니다.
- [ ] 파일명만 일치한 파일 헤더 또는 본문 일치 항목을 클릭하면 활성 **편집기 영역**에서 해당 문서를 열거나 기존 탭을 활성화합니다.
- [ ] **검색 뷰**의 검색어·옵션·결과·접힘 상태는 다른 사이드바 뷰로 전환하거나 사이드바를 접었다 펼쳐도 유지되며, 다른 워크스페이스로 전환하면 초기화되고 `workspace-state.json`에는 저장되지 않습니다.
- [ ] `<App />` 통합 · 멀티윈도우 테스트 심이 위 동작들을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
