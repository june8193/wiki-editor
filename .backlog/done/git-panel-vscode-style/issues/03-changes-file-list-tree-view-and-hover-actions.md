# 03 — Changes 섹션 파일 목록 리디자인, 경로 압축 트리 보기 및 호버 액션

**Spec:** [spec.md](../spec.md)

**What to build:** **Changes 섹션** 헤더에 아이콘 툴바(리스트↔트리 보기 전환, Commit `✓`, 새로고침 `↻`)를 배치하고, `Staged Changes`(0건 시 자동 숨김)와 `Changes` 접기/펼치기 하위 그룹, 22~24px VS Code 컴팩트 파일 행(파일 아이콘 + 파일명 + 흐린 상대 디렉토리 경로 + 호버/포커스 `파일 열기` · `롤백` · `Stage`/`Unstage` + 우측 끝 VS Code 상태 문자/색상 및 삭제 취소선), 경로 압축 폴더 트리 보기를 엔드투엔드로 구현합니다.

**Blocked by:** 02-smart-commit-cta-and-auto-stage

**Status:** resolved

- [x] UI 상태 표시 매핑 순수 모듈이 내부 `GitFileStatusCode`를 불변 유지한 채 VS Code 표기(`?` → 초록 `U`, `U` → 빨강 `C`, `M` → 앰버 `M`, `A` → 초록 `A`, `D` → 빨강 `D` + 파일명 취소선, `R` → `R`)로 매핑함을 단위 테스트로 검증합니다.
- [x] 경로 압축 폴더 트리 빌더 순수 모듈이 단일 하위 폴더 체인(`a/b/c`) 압축, 폴더 우선·알파벳순 정렬, 루트 파일 배치, 이름 변경(`origPath`) 파일 처리를 정확히 수행하고 단위 테스트로 검증합니다.
- [x] **Changes 섹션** 헤더에 `lucide-react` 아이콘 버튼(`리스트/트리 보기 전환`, `Commit ✓`(스마트 커밋 흐름 연동), `새로고침 ↻`)이 배치되며, `Staged Changes`는 0건일 때 숨겨지고 1건 이상일 때 접기/펼치기·우측 카운트 배지·호버/포커스 일괄 `-` 아이콘과 함께 표시됩니다(`Changes`는 접기/펼치기·카운트 배지·호버/포커스 일괄 `↶`/`+` 제공).
- [x] 파일 행이 파일 아이콘 + 파일명 + 흐린 상대 디렉토리 경로(리스트 모드) + 우측 끝 상태 문자로 컴팩트하게 렌더링되며, 호버 및 키보드 `:focus-within` 시 `파일 열기`(삭제 `D` 및 워크스페이스 루트 밖 경로 제외) · `롤백`(Unstaged/Untracked 전용) · `Stage`/`Unstage` 아이콘이 노출됩니다.
- [x] 파일 행 본문 클릭 시 기존처럼 활성 **편집기 영역**에 **Diff 탭**이 열리고, 호버 `파일 열기` 아이콘 클릭 시 일반 편집 문서 탭이 열리며(**Diff 탭** 미열림), 트리 보기에서 폴더 클릭으로 접기/펼치기가 세션 메모리에서 동작합니다(워크스페이스 전환 시 폴더 접힘 초기화).
- [x] 라이트·다크 양쪽 테마에서 VS Code 상태 색상과 호버·선택·포커스 대비가 정의되며, `<App />` 통합 테스트와 단위 테스트, `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
