# 05 — 종속 창 생명주기, 워크스페이스 전환 정리 및 창 닫기 미저장 보호

**What to build:** **메인 창** 종료 시 모든 **보조 창**이 함께 닫히는 종속 생명주기, **메인 창**·**보조 창** 닫기(`X`) 시 전체 창 참조 카운트 기준 마지막 미저장 문서에 대한 **확인 다이얼로그** 보호, **메인 창** 워크스페이스 전환 시 전체 창 미저장 확인 및 **보조 창** 이전 워크스페이스 탭 정리를 완성합니다.

**Blocked by:** 04-cross-window-tab-reattach-and-merge

**Status:** resolved

- [x] **보조 창**의 창 닫기(`X`) 시: 열린 탭이 없거나 미저장 문서가 다른 창에도 열려 있으면 확인 없이 즉시 닫히고, 이 **보조 창**이 닫힘으로써 전체 창 기준 마지막 참조가 사라지는 미저장 문서(`workspace` 및 `config`)가 있으면 닫기를 보류하고 해당 **보조 창**에 **확인 다이얼로그**(`저장 후 닫기` / `버리고 닫기` / `취소`)를 표시합니다(저장 실패 시 닫기 중단 및 **오류 배너** 표시).
- [x] **메인 창**의 창 닫기(`X`) 시: 모든 **보조 창**이 함께 닫혀야 하므로 **메인 창**과 모든 **보조 창** 전체에 미저장 문서(`workspace` 및 `config`)가 1개라도 있으면 **메인 창**에 **확인 다이얼로그**(`저장 후 닫기` / `버리고 닫기` / `취소`)를 표시하고, 미저장 문서가 없거나 저장 성공/버리기 확정 시 모든 **보조 창**을 추가 확인 없이 함께 닫고 종료합니다.
- [x] 탭이 모두 빠져나가 빈 상태가 된 **보조 창**의 자동 닫힘은 불필요한 닫기 확인에 가로막히지 않고 즉시 완료됩니다.
- [x] **메인 창**에서 워크스페이스를 전환(또는 새 폴더 열기)할 때 **메인 창**과 모든 **보조 창**에 열린 미저장 `workspace` 문서를 함께 확인·저장하고, 전환 확정 시 **보조 창**의 이전 워크스페이스 탭들도 모두 닫아 남은 탭이 없는 **보조 창**은 자동 닫히게 합니다(`config.json` 탭만 열려 있는 **보조 창**은 유지).
