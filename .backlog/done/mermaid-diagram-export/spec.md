# Spec: Mermaid 다이어그램 블록 내보내기(PNG · SVG) 및 클립보드 복사

## Problem Statement (문제 정의)

현재 **문서 편집기**의 `Preview`, `Split`, `위지윅` **에디터 모드**에서 렌더링되는 **Mermaid 다이어그램 블록**은 화면 열람과 코드 편집만 지원하며, 렌더링된 다이어그램을 외부 문서·발표자료·메신저에 바로 붙여넣거나 이미지/벡터 파일로 내보낼 수 있는 기능이 없습니다.

- 사용자가 다이어그램을 공유하려면 OS 화면 캡처 도구에 의존해야 하므로 고해상도 배율 저하, 불균일한 여백, 다크 테마 배경의 대비 훼손이 발생합니다.
- `Preview` **에디터 모드**에서는 다이어그램의 Mermaid 원문 코드를 복사하기 위해 `Raw`나 `Split` 모드로 전환한 뒤 해당 코드 블록을 직접 찾아 선택·복사해야 하는 번거로움이 있습니다.

## Solution (해결 방안)

각 **Mermaid 다이어그램 블록**에 이미지·코드 복사와 파일 내보내기를 즉시 실행할 수 있는 4종 원클릭 액션을 제공합니다.

1. **4종 컴팩트 아이콘 액션 바**:
   - 각 **Mermaid 다이어그램 블록**에서 `이미지 복사`(PNG 클립보드), `코드 복사`(Mermaid 원문 클립보드), `PNG 저장`, `SVG 저장`을 컴팩트 아이콘 버튼 4개(툴팁 및 접근 가능한 이름 포함)로 일렬 제공합니다.
2. **에디터 모드별 일관된 UI 통합**:
   - `Preview` 및 `Split` **에디터 모드**(우측 미리보기)에서는 문서 열람 몰입을 해치지 않도록 블록 우측 상단에 마우스 호버 또는 키보드 포커스 시 나타나는 플로팅 액션 바로 배치합니다.
   - `위지윅` **에디터 모드**에서는 이중 툴바가 생기지 않도록 기존 블록 상단 헤더(`코드 편집` 버튼 옆)에 4개 액션 버튼을 통합 배치합니다.
3. **현재 테마 유지 + 불투명 배경 · 외곽 여백 · 고해상도 보장**:
   - 활성 앱 테마(`light`: `#ffffff`, `dark`: `#161b22`)의 표면 배경색과 사방 `16px` 외곽 여백을 PNG·SVG 출력에 포함하여, 다크 모드 다이어그램을 밝은 외부 문서나 브라우저에서 열어도 텍스트·화살표 시인성이 깨지지 않게 합니다.
   - PNG 출력(클립보드 복사 및 파일 저장 공통)은 `2x` 고해상도 배율(초대형 다이어그램은 안전 한계 내 자동 축소)로 생성합니다.
4. **네이티브 파일 저장 및 문법 오류 보호**:
   - `PNG 저장`과 `SVG 저장`은 Electron 네이티브 `다른 이름으로 저장` 대화상자를 열어 `<문서명>-diagram.png` / `.svg` 기본 파일명을 자동 제안합니다.
   - 초기 렌더링 중이거나 문법 오류가 있는 상태(직전 정상 다이어그램이 화면에 유지 표시되는 상태 포함)에서는 수정 중인 코드와 다른 오래된 이미지가 실수로 공유되지 않도록 이미지 복사·저장 액션을 비활성화하고 `코드 복사`만 허용합니다.

## User Stories (사용자 스토리)

1. As a 위키 열람자, I want `Preview` 및 `Split` **에디터 모드**에서 **Mermaid 다이어그램 블록**에 마우스를 올리거나 키보드 포커스를 이동했을 때 우측 상단에 액션 바가 표시되기를 원하며, so that 평상시 문서 읽기 화면을 가리지 않으면서 필요할 때 즉시 복사·저장 액션을 실행할 수 있습니다.
2. As a 위키 작성자, I want `위지윅` **에디터 모드**에서 기존 **Mermaid 다이어그램 블록** 상단 헤더(`코드 편집` 버튼 옆)에 내보내기·복사 액션 버튼들이 함께 배치되기를 원하며, so that 한 블록 안에 툴바가 위아래로 겹치지 않고 깔끔하게 사용할 수 있습니다.
3. As a 위키 작성자, I want `이미지 복사` 버튼을 한 번 클릭해 현재 활성 테마와 불투명 배경(`16px` 여백 포함)이 반영된 `2x` 고해상도 PNG 이미지를 시스템 클립보드에 복사하기를 원하며, so that 메신저, 슬라이드, 이슈 트래커에 다이어그램을 선명하게 즉시 붙여넣을 수 있습니다.
4. As a 위키 열람자, I want `Preview` 및 `Split` **에디터 모드**를 포함한 모든 **Mermaid 다이어그램 블록**에서 `코드 복사` 버튼으로 Mermaid 원문 코드를 클립보드에 복사하기를 원하며, so that **에디터 모드**를 전환하거나 본문을 드래그하지 않고도 다이어그램 소스를 재사용할 수 있습니다.
5. As a 위키 작성자, I want `PNG 저장` 버튼을 눌러 네이티브 `다른 이름으로 저장` 대화상자에서 `<문서명>-diagram.png` 기본 파일명으로 원하는 위치에 고해상도 PNG 파일을 저장하고 원하면 취소하기를 원하며, so that 파일 이름과 저장 경로를 안전하게 제어할 수 있습니다.
6. As a 위키 작성자, I want `SVG 저장` 버튼을 눌러 현재 테마 배경색과 `16px` 여백이 포함된 독립 실행 가능한 벡터 SVG 파일을 `<문서명>-diagram.svg` 기본 파일명으로 저장하기를 원하며, so that 확대해도 깨지지 않는 벡터 그래픽을 디자인 도구나 웹 문서에서 활용할 수 있습니다.
7. As a 위키 작성자, I want 다이어그램 문법 오류가 발생한 상태(직전 정상 다이어그램이 화면에 유지되는 상태 포함)나 초기 로딩 중에는 이미지 관련 버튼(`이미지 복사`, `PNG 저장`, `SVG 저장`)이 비활성화되고 `코드 복사`만 동작하기를 원하며, so that 최신 코드와 불일치하는 과거 다이어그램 이미지를 실수로 외부에 내보내지 않습니다.
8. As a 위키 작성자, I want 복사 또는 파일 저장이 완료되면 해당 버튼이 약 1.5초간 체크(`✓`) 상태로 표시되었다가 복귀하고, 오류 발생 시 블록 내부에 간결한 인라인 알림이 표시되기를 원하며, so that 별도의 **오류 배너**나 팝업 확인 없이 작업 성패를 즉시 파악할 수 있습니다.
9. As a 위키 작성자, I want 한 문서에 여러 **Mermaid 다이어그램 블록**이 있더라도 각 블록의 버튼 상태와 피드백이 독립적으로 유지되고 비어 있는 코드 블록에서는 모든 액션이 비활성화되기를 원하며, so that 여러 다이어그램을 오가며 작업해도 상태가 섞이거나 빈 데이터가 복사·저장되지 않습니다.

## Implementation Decisions (구현 결정사항)

### 1. 다이어그램 클립보드 · 파일 저장 IPC 인터페이스 계약
- **공유 IPC 채널 및 인터페이스 형태** (설계 검토 확정 스키마):

  ```ts
  export type DiagramExportFormat = 'png' | 'svg'

  export interface DiagramSaveRequest {
    format: DiagramExportFormat
    suggestedName: string
    data: Uint8Array | string // format === 'png'일 때 Uint8Array, 'svg'일 때 UTF-8 문자열
  }

  export interface DiagramSaveResult {
    canceled: boolean
    filePath?: string
  }

  export interface WikiDiagramApi {
    copyImage(pngBytes: Uint8Array): Promise<void>
    copyText(text: string): Promise<void>
    saveFile(request: DiagramSaveRequest): Promise<DiagramSaveResult>
  }
  ```

- **Main 프로세스 실행 및 검증 규칙**:
  - `copyText(text)`: 비문자열 입력을 검증한 뒤 시스템 클립보드에 텍스트를 기록합니다.
  - `copyImage(pngBytes)`: 전달된 바이트 버퍼(`Uint8Array`)로부터 네이티브 이미지를 생성(`nativeImage.createFromBuffer`)하고, 버퍼가 비어 있거나 디코딩된 이미지가 비어 있으면(`isEmpty()`) 명시적 오류를 던져 빈 이미지가 클립보드에 들어가는 것을 막습니다.
  - `saveFile(request)`: 활성 창을 부모로 하여 Electron 네이티브 `다른 이름으로 저장` 대화상자(`showSaveDialog`)를 열고 포맷별 확장자 필터(`PNG` 또는 `SVG`)와 정제된 `suggestedName`을 기본 경로로 제안합니다. 사용자가 취소하면 디스크에 아무것도 쓰지 않고 `{ canceled: true }`를 반환하며, 경로를 선택하면 `png`는 바이너리 버퍼로, `svg`는 UTF-8 문자열로 저장한 뒤 `{ canceled: false, filePath }`를 반환합니다.
- **IPC 감사 로깅 메타데이터 정제**:
  - 다이어그램 IPC 호출을 기록할 때 원문 Mermaid 코드, 직렬화된 SVG 마크업, PNG 바이너리 배열이 로그나 버그 리포트에 포함되지 않도록 텍스트 길이, 바이트 길이, 포맷, 취소 여부 메타데이터만 추출해 기록합니다.

### 2. 단독 SVG 정규화 및 `2x` PNG 래스터화 변환 모듈 계약
- **단독 XML SVG 정규화**:
  - 렌더링·새니타이즈된 SVG 마크업에서 `viewBox`(부재 시 숫자형 `width`·`height`)를 파싱하여 논리 폭과 높이를 산출합니다.
  - 사방 `16px` 외곽 여백을 더한 새 `viewBox`(`minX - 16`, `minY - 16`, `width + 32`, `height + 32`)와 명시적 픽셀 `width`/`height`를 부여하고, 단독 뷰어에서 축소를 유발하는 반응형 `max-width` 인라인 스타일을 제거합니다.
  - 활성 테마의 표면 배경색(`light`: `#ffffff`, `dark`: `#161b22`)으로 채운 불투명 배경 `<rect>`를 SVG 최하단 레이어로 삽입합니다.
  - 루트 `<svg>` 및 `<foreignObject>` 내부 HTML 요소의 XML 네임스페이스를 보장한 뒤 유효한 XML 문자열로 직렬화합니다.
- **오프스크린 `2x` PNG 래스터화 및 안전 클램프**:
  - 정규화된 단독 SVG 문자열을 외부 네트워크 요청이 없는 `data:image/svg+xml;charset=utf-8,...` 데이터 URI로 인코딩해 디코딩함으로써 오프스크린 `<canvas>` 오염(Tainting)을 방지합니다.
  - 기본 배율은 `2x`로 적용하되, 래스터 결과의 한 변이 최대 `8192px`를 넘거나 총 픽셀 면적이 `67,108,864px`(`8192 × 8192`)를 초과하는 초대형 다이어그램에서는 종횡비를 유지한 채 배율을 안전 상한 내로 자동 축소하여 빈 캔버스나 메모리 할당 실패를 방지합니다.
  - JSDOM 등 비레이아웃 환경의 단위·통합 테스트에서도 전체 변환 흐름을 결정론적으로 검증할 수 있도록 이미지 디코딩·래스터 실행 단계를 교체 가능한 어댑터 심(Seam)으로 분리합니다.

### 3. 기본 파일명 정규화 및 문서 제목 맥락 전달
- **문서 편집기**는 활성 **문서 버퍼**에서 도출한 문서 제목을 `Preview`, `Split` 우측 미리보기, `위지윅` 컨텍스트를 통해 모든 **Mermaid 다이어그램 블록**에 전달합니다.
- 파일명 정규화 함수는 문서 제목에서 Windows 금지 문자(`[<>:"/\\|?*\x00-\x1f]`), 선행·후행 공백 및 마침표를 제거한 뒤 `<정규화된문서명>-diagram.<ext>`를 생성합니다. 문서 제목이 없거나 정제 후 빈 문자열이 되면 `mermaid-diagram.<ext>`로 폴백합니다.

### 4. 액션 바 상태 머신 및 활성화 불변식
- **버튼 순서 및 배치**:
  - 액션 버튼은 `이미지 복사` → `코드 복사` → `PNG 저장` → `SVG 저장` 순서로 일렬 배치합니다. `위지윅` **에디터 모드**의 블록 헤더에서는 기존 `코드 편집`/`코드 숨기기` 버튼의 바로 앞(또는 좌측 인접 영역)에 액션 버튼 그룹을 배치합니다.
- **활성화 불변식**:
  - `코드 복사`: 정규화된 원문 코드가 비어 있지 않으면(`code.trim().length > 0`) 렌더링 중이거나 문법 오류가 있는 상태에서도 활성화합니다.
  - `이미지 복사`, `PNG 저장`, `SVG 저장`: **현재 원문 코드와 활성 테마에 대해 유효한 최신 SVG가 확정되어 있고 문법 오류가 없을 때만** 활성화합니다. 초기 로딩 중, 디바운스 재렌더링 대기 중(이전 코드의 SVG만 남아 있는 상태), 문법 오류 상태(직전 정상 SVG가 화면에 유지 표시되는 상태 및 폴백 오류 박스 상태 모두 포함)에서는 비활성화합니다.
- **실행 · 피드백 · 오류 전이**:
  - 하나의 액션이 실행 중인 동안 중복 클릭을 차단합니다.
  - `copyText`, `copyImage`, 또는 `saveFile`이 취소 없이 완료(`canceled: false`)되면 해당 버튼이 `1500ms` 동안 체크(`✓`) 상태와 완료 안내(`복사됨` 또는 `저장됨`)로 전환된 뒤 자동 복귀합니다(언마운트 또는 후속 실행 시 이전 타이머를 안전하게 해제).
  - 파일 저장에서 사용자가 대화상자를 취소(`canceled: true`)하면 체크 전환이나 오류 표시 없이 즉시 대기 상태로 복귀합니다.
  - 래스터화·클립보드·파일 저장 중 예외가 발생하면 다이어그램 소스를 포함하지 않는 오류 로그를 남기고 블록 내부에 간결한 인라인 오류 알림(`role="alert"`)을 표시합니다.
- **가시성 규칙**:
  - `Preview` 및 `Split` 모드의 플로팅 액션 바는 마우스 호버, 키보드 포커스(`:focus-within`), 액션 실행 중, 또는 `1500ms` 완료 체크 표시 중일 때 가시 상태를 유지하며, 키보드 Tab 이동으로 언제든 접근할 수 있어야 합니다.

### 5. 도메인 용어집 동기화
- 도메인 용어집의 **Mermaid 다이어그램 블록** 정의에 PNG·SVG 파일 내보내기 및 클립보드(이미지·원문 코드) 복사 기능을 반영합니다.

## Testing Decisions (테스트 결정사항)

- **검증 기준**: 내부 구현 세부가 아니라 사용자가 접근 가능한 역할·이름·버튼 상태 및 공개 모듈 인터페이스에서 관찰 가능한 외부 동작을 검증합니다. 모든 테스트는 인메모리 하네스, 임시 디렉터리, 주입형 어댑터로 격리하여 실제 OS 클립보드나 사용자 파일에 영향을 주지 않습니다.
- **사전 합의된 테스트 심 (Pre-agreed Seams)**:
  1. **`<App />` 및 `<DocumentEditor />` 공개 UI 통합 심 (React Testing Library + 인메모리 `window.wikiApi` + 주입형 `MermaidRenderer` 및 래스터 어댑터)**
     - **Catches**: `Preview`·`Split` 플로팅 액션 바와 `위지윅` 상단 헤더 통합 배치(이중 툴바 부재), 4종 버튼 실행 및 페이로드 전달, `1500ms` 완료 피드백 및 저장 대화상자 취소 복귀, 활성 문서 제목 기반 기본 파일명 제안, 로딩·디바운스 대기·문법 오류(`lastValid` 유지 중 포함) 시 이미지 액션 비활성화 및 `코드 복사` 허용, 실패 시 블록 인라인 오류 알림 회귀.
     - **Misses**: 실제 Chromium 브라우저의 `<foreignObject>` 픽셀 래스터화 결과 및 Windows 네이티브 클립보드·저장 대화상자 창 동작.
  2. **다이어그램 내보내기 변환 모듈 심 (공개 SVG 정규화 · PNG 래스터화 · 파일명 생성 인터페이스 + 주입형 래스터 어댑터 / Vitest)**
     - **Catches**: `viewBox`/크기 추출 오류, `16px` 외곽 여백 확장 및 테마별 불투명 배경 `<rect>`(`#ffffff` / `#161b22`) 누락, `<foreignObject>` XML 네임스페이스 직렬화 결함, `2x` 배율 산출 및 최대 해상도 클램프 누락, Windows 금지 문자 파일명 정제 및 `mermaid-diagram` 폴백 오류.
     - **Misses**: 실제 GPU 캔버스 폰트 렌더링의 미세 픽셀 차이.
  3. **다이어그램 IPC 핸들러 & Preload 브리지 심 (가짜 `IpcMainLike` / `IpcRendererLike` + 주입형 클립보드 · 다이얼로그 · 파일 쓰기 어댑터 / Vitest)**
     - **Catches**: `copyText`, `copyImage`, `saveFile` IPC 채널 라우팅 및 브리지 인자 매핑 불일치, 빈/손상 PNG 버퍼 검증 누락, 저장 대화상자 취소 시 파일 쓰기 오동작, 포맷별 확장자 필터·기본 파일명 보정 누락, IPC 감사 로그에 원문 코드·SVG·PNG 바이트가 유출되는 회귀.
     - **Misses**: 실제 Electron `nativeImage` 네이티브 코덱 동작 및 Windows 파일 대화상자 UI 상호작용.
- *(위 심 목록은 사용자 승인 시 `/ticket-runner`의 사전 합의된 심(Pre-agreed Seams)으로 사용됩니다.)*
- **참고할 기존 테스트 패턴 (Prior Art)**:
  - `<App />` 통합 테스트의 인메모리 `window.wikiApi` 하네스 패턴
  - **Mermaid 다이어그램 블록** 테스트의 주입형 `MermaidDriver` 및 `vi.useFakeTimers()` 디바운스·오류 복구 검증 패턴
  - 가짜 `IpcMainLike` / `IpcRendererLike` 기반 IPC 및 Preload 브리지 단위 테스트 패턴

## Out of Scope (범위 제외 사항)

- PDF, JPEG, WebP 등 PNG·SVG 이외의 추가 이미지·문서 포맷 내보내기
- 내보내기 시 현재 앱 테마와 다른 테마로 강제 재렌더링하거나 투명 배경·배율(`1x`/`3x`)을 선택하는 **전역 설정 패널** 옵션 추가
- 문서 내 모든 **Mermaid 다이어그램 블록**을 한 번에 일괄 내보내기(Batch Export)하는 기능
- 다이어그램 확대/축소(Zoom/Pan) 또는 전체화면 모달 뷰어

## Further Notes (기타 참고사항)

- **로그 프라이버시 및 크기 보호**: IPC 감사 로그와 렌더러 오류 로그 모두 다이어그램 원문 코드, SVG 마크업, PNG 바이너리를 절대 기록하지 않고 길이·포맷·테마 같은 메타데이터만 남깁니다.
- **메모리 및 대형 다이어그램 보호**: 초대형 다이어그램 래스터화 시 최대 변(`8192px`) 및 총 면적(`67,108,864px`) 제한으로 배율을 안전하게 낮춰 메모리 초과나 캔버스 렌더링 실패를 예방합니다.
