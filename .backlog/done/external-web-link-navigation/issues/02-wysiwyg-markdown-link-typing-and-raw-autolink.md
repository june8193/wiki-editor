# 02 — 위지윅 [텍스트](URL) 타이핑 링크 변환, Raw 자동링크·맨 URL Ctrl+클릭 및 매뉴얼 갱신

**Spec:** [spec.md](../spec.md)

**What to build:** **위지윅** 모드에서 `[텍스트](URL)` 입력 후 닫는 `)`를 치는 즉시 안전한 링크 마크로 변환되도록 입력 규칙을 활성화하고(기존 **링크 자동완성 메뉴**·`Ctrl+K`·`#섹션` 링크·이미지·코드 영역과 비충돌), **Raw** 모드에서 `<https://...>` 자동링크와 맨 URL(`http://...`, `https://...`) 위에서의 `Ctrl+클릭` 외부 브라우저 열기를 지원하며, 사용자 매뉴얼(`docs/manual.md`)에 웹 링크 이동 안내를 반영합니다.

**Blocked by:** 01-external-http-url-shell-ipc-and-navigation

**Status:** resolved

- [x] **위지윅** 모드에서 `[텍스트](https://example.com)` 또는 `[텍스트](#섹션)` 입력 후 마지막 닫는 `)`를 타이핑하면 즉시 클릭 가능한 `<a>` 링크 마크로 변환되고 후속 타이핑에 링크 마크가 번지지 않으며(`inclusive: false`), 해당 링크 클릭 시 기본 브라우저 열기 또는 섹션 이동이 정상 동작한다.
- [x] **위지윅** 입력 규칙은 `isSafeMarkdownUrl`을 통과한 대상만 허용하여 `javascript:` 등 위험 스킴은 변환하지 않으며, 이미지 `![alt](...)`, 빈 라벨 `[]()`, 코드 블록, 인라인 코드 내부는 변환하지 않고 기존 **링크 자동완성 메뉴** 및 `Ctrl+K` 동작과 충돌하지 않는다.
- [x] **Raw** 모드 구문 스캐너가 기존 `[텍스트](href)` 외에 `<http://...>`/`<https://...>` 자동링크와 본문의 맨 `http://...`/`https://...` URL을 추출하며, 문장 끝 구두점(마침표·쉼표·닫는 괄호 등)은 제외하되 URL 내부의 균형 잡힌 괄호(`https://en.wikipedia.org/wiki/Foo_(bar)`)는 보존하고, 코드 펜스·인라인 코드·이미지 `![alt](https://...)` 내부는 무시한다.
- [x] **Raw** 모드에서 `<https://...>` 및 맨 `https://...` URL 위에서 `Ctrl+클릭`(`Cmd+클릭`) 시 `openExternalUrl`로 기본 브라우저가 열리고, 일반 클릭은 기존처럼 커서 이동만 수행한다.
- [x] 사용자 매뉴얼(`docs/manual.md`)의 단축키 표와 `마크다운 링크와 자동완성` 섹션에 일반 웹 링크(`http://`, `https://`) 기본 브라우저 이동 안내가 추가된다.
- [x] **위지윅** 입력 규칙·**Raw** 구문 스캐너 단위 테스트와 `<App />` 통합 테스트가 모두 통과하며, `npm run typecheck`, `npm test`, `npm run build`가 통과한다.
