# 05 — 워크스페이스 검색 결과 모드 유지 위치 이동 및 도메인 용어집 동기화

**Spec:** [spec.md](../spec.md)

**What to build:** **검색 뷰**의 본문 일치 줄을 클릭했을 때 활성 **편집기 영역**에 문서를 열거나 기존 탭을 활성화한 뒤, **현재 에디터 모드를 유지**하고 **문서 내 찾기 바**를 자동으로 띄우지 않은 상태에서 전 4개 **에디터 모드**(`Raw` · `Split` · `위지윅` · `Preview`) 각각의 일치 위치로 정확히 스크롤·임시 강조하는 교차 이동 흐름을 완성합니다. 이어서 `CONTEXT.md`에 신규 공식 도메인 용어를 등록하고 기존 용어 설명을 동기화합니다.

**Blocked by:** 02-activity-bar-search-view-and-results, 04-in-document-find-wysiwyg-and-preview

**Status:** resolved

- [x] **검색 뷰**에서 본문 일치 줄을 클릭하면 활성 **편집기 영역**에 해당 파일을 열거나 이미 열린 탭을 활성화하되, 해당 탭의 현재 **에디터 모드**를 변경하지 않고 **문서 내 찾기 바**도 자동으로 열지 않습니다.
- [x] `Raw` 및 `Split` 모드에서 점프 요청 시 정확한 `(lineNumber, columnStart, columnEnd)` 위치로 커서·선택을 이동하고 일치 구간을 임시 강조하며 뷰포트로 스크롤합니다(`Split` 우측 `Preview`도 해당 줄로 동기화 스크롤).
- [x] `위지윅` 및 `Preview` 모드에서 점프 요청 시 `data-source-line` 블록 범위와 문맥 텍스트 매칭으로 해당 일치 구간을 찾아 스크롤·임시 강조합니다.
- [x] `위지윅` 또는 `Preview` 모드에서 마크다운 문법 기호(`**`, `##`)나 링크 URL처럼 렌더링 화면에 직접 보이지 않는 원문만 일치한 경우, 오류나 무반응 없이 해당 원문 줄에 대응하는 가장 가까운 블록으로 안전하게 폴백 스크롤합니다.
- [x] 임시 강조는 다음 사용자 편집, **에디터 모드** 전환, 새 점프 요청 또는 탭 전환 시 자연스럽게 해제되며, 비동기 파일 열기 도중 다른 검색 결과를 연속 클릭하거나 워크스페이스를 전환하면 이전(stale) 점프 요청을 폐기합니다.
- [x] `CONTEXT.md`에 **검색 뷰 (Search View)**, **검색 패널 (Search Panel)**, **문서 내 찾기 바 (Find Bar)** 공식 도메인 용어를 추가하고, **액티비티 바**, **왼쪽 사이드바**, **에디터 헤더**, **문서 편집기**, **보조 창** 설명을 검색 기능에 맞게 갱신합니다.
- [x] `<App />` 통합 · 멀티윈도우 및 `<DocumentEditor />` 공개 UI 테스트 심이 전 4개 **에디터 모드**의 워크스페이스 검색 점프·폴백·경쟁 요청 폐기를 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
