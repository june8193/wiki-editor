# 02 — 왼쪽 사이드바 폴더 트리 상단으로 워크스페이스 전환기 통합

**Spec:** [spec.md](../spec.md)

**What to build:** 앱 헤더에 있던 워크스페이스 전환기(즐겨찾기·최근 워크스페이스 목록 팝오버)를 왼쪽 사이드바의 폴더 트리 상단 헤더로 이동·통합하여, 워크스페이스 이름 드롭다운과 즐겨찾기 추가/해제(`★`/`☆`) 버튼이 한곳에서 동작하게 하고 워크스페이스가 열리지 않은 초기 상태에서도 바로 즐겨찾기·최근 워크스페이스를 선택할 수 있게 합니다.

**Blocked by:** 01-drag-split-horizontal-and-vertical

**Status:** resolved

- [x] 앱 헤더에서 워크스페이스 전환기 드롭다운(`워크스페이스 전환` 버튼 및 `워크스페이스 목록` 팝오버)이 제거되고, 왼쪽 사이드바의 폴더 트리 상단 헤더로 이동합니다.
- [x] 열린 워크스페이스가 없는 초기 상태(`workspace === null`)에서도 폴더 트리 상단 헤더에 `워크스페이스 선택 ▾`(`aria-label="워크스페이스 전환"`) 드롭다운 버튼이 항상 표시되어, 앱 시작 직후 즐겨찾기 또는 최근 워크스페이스를 클릭해 바로 열 수 있습니다.
- [x] 워크스페이스가 열려 있을 때는 폴더 트리 상단 헤더의 드롭다운 버튼이 현재 워크스페이스 이름(`{workspace.name} ▾`)을 표시하고, 그 우측에 현재 워크스페이스 즐겨찾기 추가/해제(`★`/`☆`) 토글 버튼이 함께 배치되어 워크스페이스 이름이 중복 표시되지 않습니다.
- [x] 드롭다운 클릭 시 열리는 `워크스페이스 목록` 팝오버에서 기존과 동일하게 즐겨찾기 워크스페이스 전환, 개별 즐겨찾기 해제(`×`), 최근 워크스페이스 전환이 동작하며, 미저장 변경 사항이 있을 때 워크스페이스를 전환하면 저장 확인 다이얼로그가 표시됩니다.
- [x] 워크스페이스 전환기 팝오버가 왼쪽 사이드바 영역 안에서 잘리지 않고 정상적으로 표시되며, `<App />` 통합 테스트가 미열림/열림 상태에서의 사이드바 워크스페이스 전환 및 즐겨찾기 관리를 검증하며 모두 통과합니다.
