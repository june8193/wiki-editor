# 03 — 🔒 스냅샷 탭, 편집기 영역별 탐색 히스토리 및 Ctrl+클릭 정의 이동 구현

**Spec:** [spec.md](../spec.md)

**What to build:** 과거 커밋·Compare·Stash·Staged 시점 코드를 로컬 편집 파일과 시각적으로 분리해 표시하는 읽기 전용 **`🔒 <ref>` 스냅샷 탭**(Preview + Pin 재사용, 상단 읽기 전용 안내 띠, `[로컬 파일 열기]` 액션, **우측 사이드바** 심볼 **문서 목차** 연동), **편집기 영역**별 `←`/`→`(`Alt+←`/`Alt+→`·마우스 뒤로/앞으로) **탐색 히스토리**, 그리고 **Diff 뷰어**(삭제 `-` 줄 이전 Ref / 추가·문맥 줄 새 Ref 구분)·**스냅샷 뷰어**·일반 코드 `Raw` 탭에서의 `Ctrl+클릭`(`Cmd+클릭`) 정의 이동을 엔드투엔드로 구현합니다.

**Blocked by:** 01-code-raw-highlighting-and-symbol-outline, 02-git-snapshot-blob-and-symbol-search-ipc

**Status:** resolved

- [ ] **스냅샷 탭**이 **탭 바**에 `🔒 <ref>` 배지로 구분 표시되고 **스냅샷 뷰어** **에디터 헤더**에서 `저장`·모드 전환 버튼을 숨긴 채 상단 읽기 전용 안내 띠와 `[로컬 파일 열기]` 액션을 제공하며, Preview + Pin 규칙·Stash 삭제 시 자동 정리·`workspace-state.json` 미영속 계약을 준수한다.
- [ ] **Diff 뷰어**, **스냅샷 뷰어**, 비마크다운 코드 `Raw` 편집기에서 `Ctrl`(`Cmd`) 키를 누른 채 유효한 식별자 위에 마우스를 올리면 점선 밑줄과 포인터 커서가 표시되며, 주석·문자열·언어 키워드는 대상에서 제외된다.
- [ ] `Ctrl+클릭` 시 **Diff 뷰어**의 삭제(`old`) 줄은 이전 시점 Ref, 추가·문맥(`new`) 줄은 대상 시점 Ref 기준으로 해석해 Lezer 구문 트리 검증을 통과한 선언부를 우선순위(`현재 파일 → 현재 Diff 변경 파일 → 인접 경로 → 나머지`)로 좁힌 뒤, 단일 선언부는 즉시 점프하고 다중 선언 후보는 커서 근처 선택 팝오버를 표시한다.
- [ ] 점프 대상이 현재 **Diff 탭**의 변경 Hunk 내부 줄이면 **Diff 탭**으로 이동·강조하고, 그 외의 경우 워킹트리 시점은 일반 코드 `Raw` **에디터 모드** 탭으로, 과거/Compare/Stash/Staged 시점은 `🔒 <ref>` **스냅샷 탭**으로 연다.
- [ ] 각 **편집기 영역** 헤더 좌측의 `←`/`→` 버튼과 `Alt+←`/`Alt+→`·마우스 뒤로/앞으로 버튼으로 이전 탭·줄 위치까지 단계별 복귀·전진이 동작하며, 마크다운 문서의 기존 `Ctrl+클릭` 링크 이동은 100% 현행 유지된다.
