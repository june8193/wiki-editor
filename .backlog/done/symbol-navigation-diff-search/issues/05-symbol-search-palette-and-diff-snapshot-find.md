# 05 — Ctrl+T 심볼 검색 팔레트 및 Diff·스냅샷 탭 내 Ctrl+F 찾기 구현

**Spec:** [spec.md](../spec.md)

**What to build:** `Ctrl+T`(`Cmd+T`)로 현재 워크스페이스 또는 활성 **Diff 탭**·**스냅샷 탭**의 Git Ref 시점 전체 심볼 선언부를 온디맨드로 검색·점프하는 플로팅 **심볼 검색 팔레트**와, **Diff 탭**·**스냅샷 탭**에서 동작하는 `Ctrl+F`(`Cmd+F`) **문서 내 찾기 바**를 엔드투엔드로 구현합니다.

**Blocked by:** 03-snapshot-tab-history-and-ctrl-click-definition

**Status:** resolved

- [ ] `Ctrl+T`(`Cmd+T`) 단축키로 **심볼 검색 팔레트**를 여닫을 수 있으며, 열려 있는 동안 배경 에디터·전역 단축키를 억제하고 한글 IME 조합에 안전한 디바운스·`Enter` 즉시 검색 및 `↑`/`↓`/`Esc` 키보드 내비게이션을 지원한다.
- [ ] **심볼 검색 팔레트**가 활성 탭의 시점(일반 탭은 워킹트리, **Diff 탭**·**스냅샷 탭**은 해당 Git Ref)을 자동 반영하고 현재 Diff/Compare 변경 파일의 심볼을 상단에 우선 표시하며, 선택 시 시점 일치 이동과 **탐색 히스토리** 기록이 수행된다.
- [ ] **Diff 탭**(**좌우 비교**·**인라인** 및 가상 스크롤 활성 상태 포함)과 **스냅샷 탭**에서 `Ctrl+F`(`Cmd+F`)를 누르면 **문서 내 찾기 바**가 열리며 단일 줄 선택 텍스트가 있으면 검색어로 자동 채워진다.
- [ ] **Diff 뷰어** 및 **스냅샷 뷰어**의 **문서 내 찾기 바**가 대소문자 구분(`Aa`), 전체 단어(`ab`), 정규식(`.*`) 옵션을 지원하고 전체 일치 강조 및 `Enter`/`Shift+Enter` 순환 시 가상 스크롤 영역을 포함한 활성 일치 위치로 정확히 스크롤한다.
- [ ] `Esc`로 **문서 내 찾기 바**를 닫고 강조를 해제하며, **편집기 영역** 간 전환·탭 전환 시 기존 **문서 편집기** 찾기 바 상태와 일관되게 격리·유지된다.
