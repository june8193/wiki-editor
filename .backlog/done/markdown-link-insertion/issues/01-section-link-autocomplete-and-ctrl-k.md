# 01 — 현재 문서 섹션(#헤딩) 인라인 링크 자동완성 및 Ctrl+K 단축키

**Spec:** [spec.md](../spec.md)

**What to build:** 마크다운 문서의 **Raw** 및 **위지윅** 모드(본문과 표 셀 내부 포함)에서 `[텍스트](` 또는 빈 `[](`를 타이핑하거나 `Ctrl+K` 보조 단축키를 실행하면 커서 근처에 **링크 자동완성 메뉴** 팝업이 열리고, 현재 문서의 헤딩 후보를 추천·필터링하여 표준 마크다운 섹션 링크(`[표시텍스트](#슬러그)`)로 완성합니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 마크다운 문서의 **Raw** 및 **위지윅** 모드에서 `[텍스트](` 또는 빈 `[](` 입력 시 커서 좌표 근처에 접근 가능한 **링크 자동완성 메뉴**(`role="listbox"`, `aria-label="링크 자동완성"`)가 열리고, 비마크다운 문서(`config.json` 등), 이미지 구문(`![alt](`), 펜스 코드 블록 및 닫히지 않은 인라인 코드 내부에서는 열리지 않습니다.
- [x] 대괄호 라벨 내부에 완결된 인라인 코드가 포함된 `` [`심볼`]( `` 형태에서도 자동완성이 정상 열리며, 항목 선택 후에도 인라인 코드 서식이 보존된 링크(`` [`심볼`](#슬러그) ``)로 완성됩니다.
- [x] `(` 입력 직후 검색어가 비어 있을 때, `텍스트`가 입력된 `[텍스트](` 상태라면 제목·슬러그가 `텍스트`와 일치하는 헤딩이 목록 최상단에 우선 추천되고(나머지 헤딩도 문서 순서대로 아래에 유지), 빈 `[](` 상태라면 현재 문서의 헤딩들이 문서 등장 순서대로 표시됩니다.
- [x] `(` 뒤에 검색어(`#` 접두사 포함 또는 일반 문자열)를 타이핑하면 현재 문서 헤딩이 실시간 필터링되고, 공백·줄바꿈·`)` 또는 외부 스킴(`http:`, `https:`, `mailto:`) 입력 시 메뉴가 즉시 닫힙니다.
- [x] `ArrowDown`·`ArrowUp`으로 선택 이동, `Enter`·`Tab` 또는 마우스 클릭으로 링크 완성, `Escape` 또는 바깥 클릭으로 메뉴 닫기가 동작하며, **슬래시 명령어 메뉴**와 동시에 열리지 않습니다.
- [x] 항목 완성 시 `[텍스트](`는 사용자가 입력한 텍스트를 그대로 유지하고, 빈 `[](`는 선행 헤딩 번호(`1.1.` 등)가 제거된 헤딩 제목으로 `[]`를 자동 채우며(표 셀 내부에서 제목에 `|`가 포함된 경우 `\|` 이스케이프), 슬러그는 기존 **문서 목차**·**Preview**와 동일한 규칙으로 생성됩니다(**Raw**에서 맞닿은 닫는 `)` 중복 방지, **위지윅**에서 완성 직후 커서가 링크 마크 바깥 끝에 위치).
- [x] `Ctrl+K`(macOS `Meta+K`) 입력 시: 단일 줄 텍스트 선택 상태면 `[선택텍스트](`로 감싸고 메뉴를 즉시 열며, 빈 커서면 `[](`를 삽입하고 메뉴를 엽니다(**위지윅**에서 커서가 기존 링크 내부에 있으면 `[기존텍스트](`로 풀어 재선택 가능, **전역 설정 패널**·**확인 다이얼로그** 열림 시 비활성).
- [x] 순수 도메인 단위 테스트와 `<App />` 통합 테스트(**Raw**·**위지윅** 본문 및 요약표 셀 시나리오 포함)가 추가되고, `CONTEXT.md`에 **링크 자동완성 메뉴** 용어가 정의됩니다.
- [x] `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
