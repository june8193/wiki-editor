# Spec: 마크다운 섹션·파일 링크 인라인 자동완성 및 클릭 이동

## Problem Statement (문제 정의)

코드 분석 문서처럼 상단에 함수·구조체·변수 요약표를 두고 하단에 상세 명세 헤딩(`### Function: parse_header`, `### Struct: PacketCtx` 등)을 작성하거나 여러 마크다운 문서로 모듈 설명을 나누어 관리할 때, 현재 Wiki Editor에서 특정 섹션이나 파일로 향하는 링크를 연결하고 따라가기 어렵습니다.

- **개별 링크 삽입 도우미 부재**: 문서 전체 목차를 한꺼번에 생성하는 `/toc` 외에는 특정 헤딩이나 마크다운 파일을 검색·선택해 링크를 완성하는 수단이 없습니다. 사용자는 헤딩의 GitHub 스타일 슬러그 변환 규칙(대소문자, 공백→`-`, 특수문자 제거, 중복 접미사 `-1` 등)이나 파일 간 상대 경로(`../`)를 직접 계산해 타이핑해야 하므로 오타가 발생하기 쉽습니다.
- **위지윅 모드 링크 편집 수단 부재**: **위지윅** 모드에는 새로운 링크를 걸거나 기존 링크 대상을 바꿀 수 있는 입력 흐름이나 단축키가 없어 **Raw** 모드로 전환해 원문을 직접 수정해야 합니다.
- **불완전한 링크 클릭 이동(네비게이션)**: **Preview** 모드에서 같은 문서 내 `#섹션` 앵커 스크롤만 동작할 뿐, 다른 마크다운 파일 상대 경로 링크(`./types.md`)는 클릭해도 열리지 않으며, **Raw**·**위지윅** 편집 모드에서는 `Ctrl+클릭`으로 요약표에서 상세 명세 섹션이나 다른 문서로 바로 점프할 수 없습니다.

## Solution (해결 방안)

표준 마크다운 링크 문법(`[표시텍스트](#슬러그)`, `[표시텍스트](./상대경로.md)`)을 기반으로, 별도의 툴바 버튼 추가 없이 자연스러운 타이핑 흐름과 `Ctrl+K` 보조 단축키로 동작하는 **링크 자동완성 메뉴** 및 3가지 **에디터 모드** 전반의 링크 클릭 이동을 제공합니다.

1. **`[텍스트](` · `[](` 인라인 타이핑 자동완성 (Raw · 위지윅 공통)**:
   - 마크다운 본문 및 표 셀 내부에서 `[텍스트](` 또는 빈 `[](`를 입력하는 즉시 커서 근처에 **링크 자동완성 메뉴** 팝업을 표시합니다.
   - 후보 목록은 **현재 문서 내 섹션(`#헤딩`)**과 **워크스페이스 내 다른 마크다운 파일(`.md`, `.markdown`)**을 지원합니다(타 파일 내부 섹션 선택은 제외).
   - `[텍스트](` 입력 직후에는 `텍스트`와 이름이 일치하는 섹션·파일을 목록 최상단에 우선 추천하여 바로 `Enter`로 연결할 수 있게 하고, 빈 `[](`에서 선택하면 섹션은 번호를 뺀 헤딩 제목, 파일은 확장자를 뺀 파일 이름으로 `[]`까지 자동 채웁니다.
2. **`Ctrl+K` 보조 단축키**:
   - 이미 작성해 둔 단어(예: 요약표의 함수명)를 선택하고 `Ctrl+K`를 누르면 `[선택텍스트](`로 감싸며 즉시 **링크 자동완성 메뉴**를 띄우고, 빈 커서에서 누르면 `[](`를 삽입해 동일한 메뉴를 띄웁니다(**위지윅**의 기존 링크 위에서 누르면 재선택 가능하도록 풀어줌).
3. **모드별 링크 클릭 이동 및 깨진 링크 안내**:
   - **Preview** 모드에서는 일반 클릭으로, **Raw**·**위지윅** 모드에서는 `Ctrl+클릭`(`Cmd+클릭`)으로 같은 문서 `#섹션` 스크롤 및 다른 마크다운 파일 탭 열기를 지원합니다.
   - 대상 `#섹션`이나 파일이 존재하지 않으면 새 파일을 만들지 않고 상단 **오류 배너**로 안내합니다.

## User Stories (사용자 스토리)

1. As a 코드 분석 문서 작성자, I want **Raw** 또는 **위지윅** 모드의 본문과 요약표 셀 안에서 `[함수명](`을 입력했을 때 현재 문서의 헤딩과 다른 마크다운 파일 후보가 커서 아래 팝업으로 표시되기를 원하며, so that 슬러그 규칙이나 상대 경로를 외우지 않고도 상세 명세 섹션과 문서를 즉시 연결할 수 있습니다.
2. As a 코드 분석 문서 작성자, I want `[함수명](`을 입력한 직후 `함수명`과 일치하는 섹션이나 파일이 목록 맨 위에 우선 추천되기를 원하며, so that 추가 검색어를 치지 않고 `Enter` 한 번으로 요약표 항목 연결을 끝낼 수 있습니다.
3. As a 코드 분석 문서 작성자, I want 빈 대괄호 `[](`를 입력하고 후보를 고르면 섹션은 헤딩 번호(`1.1.` 등)만 제외한 제목으로, 파일은 확장자(`.md`)를 제외한 파일 이름으로 `[]` 표시 텍스트까지 자동 완성되기를 원하며, so that 같은 이름을 두 번 타이핑하지 않아도 됩니다.
4. As a 코드 분석 문서 작성자, I want `` [`parse_header`]( ``처럼 인라인 코드 서식이 포함된 표시 텍스트로도 링크 자동완성이 동작하고 완성 후에도 인라인 코드 서식이 유지되기를 원하며, so that 코드 심볼 표기를 일관되게 유지할 수 있습니다.
5. As a 위키 작성자, I want `(` 뒤에 `#`을 치면 현재 문서 섹션만, `./` 또는 `../`를 치면 다른 마크다운 파일만, 일반 검색어를 치면 섹션과 파일을 통합 필터링하고 `https://` 같은 외부 URL이나 공백·`)`을 치면 팝업이 자동으로 닫히기를 원하며, so that 원하는 대상을 빠르게 좁히고 외부 웹 링크 작성도 방해받지 않습니다.
6. As a 위키 작성자, I want 이미 적어둔 텍스트를 선택하고 `Ctrl+K`를 누르면 `[선택텍스트](`로 감싸지며 **링크 자동완성 메뉴**가 열리고, 빈 커서에서 `Ctrl+K`를 누르면 `[](`가 삽입되며 메뉴가 열리기를 원하며(위지윅의 기존 링크 위에서는 기존 링크를 풀어 재선택), so that 먼저 작성해 둔 요약표 단어들에도 빠르게 링크를 입히거나 수정할 수 있습니다.
7. As a 위키 작성자, I want 왼쪽 사이드바 **폴더 트리**에서 하위 폴더를 펼쳐 두지 않은 상태에서도 워크스페이스 내 모든 하위 폴더의 마크다운 파일이 자동완성 후보에 나타나기를 원하며, so that 깊은 경로의 문서도 바로 검색해 상대 경로로 연결할 수 있습니다.
8. As a 위키 독자 및 작성자, I want **Preview** 모드에서는 링크를 일반 클릭하고 **Raw**·**위지윅** 모드에서는 `Ctrl+클릭`했을 때 같은 문서 `#섹션`이면 해당 헤딩 위치로 스크롤되고 다른 마크다운 파일이면 현재 **편집기 영역**에 탭으로 열리기를 원하며, so that 편집 흐름을 끊지 않고 요약표와 상세 명세·연관 문서를 오갈 수 있습니다.
9. As a 위키 독자 및 작성자, I want 삭제되었거나 존재하지 않는 파일 또는 없는 `#섹션` 링크를 클릭했을 때 빈 파일이 임의로 생성되지 않고 상단 **오류 배너**로 대상을 찾을 수 없다는 안내를 받기를 원하며, so that 깨진 링크를 명확히 인지하고 의도치 않은 파일 생성을 방지할 수 있습니다.

## Implementation Decisions (구현 결정사항)

### 1. 핵심 데이터 모델 및 쿼리 계약

설계 검토를 통해 확정된 링크 자동완성 쿼리 및 후보 데이터 형태는 다음과 같습니다.

```ts
export interface LinkQueryMatch {
  label: string        // '[' 와 '](' 사이의 원문 라벨 (빈 '[]( ' 이면 '')
  query: string        // '](' 뒤부터 커서까지의 검색 문자열
  rangeFrom: number    // '[' 시작 오프셋 (에디터 좌표계 기준)
  rangeTo: number      // 현재 커서 오프셋 (또는 맞닿은 닫는 ')' 포함 치환 끝 오프셋)
}

export type LinkCandidate =
  | {
      kind: 'heading'
      slug: string          // Preview·목차와 동일한 고유 슬러그 (예: "function-parse_header")
      title: string         // 선행 번호('1.1.' 등) 및 인라인 문법이 제거된 제목
      number: string        // 계층 번호 문자열 (예: "1.1.")
      level: 1 | 2 | 3 | 4 | 5 | 6
      line: number          // 1-based 줄 번호
    }
  | {
      kind: 'file'
      path: string          // 워크스페이스 내 파일 절대 경로
      relativePath: string  // 워크스페이스 루트 기준 POSIX 상대 경로 (팝업 보조 경로 표시용)
      href: string          // 현재 활성 문서 기준 마크다운 상대 경로 (예: "./types.md", "../net/a%20b.md")
      displayName: string   // 마크다운 확장자(.md, .markdown)를 제외한 파일 이름
    }
```

### 2. 트리거 감지 및 상호 배제 불변식
- **마크다운 문서 한정**: 마크다운 문서에서만 **링크 자동완성 메뉴**와 `Ctrl+K` 단축키를 활성화합니다(`config.json` 등 비마크다운 **문서 버퍼**에서는 비활성).
- **유효 트리거 조건**: 커서와 같은 줄 앞쪽에서 닫히지 않은 `[라벨](쿼리` 패턴을 감지합니다.
  - 이미지 문법 `![alt](`(`[` 바로 앞 문자가 `!`), 펜스 코드 블록 내부, 닫히지 않은 인라인 코드 백틱 내부는 감지에서 제외합니다.
  - 단, 대괄호 라벨 내부에 완결된 인라인 코드가 포함된 `` [`심볼`]( `` 형태는 유효한 라벨로 허용하며 완성 후에도 인라인 코드 서식을 유지합니다.
  - 같은 줄에 여러 대괄호가 있을 때는 이스케이프되지 않은 가장 안쪽의 유효한 `[라벨](` 쌍을 기준으로 매칭합니다.
- **자동 닫힘 조건**: `쿼리`에 공백 문자, 줄바꿈, 닫는 `)`가 포함되거나 외부 스킴(`http:`, `https:`, `mailto:`, 대소문자 무관)이 입력되면 즉시 메뉴를 닫습니다. 커서 이동으로 선택 영역이 생기거나 `[라벨](쿼리` 범위를 벗어나도 닫습니다.
- **팝업 상호 배제 및 조작**: **슬래시 명령어 메뉴**와 **링크 자동완성 메뉴**는 동시에 열리지 않으며, 커서 좌표 기반 플로팅 배치 유틸리티를 공유합니다. 키보드 조작(`ArrowDown`, `ArrowUp`, `Enter`, `Tab`, `Escape`) 및 마우스 호버·클릭 선택 규칙은 **슬래시 명령어 메뉴**와 일관되게 동작합니다.

### 3. `Ctrl+K` 보조 단축키 전이 규칙
- **전역 설정 패널**이나 **확인 다이얼로그**가 열려 단축키가 비활성화된 상태에서는 동작하지 않습니다.
- **Raw** 및 **위지윅** 모드에서 `Ctrl+K`(macOS `Meta+K`) 입력 시:
  - **단일 줄 텍스트 선택 상태**: 선택된 범위를 `[선택텍스트](`로 감싸고 커서를 `(` 바로 뒤에 위치시킨 뒤 즉시 **링크 자동완성 메뉴**를 엽니다(위지윅에서 인라인 코드 마크가 적용된 텍스트를 선택한 경우 인라인 코드 표현을 보존). 줄바꿈이 포함된 다중 줄 선택이나 코드 블록 내부에서는 무동작으로 안전하게 무시합니다.
  - **빈 커서 상태**:
    - **위지윅** 모드에서 커서가 기존 링크 마크 내부에 놓여 있으면 해당 링크 마크 전체 범위를 `[기존표시텍스트](` 일반 텍스트로 풀어 커서를 `(` 바로 뒤에 두고 메뉴를 열어 대상을 재선택할 수 있게 합니다(단일 트랜잭션 처리로 실행 취소 1회에 복원).
    - 그 외 일반 빈 커서에서는 `[](`를 삽입하고 커서를 `(` 바로 뒤에 두어 즉시 메뉴를 엽니다.

### 4. 후보 수집, 추천 정렬 및 완성 규칙
- **섹션 슬러그 일관성**: 현재 문서의 헤딩 파싱 및 슬러그 생성은 기존 **문서 목차** 및 **Preview** 렌더링이 사용하는 동일한 헤딩 파서·슬러그 생성기를 그대로 재사용하여 100% 일치시킵니다.
- **워크스페이스 전체 마크다운 파일 인덱싱**:
  - 워크스페이스 파일시스템 계층에 열린 워크스페이스를 재귀 순회하여 `.md`, `.markdown`(대소문자 무관) 파일 엔트리 목록만 반환하는 인터페이스를 추가합니다.
  - 기존 경로 보안 정책과 동일하게 `.git`, `node_modules` 등 시스템 예약 폴더와 워크스페이스 루트 밖을 가리키거나 깨진 심볼릭 링크는 제외합니다.
  - 렌더러는 워크스페이스 열기, 파일 생성·이름 변경·삭제, 외부 파일 변경 감시 이벤트 시 마크다운 파일 목록을 동기화하며, 후보 생성 시 현재 활성 문서 자신은 제외합니다.
- **정렬 및 필터링**:
  - `쿼리`가 비어 있을 때(`(` 입력 직후): `라벨`이 비어 있지 않으면(백틱 등 인라인 기호 제거 후 대소문자 무시 비교) 제목·슬러그·파일명이 `라벨`과 일치(정확 일치 → 접두사 일치 → 부분 포함)하는 후보들을 최상단에 우선 배치하고, 나머지 후보들도 그 아래(현재 문서 섹션 문서 등장 순서 → 다른 파일 상대 경로 알파벳 순)에 유지합니다. `라벨`이 비어 있는 `[](` 상태이면 현재 문서 섹션(문서 등장 순서) → 다른 파일(상대 경로 순) 순서로 표시합니다.
  - `쿼리`가 있을 때: `#`으로 시작하면 `#` 뒤 문자열로 `heading` 후보만, `./` 또는 `../`로 시작하면 경로 검색어로 `file` 후보만, 그 외 일반 검색어는 `heading`과 `file`을 통합 필터링(정확 일치 → 접두사 일치 → 부분 포함, 동률 시 `heading` 우선)합니다. 결과가 비면 메뉴를 닫습니다.
- **표시 텍스트 및 상대 경로 포맷**:
  - 직접 입력한 `라벨`이 있으면 그대로 유지하고, 빈 `[](`이면 `heading`은 선행 번호가 제거된 `title`, `file`은 확장자가 제거된 `displayName`으로 채웁니다. 표 셀 내부에서 자동 채움 텍스트에 `|` 문자가 포함된 경우 표 열 구분이 깨지지 않도록 `\|`로 이스케이프합니다.
  - 다른 파일 `href`는 현재 활성 문서의 상위 폴더 기준 POSIX 슬래시(`/`) 상대 경로로 계산하되, 같은 폴더 파일은 `./파일명.md`, 상위·타 폴더 파일은 `../폴더/파일명.md` 형태를 사용하며 공백·괄호(`(`, `)`) 등 마크다운 링크 파싱을 깨뜨리는 문자는 경로 세그먼트 단위로 퍼센트 인코딩합니다.
  - **Raw** 모드에서는 `[라벨](쿼리`(커서 직후 맞닿은 `)`가 있으면 함께 소비)를 `[표시텍스트](href)`로 치환 후 커서를 닫는 `)` 뒤에 두고, **위지윅** 모드에서는 실제 링크 마크 노드로 단일 트랜잭션 치환 후 커서를 링크 마크 바깥 끝에 두어 후속 타이핑에 링크 서식이 번지지 않게 합니다.

### 5. 링크 클릭 이동(네비게이션) 및 오류 처리 계약
- **모드별 클릭 트리거**:
  - **Preview** 모드: 링크 일반 클릭 시 이동합니다.
  - **Raw** 및 **위지윅** 모드: 링크 위에서 `Ctrl+클릭`(macOS `Meta+클릭`) 시에만 이동하며, 일반 클릭은 기존 텍스트 편집 커서 이동을 유지합니다(Electron 기본 창 이동은 항상 차단).
- **이동 및 예외 처리**:
  - 외부 스킴(`http:`, `https:`, `mailto:`)은 앱 내 문서 이동 대상이 아니므로 무시합니다.
  - **같은 문서 `#슬러그`**: 퍼센트 디코딩한 슬러그에 대응하는 현재 문서 헤딩을 찾아 클릭이 일어난 **편집기 영역**의 현재 **에디터 모드**(Raw 줄 이동 / 위지윅 헤딩 스크롤 / Preview 앵커 스크롤)로 스크롤합니다. 일치하는 헤딩이 없으면 상단 **오류 배너**로 안내합니다.
  - **상대 경로 마크다운 파일**(`./파일.md`, `../폴더/파일.md`, 수동 작성된 `./파일.md#슬러그` 포함): 현재 문서 경로 기준으로 대상 경로를 해석(퍼센트 디코딩 포함)합니다. 워크스페이스 루트 밖 경로이거나 대상 파일이 존재하지 않으면 **새 파일을 생성하지 않고** 상단 **오류 배너**로 안내합니다. 대상 파일이 존재하면 클릭이 발생한 **편집기 영역**에서 해당 파일 탭을 열거나 이미 열린 탭을 활성화합니다(`#슬러그`가 함께 지정된 경우 열린 탭에서 해당 헤딩으로 스크롤하며, 파일 내 해당 헤딩이 없으면 파일은 연 채 **오류 배너**로 섹션 부재를 안내).

### 6. 도메인 용어 동기화 (`CONTEXT.md`)
- `CONTEXT.md`의 **문서 편집기 및 에디터 모드** 섹션에 **링크 자동완성 메뉴 (Link Autocomplete Menu)** 용어 정의와 피해야 할 동의어(_Avoid_: 링크 팔레트, 위키링크 드롭다운, URL 모달)를 추가합니다.

## Testing Decisions (테스트 결정사항)

- **검증 기준**: 구현 세부사항이 아닌 접근 가능한 역할·이름(`role="listbox"`, `role="option"`, `role="alert"` 등)과 에디터 입출력·탭 전환·스크롤 요청 등 사용자가 관찰하는 외부 동작을 기준으로 **TDD(Red → Green → Refactor)** 절차에 따라 검증합니다. 모든 테스트는 임시 디렉토리 또는 인메모리 하네스에서 격리 실행합니다.
- **사전 합의된 테스트 심 (Pre-agreed Seams)**:
  1. **`<App />` 통합 테스트 심 (인메모리 `createInMemoryWikiApi` 하네스 + React Testing Library)**: Catches **Raw**·**위지윅** 모드(본문 및 표 내부)에서 `[텍스트](`·`[](` 타이핑 및 `Ctrl+K`를 통한 **링크 자동완성 메뉴** 오픈·추천 정렬·키보드/마우스 완성, 접힌 하위 폴더의 마크다운 파일 상대 경로 연결, **Preview** 일반 클릭 및 **Raw**·**위지윅** `Ctrl+클릭`을 통한 섹션 스크롤·다른 마크다운 파일 탭 열기(분할된 **편집기 영역** 포함), 없는 파일·없는 `#섹션` 클릭 시 파일 미생성 및 **오류 배너** 표시 등 E2E 회귀 / Misses 실제 OS 파일시스템의 재귀 디렉토리 탐색·심볼릭 링크 보안 필터링 및 실제 Electron IPC 프로세스 간 직렬화.
  2. **워크스페이스 파일시스템 & Preload IPC 경계 심 (`WorkspaceFsService` 임시 디렉토리 통합 테스트 + `createWikiApi` 단위 테스트)**: Catches 중첩 하위 폴더의 `.md`·`.markdown` 재귀 수집 누락, 비마크다운 파일 혼입, `.git`·`node_modules` 등 시스템 예약 폴더 및 워크스페이스 외부 심볼릭 링크 유출, Preload 브리지 채널 바인딩 불일치 / Misses 렌더러 에디터 팝업 UI 및 클릭 이벤트 처리.
  3. **마크다운 링크 쿼리·후보 정렬·상대 경로 해석 순수 도메인 심 (Vitest 단위 테스트)**: Catches 코드 펜스·인라인 코드·이미지(`![alt](`) 오탐, `` [`심볼`]( `` 인라인 코드 라벨 파싱 실패, `[텍스트]` 일치 후보 최상단 추천 및 `#`·`./`·`../` 접두사 필터링 오류, 공백·괄호 포함 파일명의 상대 경로 인코딩·디코딩 오류, CRLF 줄바꿈 문서의 오프셋 계산 오류 / Misses CodeMirror·TipTap 뷰 트랜잭션 디스패치 및 실제 DOM 스크롤 반영.
- *(위 심 목록은 `/ticket-runner`의 사전 합의된 심(Pre-agreed Seams)으로 사용됩니다.)*

## Out of Scope (범위 제외 사항)

- 다른 마크다운 파일 내부의 특정 섹션(`파일.md#섹션`) 후보까지 자동완성 팝업에서 미리 파싱·선택하는 기능 (단, 수동으로 작성된 `파일.md#섹션` 링크의 클릭 이동은 지원)
- 비표준 위키링크 문법(`[[문서명]]`, `[[#섹션|별칭]]`) 파싱·렌더링 지원
- **서식 툴바**, **표 편집 툴바**, 또는 **문서 목차** 패널에 별도의 링크 삽입/복사 버튼을 추가하는 작업
- 없는 파일 링크 클릭 시 새 파일을 생성하는 확인 다이얼로그 제공
- 파일이나 헤딩 이름 변경 시 다른 문서 본문 내 기존 마크다운 링크 경로·슬러그를 일괄 자동 리팩토링(Backlink 업데이트)하는 기능
- `http://`, `https://` 외부 웹 링크를 OS 기본 브라우저로 여는 동작 변경

## Further Notes (기타 참고사항)

- **대규모 워크스페이스 성능**: 마크다운 파일 목록 인덱싱은 파일 본문을 읽지 않고 디렉토리 엔트리 메타데이터만 비동기로 순회하며, 시스템 폴더(`.git`, `node_modules` 등)를 조기에 건너뛰어 메인 이벤트 루프와 타이핑 반응성을 저해하지 않아야 합니다.
- **경로 보안 유지**: 링크 클릭으로 상대 경로 파일을 열 때도 기존 워크스페이스 경로 검증을 그대로 거치므로 `../../outside.md` 같은 루트 외부 경로 접근은 항상 차단되고 **오류 배너**로 안전하게 처리됩니다.
