# 04 — 메인 창·보조 창 공유 세션 모듈 추출 및 창 호스트 어댑터 전환

**Spec:** [spec.md](../spec.md)

**What to build:** Electron 창 핸들과 결합되어 있던 멀티 윈도우 세션 규칙(**메인 창**·**보조 창** 세션 생성/폐기, 중복 워크스페이스 창 복원·포커스, 닫기 게이트·clean flush 타이머, **보조 창** 0탭 자동 닫기·연쇄 닫기, 세션별 탭 드래그 격리)을 창 호스트 **심(seam)** 위의 `@shared` 깊은 **모듈**로 추출하고, Electron **어댑터**·인메모리 테스트 **어댑터** 전환과 함께 하네스 450줄 중복·미사용 `activateOrOpen` 채널·IPC 단독 세션 폴백 분기를 제거합니다.

**Blocked by:** 01-shared-workspace-query-and-schema-module

**Status:** resolved

- [ ] `@shared` 멀티 윈도우 세션 **모듈**이 좁은 창 호스트 **심(seam)**(창 생성·포커스/복원·닫기·bounds 조회·닫기 요청 전달·수명주기 이벤트) 뒤에서 세션 생성/폐기, `pendingInitialWorkspacePath`/`pendingOpenWorkspacePath`/`activeRoot` 기반 중복 워크스페이스 창 탐색·포커스, **보조 창** pending transfer 등록·0탭 자동 닫기·**메인 창** 닫힘 시 연쇄 닫기, 닫기 게이트·clean flush 타임아웃 상태 머신, 세션 내부/타 세션 간 탭 드래그 격리를 단일 구현으로 소유합니다.
- [ ] 메인 프로세스 창 매니저가 브라우저 창 생성·URL/파일 로드·입력 이벤트 전달만 담당하는 Electron 호스트 **어댑터**로 축소되고, 인메모리 테스트 하네스가 가상 창 핸들 **어댑터**를 통해 동일한 `@shared` 세션 **모듈**을 실행하면서 기존 약 450줄의 병렬 세션/창 구현을 삭제합니다.
- [ ] **보조 창** 0탭 자동 닫기의 단일 권위를 공유 세션 **모듈**의 `syncWindowTabs` 전이 처리에 두어 **보조 창** 셸에 중복 존재하던 탭 수 감시 닫기 효과를 제거하며, 탭 닫기와 창 밖 탭 드래그 아웃 모두에서 **보조 창**이 정확히 자동 닫힙니다.
- [ ] 렌더러와 하네스에서 미사용 중인 `activateOrOpen` IPC 채널을 공유·프리로드·메인 전반에서 제거하고, 워크스페이스·**문서 버퍼**·프론트매터 IPC 레지스트라가 항상 세션 소스 **인터페이스**를 균일하게 받도록 단순화해 단독 세션 폴백 서비스 생성 분기를 삭제합니다(관련 IPC 단위 테스트도 경량 세션 소스 **어댑터**로 전환).
- [ ] `@shared` 세션 **모듈** **인터페이스** 테스트·메인 IPC/프리로드 계약 테스트·`<App />` 멀티윈도우 통합 테스트가 모두 통과하고, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
