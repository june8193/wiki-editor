# 03 — 메인 창 워크스페이스 열기·복원·영속화 수명주기 모듈 통합

**Spec:** [spec.md](../spec.md)

**What to build:** **메인 창**의 시작 초기화(`getInitContext` 단일화)·중복 **메인 창** 포커스 확인·미저장 **문서 버퍼** 전환 가드·**문서 버퍼** 초기화·**폴더 트리**/편집기 영역 레이아웃 복원·`workspace-state.json` 디바운스/flush 영속화를 하나의 깊은 워크스페이스 수명주기 **모듈**로 통합하고, **폴더 트리** **모듈**에서 영속화 읽기를 분리하며 **메인 창** 셸의 12개 동기화 ref를 제거합니다.

**Blocked by:** 02-deepen-git-session-and-panel-module

**Status:** resolved

- [ ] 단일 깊은 **메인 창** 워크스페이스 수명주기 **모듈**이 창 초기화 컨텍스트(`getInitContext`를 앱 시작당 단일 진입으로 통합)와 초기 `config.json` 최근 워크스페이스 조인, 중복 **메인 창** 포커스 단축 분기, 공용 미저장 **문서 버퍼** 확인 가드(티켓 02에서 정돈된 공용 헬퍼 활용), 전환 시 기존 **문서 버퍼** 정리, **폴더 트리**·**편집기 영역** 레이아웃 복원, 창 닫기 전 즉시 flush를 통합 소유합니다.
- [ ] `workspace-state.json` 영속화의 일시 중지·재개 상태 머신(`suspendAndFlush`, 복원 완료 시 `markRestored`, 워크스페이스 열기 실패 시 이전 루트로 `resumeForWorkspace` 롤백)이 수명주기 **모듈** 내부 구현으로 캡슐화되어 외부 호출자에게 노출되지 않습니다.
- [ ] **폴더 트리** **모듈**에서 `workspace-state.json` 조회 책임을 제거해 디렉터리 트리 상태·다중 선택·파일/폴더 CRUD·파일 감시 갱신만 담당하는 순수 트리 **모듈**로 단순화합니다.
- [ ] **메인 창** 셸이 시작/전환/복원 순서를 맞추기 위해 유지하던 약 12개의 mutable ref와 조정 글루를 제거하고 수명주기 **모듈**의 좁은 **인터페이스**만 소비하며, **보조 창** 셸도 불필요한 중복 초기화 호출 없이 동작합니다.
- [ ] 새 수명주기 **모듈** **인터페이스** 테스트에서 시작 복원 경합·중복 창 포커스·전환 실패 시 영속화 롤백·창 닫기 전 flush 불변식이 검증되고, 기존 `<App />` 워크스페이스·영속화·멀티윈도우 통합 테스트 및 `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
