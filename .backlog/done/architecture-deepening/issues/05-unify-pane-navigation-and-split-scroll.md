# 05 — 편집기 영역 점프·문서 내 찾기 바·문서 목차 스크롤 통합 및 죽은 코드 정리

**Spec:** [spec.md](../spec.md)

**What to build:** 탭 저장소 전이 이벤트에 구독해 **검색 패널** 점프와 **문서 목차** 스크롤 요청을 한곳에서 자동 무효화하는 **편집기 영역** 내비게이션 **모듈**을 도입하여 4중 `onChangeContent` 콜백 체이닝·6곳 수동 무효화·이중 점프 상태 머신을 제거하고, `Split` **에디터 모드**의 **문서 목차** 스크롤을 `Raw` 단일 드라이버로 통일하며 **편집 공간**의 미사용 리사이즈 코드를 정리합니다.

**Blocked by:** 03-collapse-main-window-workspace-lifecycle

**Status:** resolved

- [ ] **편집기 영역** 단위의 단일 임시 내비게이션 **모듈**이 탭 저장소의 전이 이벤트(`tab-opened`, `tab-switched`, `editor-mode-changed`, `tab-closed`)와 **문서 버퍼** 본문 편집을 직접 구독하여 대기 중인 **검색 패널** 점프와 **문서 목차** 스크롤 요청을 한곳에서 자동 무효화합니다.
- [ ] 중복되어 있던 두 개의 검색 점프 상태 머신(워크스페이스 점프 훅 + 문서 내 점프 훅)을 하나로 통합하고, 4단계에 걸친 `onChangeContent` 콜백 재래핑과 **메인 창** 셸 6곳의 수동 점프 무효화 호출을 제거하며, 52개 속성을 평탄하게 재노출하던 얕은 편집기 워크스페이스 훅의 통과 표면(미사용 더미 액션 포함)을 축소합니다.
- [ ] **문서 목차** 상태와 스크롤 스파이 조정을 응집하고, `Split` **에디터 모드**에서 **문서 목차** 헤딩 클릭 시 **검색 패널** 점프와 동일하게 `Raw` 편집기만 직접 스크롤하여 미리보기가 줄 동기화로 따라오도록 통일함으로써 양쪽 동시 스크롤 충돌 방지용 6px 허용 오차 우회를 제거합니다.
- [ ] **편집 공간**에서 별도 **분할 구분선** 추출 이후 남아 있던 미사용 분할 리사이즈 상태와 키보드 핸들러 약 47줄을 삭제합니다.
- [ ] 내비게이션 **모듈** **인터페이스** 테스트에서 탭/모드 전환·본문 편집·워크스페이스 전환 시 점프/스크롤 자동 무효화 불변식이 검증되고, 기존 `<DocumentEditor />`·**문서 내 찾기 바**·**문서 목차**·`<App />` 검색 점프 통합 테스트 및 `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
