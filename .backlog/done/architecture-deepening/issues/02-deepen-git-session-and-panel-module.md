# 02 — Git 패널 변경 작업·Diff 탭·패널 UI 상태 통합 세션 모듈 심화

**Spec:** [spec.md](../spec.md)

**What to build:** **Git 패널**의 변경 실행·저장소↔워크스페이스 경로 해석·**문서 버퍼** discard 브래킷·**Diff 탭** 로드/캐시/정리·모든 Git **확인 다이얼로그**·Stash 입력 다이얼로그 상태·아코디언/보기 UI 상태를 좁은 협력자 **어댑터** 뒤의 단일 깊은 Git 세션 **모듈**로 통합하고, **Git 패널**의 40개 평탄 프롭과 **메인 창** 셸의 Git 조정 글루를 제거합니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] 심화된 Git 세션 **모듈**이 외부 의존성(**문서 버퍼** 저장/discard/재조정, **Diff 탭** 열기/닫기/목록 조회, **확인 다이얼로그** 호출, **폴더 트리** 새로고침)만 좁은 협력자 **어댑터**로 주입받고, 저장소↔워크스페이스 경로 해석·단일/연속 Git 변경 뮤테이션 잠금·`prepare`/`finish` **문서 버퍼** discard 브래킷·**Diff 탭** 로드/캐시/프루닝(기존 Diff 탭 훅 흡수)을 단일 트랜잭션으로 소유합니다.
- [ ] 자동 Stage 커밋 확인, 변경 전 미저장 **문서 버퍼** 보호 확인, `Discard All` 위험 확인, `Stash Drop` / `Clear All` 위험 확인 및 Stash 입력 다이얼로그 열기·닫기·제출 상태가 모두 Git 세션 **모듈**/**Git 패널** 범위 안에 응집되며, 미저장 **문서 버퍼** 확인 프롬프트는 워크스페이스 전환에서도 재사용 가능한 공용 헬퍼로 분리됩니다.
- [ ] **Git 패널**의 세션 UI 상태(**Changes 섹션**/**Stashes 섹션**/**Graph 섹션** 아코디언 분할 상태 및 리스트/트리 보기·접기 상태)를 Git 세션 **모듈**이 소유해 **왼쪽 사이드바** 뷰 전환 후에도 동일하게 유지되며, 중복 구현되어 있던 Git 패널 분할 계산이 공용 2단 아코디언 분할 **모듈**로 통일됩니다.
- [ ] **Git 패널** 프롭 표면이 40개 평탄 프롭에서 응집된 세션 모델로 축소되고 Stash 입력 다이얼로그가 **Git 패널** 범위 내에서 렌더링되며, **메인 창** 셸에서 Git 수명주기 콜백 8개·mutable ref 경로 보관·Git 다이얼로그/분할 보일러플레이트가 제거됩니다.
- [ ] 전체 앱 셸을 마운트하지 않는 Git 세션 **모듈** **인터페이스** 테스트에서 변경↔**문서 버퍼** discard↔**Diff 탭**↔**확인 다이얼로그**↔아코디언 분할 불변식이 직접 검증되고, 기존 `<App />` Git·**Git 패널** 통합 테스트 및 `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
