# Spec: 코드베이스 아키텍처 심화 (Architecture Deepening)

## Problem Statement (문제 정의)

최근 변경이 집중된 핵심 영역(검색·프론트매터, **Git 패널**, **메인 창** 워크스페이스 수명주기, 멀티 윈도우 세션, **문서 편집기** 점프/스크롤) 전반에서 도메인 불변식이 여러 얕은 **모듈**과 거대한 셸·테스트 하네스에 흩어져 있어 수정 국소성과 테스트 레버리지가 떨어지고 있습니다.

1. **검색·프론트매터 스키마 스캔의 메인/하네스 이중 구현 및 유출**: 문서 스캔·검색·필드값 수집·**프론트매터 스키마** **모듈**이 `node:fs`와 직접 결합되어 렌더러 JSDOM 통합 테스트에서 실행할 수 없으며, 이 때문에 인메모리 테스트 하네스가 약 330줄 규모의 검색·필드값 수집·스키마 상태 머신을 병렬 재구현하고 있습니다. 재구현을 위해 `@shared`에 루프 내부 헬퍼가 노출되었고, 메인과 하네스 사이에는 스키마 오류 처리·동시 워커·정렬 분기 등 실질적 동작 불일치가 누적되고 있습니다.
2. **Git 패널 트랜잭션의 셸/컨트롤러 분할**: **Git 패널**의 단일 변경 작업이 컨트롤러 **모듈**과 **메인 창** 셸 사이에 8개 수명주기 콜백과 mutable ref 경로 전달로 쪼개져 있으며, **확인 다이얼로그**(자동 Stage·미저장 보호 vs 전체 롤백·Stash 삭제)와 Stash 입력 상태·**Diff 탭** 정리가 서로 다른 **모듈**에 분산되어 있습니다. 또한 **Git 패널**이 접기/펼치기·목록/트리 상태를 유지하기 위해 40개 프롭을 전달받고, 아코디언 분할 수학을 공용 아코디언 분할 **모듈**과 중복 구현하고 있습니다.
3. **메인 창 워크스페이스 열기·복원·영속화의 비국소적 순서 제어**: 시작 초기화(`getInitContext`가 셸과 **문서 버퍼** 동기화 클라이언트에서 2회 호출됨)·중복 **메인 창** 포커스 확인·미저장 변경 확인·**폴더 트리** 로드·**문서 버퍼** 초기화·**편집기 영역** 레이아웃 복원·`workspace-state.json` 영속화 일시 중지/복원(`suspendAndFlush`/`markRestored`/`resumeForWorkspace`)을 **메인 창** 셸이 12개의 mutable ref로 수동 조합하고 있으며, **폴더 트리** **모듈**이 `workspace-state.json` 조회까지 떠안고 있습니다.
4. **멀티 윈도우 세션 규칙과 Electron 창 핸들의 결합**: 중복 워크스페이스 포커스, 닫기 게이트·clean flush 타이머, **보조 창** 0탭 자동 닫기(메인·하네스·보조 창 셸 3곳에 중복)·연쇄 닫기, 세션별 탭 드래그 격리 규칙이 Electron 창 핸들 처리와 섞여 있어, 테스트 하네스가 약 450줄의 세션/창 상태 머신을 별도로 재구현하고 있습니다. 또한 렌더러 어디에서도 호출하지 않는 `activateOrOpen` IPC 채널과 IPC 레지스트라의 단독 세션 폴백 분기가 남아 있습니다.
5. **문서 편집기 내비게이션의 4중 콜백 체이닝과 스크롤 동기화 충돌**: **검색 패널** 점프와 **문서 목차** 스크롤 요청을 무효화하기 위해 `onChangeContent`가 4단계에 걸쳐 재래핑되고 **메인 창** 셸 6곳에 수동 점프 무효화 호출이 흩어져 있으며, 2개의 병렬 점프 상태 머신이 동일 전이 불변식을 중복 검사합니다. `Split` **에디터 모드**에서는 **문서 목차** 점프가 `Raw`와 `Preview`를 동시에 스크롤해 6px 오차 보정에 의존하고 있으며, **편집 공간**에는 47줄의 미사용 분할 리사이즈 코드가 잔존합니다.

## Solution (해결 방안)

사용자에게 드러나는 UI·동작·도메인 개념은 100% 동일하게 보존한 채, 위 5개 클러스터를 **좁은 인터페이스와 깊은 구현**을 가진 **모듈** 구조로 재편합니다.

1. **검색·프론트매터 스키마 통합 `@shared` 모듈**: 이미 검증된 공유 **문서 버퍼** 허브 패턴을 확장해, 스키마 상태 머신·문서 스캔·검색/정렬·`allowCustom` 커스텀 필드값 수집을 좁은 스토리지 **심(seam)**(메인 디스크 **어댑터** + 하네스 인메모리 **어댑터**) 위의 단일 `@shared` 깊은 **모듈**로 통합합니다.
2. **Git 세션 조정 모듈 심화**: Git 변경 트랜잭션·저장소↔워크스페이스 경로 해석·**문서 버퍼** discard 브래킷·**Diff 탭** 로드/캐시/정리·모든 Git **확인 다이얼로그**·Stash 입력 다이얼로그 상태·**Git 패널** 아코디언/보기 상태를 좁은 협력자 **어댑터** 뒤의 단일 깊은 Git 세션 **모듈**로 응집합니다.
3. **메인 창 워크스페이스 수명주기 모듈 통합**: 시작 시퀀스·중복 **메인 창** 포커스·미저장 확인·**문서 버퍼** 초기화·**폴더 트리**/레이아웃 복원·`workspace-state.json` 영속화를 하나의 깊은 수명주기 **모듈**로 통합해 12개 동기화 ref를 제거하고 **폴더 트리** **모듈**을 순수 트리 책임으로 되돌립니다.
4. **멀티 윈도우 세션 모듈 추출 (`@shared`)**: **메인 창**·**보조 창** 세션 수명주기와 닫기 게이트·드래그 격리 규칙을 창 호스트 **심(seam)**(Electron 호스트 **어댑터** + 인메모리 호스트 **어댑터**) 위의 `@shared` 깊은 **모듈**로 추출해 하네스 450줄 중복·3중 0탭 자동 닫기·미사용 채널·폴백 분기를 제거합니다.
5. **편집기 영역 내비게이션 모듈 통합 및 `Split` 스크롤 단일화**: 탭 저장소 전이 이벤트에 구독해 **검색 패널** 점프와 **문서 목차** 스크롤 무효화를 자동화하는 단일 **편집기 영역** 내비게이션 **모듈**을 두고, `Split` **에디터 모드**의 **문서 목차** 스크롤을 `Raw` 단일 드라이버로 통일하며 미사용 분할 리사이즈 코드를 정리합니다.

## User Stories (사용자 스토리)

1. As a 유지보수자, I want **검색 패널** 쿼리·`allowCustom` 필드값 수집·**프론트매터 스키마** 상태 머신이 좁은 스토리지 **심(seam)** 위의 단일 `@shared` 깊은 **모듈**에서 실행되기를 원하며, so that 메인 프로세스와 통합 테스트 하네스 간의 중복과 동작 불일치를 제거하고 검색·스키마 회귀를 한 곳에서 검증할 수 있습니다.
2. As a 유지보수자, I want **Git 패널**의 변경 실행·**문서 버퍼** discard 브래킷·**Diff 탭** 동기화·**확인 다이얼로그**·패널 UI 상태가 단일 Git 세션 **모듈** 내부에 응집되기를 원하며, so that **메인 창** 셸을 마운트하지 않고도 Git↔버퍼↔Diff 탭 불변식을 테스트하고 **Git 패널** 프롭을 단순화할 수 있습니다.
3. As a 유지보수자, I want **메인 창**의 시작 초기화·워크스페이스 전환·레이아웃 복원·`workspace-state.json` 영속화 일시 중지/재개 순서가 하나의 수명주기 **모듈**에 캡슐화되기를 원하며, so that 셸의 mutable ref 동기화 부담과 **폴더 트리** **모듈**의 영속화 결합을 없앨 수 있습니다.
4. As a 유지보수자, I want **메인 창**·**보조 창** 세션 라우팅·닫기 게이트·0탭 자동 닫기·세션별 탭 드래그 격리가 창 호스트 **심(seam)** 위의 단일 `@shared` **모듈**에서 실행되기를 원하며, so that 테스트 하네스가 실제 세션 규칙을 그대로 실행하고 미사용 IPC 분기를 제거할 수 있습니다.
5. As a 유지보수자, I want **검색 패널** 점프·**문서 내 찾기 바**·**문서 목차** 스크롤 무효화가 탭 저장소 전이 이벤트 기반의 단일 **편집기 영역** 내비게이션 **모듈**에 집중되기를 원하며, so that 4중 콜백 체이닝·이중 점프 상태 머신·`Split` **에디터 모드** 스크롤 충돌과 죽은 코드를 제거할 수 있습니다.

## Implementation Decisions (구현 결정사항)

*(구현 중 구조가 바뀌므로 구체적인 파일 경로나 일반 코드 스니펫은 기재하지 않으며, 모든 리팩토링은 기존 사용자 관점 동작을 그대로 보존합니다.)*

### 1. 검색 패널·프론트매터 스키마 통합 `@shared` 모듈
- **책임 통합**: 기존 메인 프로세스의 문서 스캐너·텍스트/프론트매터 검색·`allowCustom` `multi-select` 필드값 수집·**프론트매터 스키마** 상태 머신(읽기, 엄격 검증, 기본 스타터 템플릿 초기화, 저장, 직렬화 비동기 큐, `missing`/`valid`/`error` 핑거프린트 비교, 변경 브로드캐스트)을 브라우저·Node 공용 `@shared` 단일 깊은 **모듈**로 통합합니다.
- **스토리지 심(seam)과 두 어댑터**: 워크스페이스 루트 조회 및 루트 변경 구독, 조건에 맞는 대상 파일 목록 열거, 후보 문서 텍스트 읽기(문자열 바이트 길이 검사는 `TextEncoder` 기반으로 브라우저 호환 유지), 선택적 실제 경로(realpath) 해석(심볼릭 링크가 걸린 열린 **문서 버퍼** 매칭용), 스키마 raw 읽기/원자적 쓰기, 선택적 외부 스키마 변경 감시 알림만 좁은 스토리지 **심**으로 추상화합니다.
  - 메인 디스크 **어댑터**: 기존 `fsWatch` 디바운스 감시, 워크스페이스 루트 탈출/심볼릭 링크 차단 보안 검증, 임시 파일 기반 원자적 쓰기를 그대로 유지합니다.
  - 인메모리 테스트 **어댑터**: 가상 파일 맵을 직접 연결하며, 테스트 하네스에 중복 작성되어 있던 검색·필드값 수집·스키마 상태 머신 코드를 전부 삭제합니다.
- **열린 문서 버퍼 허브 직접 연동**: 공유 **문서 버퍼** 허브를 직접 연결하여, 검색/필드값 스캔 시 미저장 **문서 버퍼**를 디스크보다 우선 오버레이하고, 스키마 저장 또는 외부 변경 감지 시 열려 있는 깨끗한(clean) `.wiki-editor/frontmatter.json` **문서 버퍼**를 자동 갱신합니다.
- **동시성 및 취소 불변식**: `search`와 `collectFieldValues`는 서로의 진행을 방해하지 않도록 독립된 single-flight `AbortController` 레인을 유지하되(예: 필터 팝오버가 열릴 때 진행 중인 검색을 끊지 않음), 워크스페이스 루트 전환 또는 `dispose` 호출 시에는 두 레인을 모두 일괄 취소합니다.
- **내부화(삭제 테스트)**: 하네스와의 코드 공유를 위해 `@shared`에 노출되어 있던 루프 내부 헬퍼(`WorkspaceSearchAccumulator`, `commitSearchCandidateSlot`, `createFrontmatterFieldValuesCollector`)를 새 깊은 **모듈** 내부 구현으로 비공개화합니다.

### 2. Git 세션 조정 모듈 심화
- **단일 트랜잭션 캡슐화**: Git 변경 실행(`stage`/`unstage`/`commit`/`checkout`/`pull`/`push`/`fetch`/`sync`/`discard`/`stash`), 저장소 상대 경로↔워크스페이스 경로 해석, `prepare`/`finish` **문서 버퍼** discard 브래킷, **Diff 탭** payload 로드·캐시·정리(별도 Diff 탭 훅 흡수), 작업 완료 후 **폴더 트리** 새로고침 및 버퍼 재조정을 하나의 깊은 Git 세션 **모듈**로 통합합니다.
- **협력자 어댑터 심**: 외부 상태(**문서 버퍼** 저장/discard/재조정, **Diff 탭** 열기/닫기/목록 조회, **확인 다이얼로그** 열기, **폴더 트리** 새로고침)만 좁은 협력자 **어댑터**로 주입받아, **메인 창** 셸이 콜백 8개와 ref 경로 보관으로 트랜잭션을 수동 연결하지 않도록 제거합니다.
- **확인 다이얼로그·Stash 다이얼로그·공용 미저장 가드**: 자동 Stage 커밋 확인, 변경 전 미저장 **문서 버퍼** 확인, `Discard All` 위험 확인, `Stash Drop` / `Clear All` 위험 확인과 Stash 입력 다이얼로그 열기/닫기/제출 상태를 Git 세션 **모듈**·**Git 패널** 범위로 내립니다. 이때 미저장 **문서 버퍼** 확인 프롬프트 로직은 워크스페이스 전환에서도 재사용할 수 있는 좁은 공용 헬퍼로 유지합니다.
- **Git 패널 UI 상태 통합 및 아코디언 계산 공용화**: **왼쪽 사이드바** 뷰 전환 시 마운트 해제되어도 유지되어야 하는 **Git 패널** 세션 상태(**Changes 섹션**/**Stashes 섹션**/**Graph 섹션** 아코디언 분할 상태와 리스트/트리 보기·접기 상태)를 Git 세션 **모듈**이 소유하고, 중복 구현되어 있던 분할 비율 클램핑·키보드 스텝·백분율 계산을 공용 2단 아코디언 분할 **모듈**로 통일합니다.
- **인터페이스 축소**: **Git 패널**이 받던 40개 평탄 프롭을 응집된 세션 모델 프롭으로 축소하고, Stash 입력 다이얼로그를 **Git 패널** 맥락 안에서 렌더링합니다.

### 3. 메인 창 워크스페이스 수명주기 모듈 통합
- **수명주기 상태 머신 통합**: 앱 시작 시 창 초기화 컨텍스트 조회(`getInitContext` 중복 호출을 단일 진입으로 정리)와 초기 `config.json`의 최근 워크스페이스 조인, 중복 **메인 창** 포커스 우선 확인, 미저장 **문서 버퍼** 확인, 전환 전 **문서 버퍼** 정리, **폴더 트리** 열기 및 **편집기 영역** 레이아웃 복원, 닫기 전 즉시 flush를 하나의 **메인 창** 워크스페이스 수명주기 **모듈**로 통합합니다.
- **영속화 일시 중지/재개 캡슐화**: `workspace-state.json` 디바운스 저장, 전환 시 `suspendAndFlush`, 복원 완료 시 `markRestored`, 전환 실패 시 이전 워크스페이스로의 `resumeForWorkspace` 롤백 순서를 수명주기 **모듈** 내부 불변식으로 감춰 외부 호출자가 순서를 틀릴 수 없도록 합니다.
- **폴더 트리 모듈 순수화**: **폴더 트리** **모듈**에서 `workspace-state.json` 조회 책임을 제거하여, 순수 디렉터리 트리 상태·다중 선택·파일/폴더 CRUD·감시 이벤트 처리만 담당하도록 단순화합니다.
- **메인 창 셸 경량화**: **메인 창** 셸에서 시작/전환/복원 순서를 맞추기 위한 12개 mutable ref와 조정 글루를 제거합니다.

### 4. 메인 창·보조 창 공유 세션 모듈 추출 (`@shared`)
- **순수 멀티 윈도우 세션 코디네이터**: 세션 생성·폐기, `pendingInitialWorkspacePath`/`pendingOpenWorkspacePath`/`activeRoot`를 아우르는 중복 워크스페이스 창 탐색·복원·포커스, **보조 창** pending transfer 등록·0탭 자동 닫기·**메인 창** 닫힘 시 연쇄 닫기, 창 닫기 게이트(`closePromptPending`, `closeFlushEnabled`, clean close flush 타이머), 세션 내부 vs 타 세션 간 탭 드래그 격리(`different-workspace-session`) 규칙을 `@shared`의 단일 깊은 **모듈**로 추출합니다.
- **창 호스트 심(seam)과 두 어댑터**: 창 생성, 포커스/복원, 닫기, bounds 조회, 닫기 요청 전달, 창 수명주기 이벤트 구독만 좁은 창 호스트 **심**으로 추상화합니다.
  - 메인 Electron **어댑터**: 실제 브라우저 창 생성·URL/파일 로드·입력 이벤트 전달만 담당합니다.
  - 인메모리 테스트 **어댑터**: 가상 창 핸들을 연결해 테스트 하네스의 약 450줄 중복 멀티 윈도우 세션 구현을 삭제합니다.
- **단일 소유권 및 미사용 표면 제거**:
  - **보조 창** 0탭 자동 닫기의 단일 권위를 공유 세션 **모듈**의 `syncWindowTabs` 전이에 두어, 렌더러 **보조 창** 셸에 중복 구현된 탭 수 감시 자동 닫기 효과를 제거합니다(단, 탭 닫기 및 창 밖 드래그 아웃 시나리오가 모두 `syncWindowTabs`로 안전하게 닫히는지 통합 검증).
  - 렌더러에서 전혀 사용하지 않으며 테스트 하네스에도 빠져 있던 `activateOrOpen` IPC 채널을 공유·프리로드·메인 전역에서 제거합니다.
  - 워크스페이스·**문서 버퍼**·프론트매터 IPC 레지스트라가 항상 세션 소스 **인터페이스**를 균일하게 받도록 단순화하고, 단독 세션 폴백 서비스 그래프 분기를 삭제합니다(IPC 단위 테스트도 경량 세션 소스 어댑터로 통일).

### 5. 편집기 영역 내비게이션 모듈 통합 및 `Split` 스크롤 단일화
- **전이 이벤트 기반 내비게이션 모듈**: 탭 저장소가 이미 발행하는 전이 이벤트(`tab-opened`, `tab-switched`, `editor-mode-changed`, `tab-closed`)와 **문서 버퍼** 본문 편집에 직접 구독하여, 대기 중인 **검색 패널** 점프 요청과 **문서 목차** 스크롤 요청을 한곳에서 자동 무효화하는 **편집기 영역** 내비게이션 **모듈**을 도입합니다.
- **이중 상태 머신 및 4중 래핑 제거**: 두 개의 병렬 검색 점프 상태 머신을 하나로 통합하고, 4단계에 걸친 `onChangeContent` 콜백 재래핑과 **메인 창** 셸의 6곳 수동 점프 무효화 호출을 제거합니다. 동시에 52개 속성을 평탄하게 재노출하던 얕은 편집기 워크스페이스 훅의 통과 표면(사용하지 않는 더미 액션 포함)을 축소합니다.
- **문서 목차 통합 및 `Split` 스크롤 단일화**: **문서 목차** 상태와 스크롤 스파이 조정을 응집하고, `Split` **에디터 모드**의 **문서 목차** 점프 스크롤 역시 **검색 패널** 점프와 동일하게 `Raw` 편집기만 직접 스크롤해 미리보기가 줄 동기화로 뒤따라오도록 통일합니다. 이로써 양쪽 동시 스크롤 충돌을 막기 위해 존재하던 6px 허용 오차 우회를 제거합니다.
- **죽은 코드 정리**: **편집 공간**에서 별도 **분할 구분선** 분리 이후 남아 있던 미사용 리사이즈 상태와 키보드 핸들러 약 47줄을 삭제합니다.

## Testing Decisions (테스트 결정사항)

- **검증 기준**: 개별 얕은 헬퍼나 내부 구현 상태가 아니라, 심화된 각 **모듈**의 공개 **인터페이스**와 외부에서 관찰 가능한 사용자 동작을 기준으로 검증합니다. 모든 테스트는 임시 디렉터리 또는 인메모리 **어댑터**를 사용해 완전 격리 상태로 실행합니다.
- **사전 합의된 테스트 심 (Pre-agreed Seams)**:
  1. **공유 코어·세션 모듈 공개 인터페이스 심** (`@shared` 검색·스키마 통합 **모듈** 및 멀티 윈도우 세션 **모듈** + 인메모리 **어댑터**)
     - **Catches**: 검색·프론트매터 필터/정렬·커스텀 필드값 수집, 스키마 핑거프린트·변경 브로드캐스트·clean **문서 버퍼** 갱신, 독립 single-flight 취소, 중복 **메인 창** 포커스, 닫기 게이트·**보조 창** 0탭/연쇄 닫기, 세션 간 탭 드래그 격리 불변식 회귀.
     - **Misses**: 실제 OS 파일시스템 심볼릭 링크/경로 탈출 차단·원자적 쓰기·파일 감시 디바운스 동작 및 렌더러 React UI 상호작용.
  2. **메인 프로세스 디스크 어댑터·IPC 통합 테스트 심** (임시 디렉터리 파일시스템 + 가짜 `ipcMain` + 프리로드 브리지)
     - **Catches**: `.wiki-editor/frontmatter.json` 및 워크스페이스 스캔의 경로 탈출·심볼릭 링크 차단, 원자적 파일 쓰기·외부 변경 감시 재로드, 세션 격리 IPC 라우팅 및 미사용 채널·폴백 분기 제거 후 브리지 계약 회귀.
     - **Misses**: 렌더러 React 상태 전이, **확인 다이얼로그**·**Git 패널**·**문서 편집기** UI 렌더링 및 스크롤 동기화.
  3. **`<App />` 통합 · 멀티윈도우 및 렌더러 심화 모듈 공개 인터페이스 심** (실제 `@shared` **모듈**에 연결된 인메모리 하네스 기반 `<App />`·`<DocumentEditor />` + 심화된 Git 세션·워크스페이스 수명주기·편집기 영역 내비게이션 **모듈** **인터페이스**)
     - **Catches**: **Git 패널** 변경↔**문서 버퍼** discard 브래킷↔**Diff 탭** 정리↔**확인 다이얼로그**↔아코디언 분할 정합성, **메인 창** 시작 복원·중복 창 전환·실패 롤백·닫기 전 flush, **검색 패널** 점프·**문서 목차** 스크롤·**문서 내 찾기 바**·`Split` **에디터 모드** 스크롤 전이 및 **보조 창** 동기화 회귀.
     - **Misses**: 실제 OS 디스크 I/O·네이티브 Electron 창 배치/포커스·실제 Chromium 서브픽셀 페인트 레이아웃.

- **참고할 기존 테스트 패턴 (Prior Art)**:
  - 공유 **문서 버퍼** 허브 및 탭 드래그 세션 **모듈**의 `@shared` 인메모리 **어댑터** 기반 공개 **인터페이스** 테스트 패턴
  - 메인 프로세스 임시 디렉터리·가짜 `ipcMain`·프리로드 브리지 통합 테스트 패턴
