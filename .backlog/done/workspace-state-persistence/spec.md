# Spec: 앱 시작 및 워크스페이스 전환 시 워크스페이스별 이전 상태 유지·복원

## Problem Statement (문제 정의)

현재 앱은 시작 시 마지막 최근 워크스페이스 폴더만 자동으로 다시 열 뿐, 해당 워크스페이스에서 열려 있던 문서 탭·**화면 분할 모드**·탭별 **에디터 모드**·스크롤 및 커서 위치·**폴더 트리** 펼침 상태를 전혀 보존하지 않습니다.

- 앱을 재시작하거나 다른 워크스페이스로 옮겼다 돌아올 때마다 이전에 열어 두었던 문서 탭들과 분할 배치, 작업 중이던 스크롤·커서 위치, 펼쳐 두었던 하위 폴더들이 모두 초기화되어 매번 수동으로 다시 찾아 열어야 합니다.
- 이미 열려 있는 현재 워크스페이스를 **워크스페이스 뷰**나 `'폴더 열기...'`에서 다시 선택했을 때도 다른 워크스페이스로의 전환과 동일하게 취급되어 불필요한 미저장 **확인 다이얼로그**가 뜨고 열린 탭과 트리가 초기화됩니다.

## Solution (해결 방안)

앱 데이터(`userData`) 폴더 내 별도 상태 파일(`workspace-state.json`)에 워크스페이스별 작업 세션을 영속화하여, 앱 시작 시 자동 복원 및 워크스페이스 전환 시 이전 작업 상태를 끊김 없이 이어갈 수 있도록 합니다.

1. **별도 상태 파일(`workspace-state.json`) 기반 영속화**: Git 워킹트리를 오염시키지 않고 사용자가 직접 편집하는 전역 설정(`config.json`)과도 충돌하지 않도록 `userData` 내 별도 `workspace-state.json`에 워크스페이스별 상태를 원자적으로(atomic write) 저장하고 손상 시 안전하게 복구합니다.
2. **메인 창 편집 공간 및 탭별 뷰 상태 복원**: 워크스페이스별로 **메인 창**의 **편집 공간** 레이아웃(**화면 분할 모드**, **분할 구분선** 비율, 활성 **편집기 영역**, **주 편집기 영역**·**보조 편집기 영역** 각각의 워크스페이스 문서 탭 목록·순서·활성 탭)과 각 탭의 뷰 상태(**에디터 모드**, 커서 선택 범위, 스크롤 위치, `Split` 내부 비율)를 저장·복원합니다.
3. **폴더 트리 펼침 상태 복원**: 각 워크스페이스의 **폴더 트리**에서 펼쳐 두었던 폴더 목록(`expandedDirs`)을 기억하여 워크스페이스를 다시 열 때 하위 항목들을 함께 로드해 펼쳐진 상태로 복원합니다.
4. **누락 파일·폴더 무오류 정리 및 레이아웃 자동 축소**: 복원 시점에 외부에서 삭제·이동되어 더 이상 존재하지 않는 파일 탭이나 폴더는 **오류 배너** 없이 조용히 건너뛰며, 분할 상태에서 한쪽 **편집기 영역**의 탭이 모두 사라지면 자동으로 `single` 모드로 전환합니다.
5. **동일 워크스페이스 재선택 무해화**: 현재 열려 있는 워크스페이스와 동일한 경로를 다시 선택했을 때는 미저장 **확인 다이얼로그**나 탭·트리 초기화 없이 현재 열려 있는 상태(미저장 **문서 버퍼** 포함)를 그대로 유지하고 **워크스페이스 뷰**에서 **탐색기 뷰**로만 전환합니다.

## User Stories (사용자 스토리)

1. As a 위키 작성자, I want 앱을 종료했다가 다시 시작할 때 마지막으로 열었던 워크스페이스의 열린 문서 탭 목록·순서, 활성 탭, **화면 분할 모드**(`single` / `horizontal` / `vertical`) 및 **분할 구분선** 비율, 활성 **편집기 영역**이 그대로 복원되기를 원하며, so that 앱을 켤 때마다 작업하던 화면 구성을 다시 세팅하지 않아도 됩니다.
2. As a 위키 작성자, I want 워크스페이스 A에서 작업하다가 워크스페이스 B로 전환한 뒤 다시 워크스페이스 A로 돌아왔을 때 각 워크스페이스에서 열어 두었던 탭과 분할 레이아웃이 각각 독립적으로 복원되기를 원하며, so that 여러 위키 프로젝트를 오가며 작업할 때 문맥을 잃지 않습니다.
3. As a 위키 작성자, I want 복원된 각 문서 탭이 이전에 사용하던 **에디터 모드**(`Raw` / `위지윅` / `Preview` / `Split`), `Split` 내부 분할 비율(`splitPreviewRatio`), 커서 선택 위치(`cursor`), 스크롤 위치(`scrollTop`)를 그대로 유지하기를 원하며, so that 읽거나 편집하던 문서의 정확한 위치부터 즉시 작업을 재개할 수 있습니다.
4. As a 위키 작성자, I want 앱 시작 시나 워크스페이스 재전환 시 해당 워크스페이스의 **폴더 트리**에서 펼쳐 두었던 하위 폴더(`expandedDirs`)들이 그대로 펼쳐진 채로 복원되기를 원하며, so that 깊은 폴더 계층을 매번 다시 클릭해 펼치지 않아도 됩니다.
5. As a 위키 작성자, I want 워크스페이스 내부에서 파일·폴더 이름을 변경하거나 이동·삭제했을 때 해당 워크스페이스의 저장된 탭 경로와 **폴더 트리** 펼침 경로도 함께 갱신되기를 원하며, so that 파일 구조 변경 후 앱을 재시작해도 변경된 경로로 탭과 폴더가 정상 복원됩니다.
6. As a 위키 작성자, I want 복원하려는 파일이나 펼쳐진 폴더가 앱 외부에서 삭제·이동되어 디스크에 더 이상 존재하지 않을 때 **오류 배너** 없이 조용히 건너뛰고 존재하는 항목만 복원되기를 원하며(분할 상태에서 한쪽 영역 탭이 모두 사라지면 단일 모드로 자동 전환), so that 외부 파일 정리 후 앱을 열 때 불필요한 오류 알림에 방해받지 않습니다.
7. As a 위키 작성자, I want 일시적인 Git **Diff 탭**, 전역 `config.json` 탭, 분리된 **보조 창**은 워크스페이스별 복원 대상에서 제외되기를 원하며, so that 워크스페이스를 열 때 순수한 해당 워크스페이스의 문서 편집 환경만 깔끔하게 복원됩니다.
8. As a 위키 작성자, I want 이미 열려 있는 현재 워크스페이스를 **워크스페이스 뷰**나 `'폴더 열기...'`에서 다시 선택했을 때 미저장 **확인 다이얼로그**나 탭·트리 초기화 없이 현재 작업 상태가 그대로 유지되고 **워크스페이스 뷰**에서 **탐색기 뷰**로만 이동하기를 원하며, so that 실수로 같은 워크스페이스를 클릭해도 작업 흐름이나 미저장 편집 내용이 초기화되지 않습니다.

## Implementation Decisions (구현 결정사항)

### 확정된 핵심 상태 및 스키마 형태 (설계 검토 확정안)

```ts
interface PersistedWorkspaceTabState {
  path: string
  mode: EditorMode
  cursor: CursorPosition
  scrollTop: number
  splitPreviewRatio: number
}

interface PersistedWorkspacePaneState {
  tabs: PersistedWorkspaceTabState[]
  activeTabPath: string | null
}

interface PersistedWorkspacePaneLayout {
  splitMode: SplitMode
  splitRatio: number
  activePaneId: PaneId
  panes: Record<PaneId, PersistedWorkspacePaneState>
}

interface PersistedWorkspaceState {
  rootPath: string
  updatedAt: string // ISO-8601
  expandedDirs: string[]
  layout: PersistedWorkspacePaneLayout
}

interface WorkspaceStateDocument {
  version: 1
  workspaces: Record<string, PersistedWorkspaceState>
}
```

### 아키텍처 및 전이 규칙

- **저장소 분리 및 원자적 파일 관리**:
  - 워크스페이스별 이전 상태는 `userData` 디렉터리 내 `workspace-state.json`에 저장합니다(전역 `config.json` 스키마 및 사용자가 직접 여는 `config.json` **문서 버퍼**와 완전히 분리).
  - 임시 파일 쓰기 후 이름 변경(atomic write)과 비동기 직렬 큐로 동시 쓰기 경쟁을 방지하고, 파일이 존재하지 않으면 기본값(`version: 1, workspaces: {}`)으로 초기화하며, JSON 구문 오류나 최상위 구조 손상 시 `.corrupt.<suffix>.bak` 백업 파일을 남기고 로그 기록 후 기본 상태로 복구합니다.
  - 개별 워크스페이스 엔트리나 내부 필드 일부가 손상·유효하지 않은 경우 전체 파일을 버리지 않고 유효한 워크스페이스·탭·경로 항목만 정규화하여 살립니다(`splitRatio` 및 `splitPreviewRatio`는 `[0.15, 0.85]` 범위로 클램핑).
  - 상태 파일이 무한정 커지지 않도록 최근 갱신된 워크스페이스 기준 상한(예: 최대 30개 LRU)을 두어 오래된 항목을 자동 정리합니다.
- **식별 키 및 보안 경계**:
  - 워크스페이스 맵의 키는 정규화된 경로 비교 키(`getWorkspacePathKey(rootPath)`)를 사용합니다.
  - 복원 및 저장 시 모든 파일 경로(`tab.path`)와 펼쳐진 폴더 경로(`expandedDirs`)는 해당 워크스페이스 `rootPath` 하위 경로인지 검증하며, 워크스페이스 루트 밖 경로는 제외합니다.
- **복원 대상 및 제외 범위**:
  - 복원 대상은 워크스페이스별 **폴더 트리** 펼침 목록(`expandedDirs`), **메인 창**의 **편집 공간** 분할 상태(`splitMode`, `splitRatio`, `activePaneId`), **주 편집기 영역**·**보조 편집기 영역**의 워크스페이스 문서 탭(마크다운 문서 및 읽기 전용 이미지 미리보기 탭) 목록·순서·활성 탭, 각 문서 탭의 뷰 상태(`mode`, `cursor`, `scrollTop`, `splitPreviewRatio`)로 한정합니다.
  - 일시적인 **Diff 탭**, 전역 `config.json` 탭, 분리된 **보조 창**은 저장·복원 대상에서 제외합니다.
  - **메인 창** 크기·위치 및 **왼쪽 사이드바**·**우측 사이드바** 너비/접힘, **Git 패널** 분할 비율 등 앱 셸 레이아웃은 디스크에 저장하지 않고 기존 기본값으로 시작합니다.
- **동일 워크스페이스 재선택 무해화**:
  - **워크스페이스 뷰**의 목록 클릭이나 `'폴더 열기...'` 다이얼로그 선택 결과가 현재 열려 있는 워크스페이스와 동일한 경로(`isSameWorkspacePath`)인 경우, 미저장 **확인 다이얼로그**를 띄우거나 `openWorkspace`·`clearWorkspaceBuffers`를 재실행하지 않고 현재 열린 **문서 버퍼**·**편집 공간**·**폴더 트리** 상태를 그대로 유지합니다.
  - 이때 **왼쪽 사이드바**가 펼쳐진 **워크스페이스 뷰**였다면 **탐색기 뷰**로 전환합니다.
- **워크스페이스 열기 및 복원 순서**:
  - 앱 시작 시 초기 설정 로드 후 최근 워크스페이스(`recentWorkspaces[0]`)를 열거나 사용자가 다른 워크스페이스로 전환해 워크스페이스 열기가 완료되면, 해당 워크스페이스의 저장된 `PersistedWorkspaceState`를 조회합니다.
  - **폴더 트리 복원**: 저장된 `expandedDirs` 각각에 대해 하위 디렉터리 읽기를 병렬 수행하고, 성공한 디렉터리만 `expandedDirs`와 `childrenByDir`에 반영합니다(삭제·이동되어 읽기 실패한 폴더는 **오류 배너** 없이 제외).
  - **편집 공간 및 탭 복원**: 저장된 `primary`·`secondary` 영역의 탭 경로들을 순서대로(영역 내 중복 경로는 첫 탭만 유지) 워크스페이스 **문서 버퍼**로 열고(존재하지 않거나 열기에 실패한 파일은 **오류 배너** 없이 건너뜀), 각 탭의 뷰 상태(`mode`, `cursor`, `scrollTop`, `splitPreviewRatio`)와 영역별 활성 탭(`activeTabPath`가 누락된 경우 해당 영역의 첫 번째 유효 탭), `splitMode`, `splitRatio`, `activePaneId`를 일괄 복원합니다.
  - **빈 영역 자동 축소 불변식**: 파일 누락 등으로 인해 복원 후 `secondary` 영역의 탭이 `0`개가 되면 `splitMode`는 `'single'`, `activePaneId`는 `'primary'`로 전환합니다. 복원 후 `primary` 영역의 탭이 `0`개이고 `secondary` 영역에만 탭이 존재하면 `secondary` 탭과 활성 탭을 `primary`로 승격하고 `'single'` 모드로 전환합니다.
  - 워크스페이스 전환 시 **메인 창**에 이미 열려 있던 전역 `config.json` 탭이 있다면 기존 `config.json` **문서 버퍼**는 닫지 않고 보존합니다.
- **상태 저장 시점 및 레이스 방지**:
  - 워크스페이스가 열려 있고 초기 복원이 완료된 이후에 **편집 공간** 레이아웃·탭 뷰 상태·`expandedDirs` 변경이 발생하면 짧은 디바운스(예: 250ms)로 현재 워크스페이스 상태를 저장합니다.
  - 다른 워크스페이스로 전환하기 직전(이전 워크스페이스의 탭을 비우기 전)과 **메인 창**이 닫히기 직전에는 디바운스를 기다리지 않고 현재 워크스페이스의 최신 상태를 즉시 캡처·저장하여, 전환 과정에서 빈 탭 상태가 이전 워크스페이스 상태로 덮어써지지 않도록 보장합니다.
  - 워크스페이스 복원이 진행 중일 때 사용자가 곧바로 다른 워크스페이스로 다시 전환하면 이전 복원 작업의 늦은 비동기 응답은 무시합니다(시퀀스 가드).

## Testing Decisions (테스트 결정사항)

- 검증 기준: 내부 구현 세부사항이 아니라 사용자 관점의 외부 관찰 동작(앱 재마운트 및 워크스페이스 전환 후 화면에 표시되는 탭·분할 영역·에디터 모드·스크롤/커서·펼쳐진 폴더 트리 및 동일 워크스페이스 재선택 동작)과 저장소 공개 계약을 기준으로 검증합니다. 모든 테스트는 인메모리 하네스 또는 임시 디렉터리로 격리합니다.
- 핵심 모듈 및 테스트 심(Test Seam):
  - **`<App />` 통합 테스트 (인메모리 `WikiApi` 하네스)**: Catches 앱 시작(재마운트) 및 워크스페이스 A↔B 전환 시 열린 문서 탭·**화면 분할 모드**·`splitRatio`·활성 영역/탭·**에디터 모드**·`cursor`·`scrollTop`·`splitPreviewRatio`·**폴더 트리** `expandedDirs` 복원 누락, 전환 직전 빈 상태 덮어쓰기 레이스, 삭제된 파일/폴더 복원 시 불필요한 **오류 배너** 노출이나 빈 분할 영역 방치, **Diff 탭**·`config.json` 탭 오저장, 동일 워크스페이스 재선택 시 미저장 **확인 다이얼로그** 노출 및 탭 초기화 회귀 / Misses 실제 OS 파일시스템 상의 `workspace-state.json` 원자적 파일 교체(`rename`) 및 손상 백업 파일 생성.
  - **워크스페이스 상태 저장소 및 정규화 통합/단위 테스트 (임시 디렉터리 기반 서비스 및 IPC 테스트 하네스)**: Catches `workspace-state.json` 원자적 읽기·쓰기, 손상된 JSON 백업(`.corrupt.*.bak`) 및 기본값 복구, 부분 손상 데이터 정규화(`splitRatio` 클램핑·루트 밖 경로 차단·LRU 정리), 빈 **편집기 영역** 단일 모드 축소 및 `secondary`→`primary` 승격 규칙 오류 / Misses 실제 Chromium 렌더러 DOM 스크롤 복원.

## Out of Scope (범위 제외 사항)

- **메인 창** 크기·위치(`WindowBounds`, 최대화 여부)나 **왼쪽 사이드바**·**우측 사이드바** 너비/접힘, **Git 패널** 분할 비율을 디스크에 저장·복원하는 기능
- 분리된 **보조 창 (Auxiliary Window)** 목록·위치나 Git **Diff 탭**, 전역 `config.json` 탭을 워크스페이스 상태에 포함해 복원하는 기능
- 저장하지 않은(dirty) 메모리 내 임시 편집 본문을 디스크 원본 파일과 별도로 스냅샷 저장(hot exit)하는 기능 (워크스페이스 전환 및 창 닫기 시 기존 미저장 **확인 다이얼로그**로 보호)

## Further Notes (기타 참고사항)
