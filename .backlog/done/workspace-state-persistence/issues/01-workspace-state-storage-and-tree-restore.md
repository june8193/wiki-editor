# 01 — 워크스페이스 상태 저장소·동일 워크스페이스 재선택 보호 및 폴더 트리 펼침 상태 복원

**Spec:** [spec.md](../spec.md)

**What to build:** 앱 데이터(`userData`) 폴더 내 별도 상태 파일(`workspace-state.json`)을 관리하는 영속화 서비스 및 IPC 계약을 구축하고, 이미 열려 있는 워크스페이스를 다시 선택했을 때는 미저장 **확인 다이얼로그**나 초기화 없이 현재 상태를 유지하며, 앱 시작 시 및 워크스페이스 전환 시 각 워크스페이스의 **폴더 트리** 펼침 상태(`expandedDirs`)를 저장·복원합니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] `userData` 내 별도 `workspace-state.json` 파일에 워크스페이스별 상태를 원자적으로(atomic write) 읽고 쓰며, 파일이 없을 때는 기본 상태로 초기화하고 손상된 JSON일 때는 `.corrupt.*.bak` 백업 생성 및 로그 기록 후 기본 상태로 복구합니다(전역 `config.json`과 분리).
- [x] 저장된 상태 정규화 시 워크스페이스 루트 밖의 경로를 차단하고, 최근 갱신 기준 상한(LRU)을 초과한 오래된 워크스페이스 상태를 정리합니다.
- [x] 앱 시작 시 마지막 워크스페이스가 자동으로 열릴 때와 워크스페이스 A에서 B로 전환했다가 다시 A로 돌아올 때, 해당 워크스페이스에서 펼쳐 두었던 **폴더 트리** 경로(`expandedDirs`)들과 각 폴더의 하위 항목들이 자동으로 로드되어 펼쳐진 상태로 복원됩니다.
- [x] 워크스페이스 내에서 폴더를 펼치거나 접을 때, 그리고 폴더 이름 변경·이동·삭제가 일어날 때 갱신된 `expandedDirs`가 해당 워크스페이스 상태로 저장됩니다.
- [x] 복원 시점에 외부에서 삭제·이동되어 디스크에 더 이상 존재하지 않는 폴더 경로는 **오류 배너** 없이 조용히 건너뛰고 존재하는 폴더만 펼칩니다.
- [x] 현재 열려 있는 워크스페이스와 동일한 경로를 **워크스페이스 뷰**(즐겨찾기·최근 목록) 또는 `'폴더 열기...'`에서 다시 선택한 경우, 미저장 **확인 다이얼로그**를 띄우거나 열린 **문서 버퍼**·**탭 바**·**폴더 트리**를 초기화하지 않고 현재 상태를 그대로 유지하며, 펼쳐진 **워크스페이스 뷰**였다면 **탐색기 뷰**로만 전환합니다.
- [x] `<App />` 통합 테스트 심과 워크스페이스 상태 저장소·정규화 테스트 심에서 위 동작을 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 통과합니다.
