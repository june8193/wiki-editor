# 01 — 개별 변경 파일 즉시 롤백 및 문서 버퍼·Diff 탭 동기화

**Spec:** [spec.md](../spec.md)

**What to build:** Git 서비스의 경로별 롤백(`git:discard` — 추적 `M`·`D` 파일의 Index 기준 복원, 병합 충돌 `U` 파일의 현재 브랜치 `HEAD`/`--ours` 기준 강제 복원, 미추적 `?` 파일의 OS 휴지통 이동)과 Preload 브리지를 연결하고, **Changes 섹션**의 `변경 사항` 파일 행에 상시 `↶` 버튼을 배치합니다. 개별 `↶` 클릭 시 별도 롤백 모달 없이 즉시 롤백하되 대상 파일에 열린 미저장(`●`) **문서 버퍼**가 있을 때만 `'저장 후 진행'` / `'저장 없이 진행'` 확인을 거치며, 완료 후 **메인 창**·**보조 창**의 대상 **문서 버퍼** 강제 디스크 동기화(삭제 시 탭 닫기), **폴더 트리** 갱신, 열린 `unstaged` **Diff 탭** 자동 닫기까지 엔드투엔드로 완결합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 공유 `WikiGitApi.discard` 타입 계약, `git:discard` IPC 채널(활성 워크스페이스 일치 검증 포함), Preload `window.wikiApi.git.discard` 브리지, Electron 메인 프로세스의 `shell.trashItem` 주입 연결이 구현되고 경계 단위 테스트가 통과합니다.
- [ ] Git 서비스의 `discard(workspacePath, paths)`가 저장소 외부 경로·심볼릭 링크 탈출·`.git` 세그먼트를 차단하고 최신 상태를 기준으로: (a) 추적 `M`·`D` 파일은 동일 경로의 Staged 변경을 보존한 채 Index 기준으로 워킹 트리를 복원(첫 커밋 전 `isUnborn` 저장소 포함)하며, (b) 병합 충돌 `U` 파일(`UU`, `AA`, `DD`, `DU`, `UD`, `AU`, `UA`)은 현재 브랜치(`HEAD`/`--ours`) 기준으로 Index와 워킹 트리를 강제 복원·정리하여 충돌 상태를 해소하고, (c) 미추적 `?` 파일은 주입된 `trashItem`으로 삭제(미주입 시 파일시스템 삭제 폴백, 이미 없는 경로는 멱등 처리)함을 격리된 임시 Git 저장소 통합 테스트로 검증합니다.
- [ ] **Changes 섹션**의 `변경 사항` 각 파일 행에만 기존 `+` 버튼 왼쪽에 상시 `↶` 버튼(`aria-label`: `"${file.path} 변경 사항 롤백"`, `title`: `"변경 사항 롤백"`, 작업 진행 중 비활성화)이 렌더링되며, `스테이지됨` 섹션에는 롤백 버튼이 표시되지 않고 `↶` 클릭 시 **Diff 탭**이 열리지 않습니다.
- [ ] 깨끗한(`isDirty === false`) 파일이나 열려 있지 않은 파일에서 `↶` 클릭 시 별도 **확인 다이얼로그** 없이 즉시 롤백되며, 롤백 대상 파일에 미저장(`●`) **문서 버퍼**가 열려 있을 때만 `'저장 후 진행'` / `'저장 없이 진행'` **확인 다이얼로그**가 표시됩니다(롤백 대상이 아닌 다른 문서의 미저장 버퍼는 프롬프트를 유발하거나 변경되지 않음).
- [ ] 롤백 완료 후(`'저장 없이 진행'` 선택 포함) 대상 경로의 열린 **문서 버퍼**는 자동 저장 타이머 재실행이나 외부 변경 충돌 경고 없이 복원된 디스크 내용(`isDirty: false`)으로 **메인 창**과 모든 **보조 창**에 즉시 반영되며, 디스크에서 제거된 파일(미추적 `?` 휴지통 이동 또는 `HEAD`에 없던 `U` 파일)의 탭은 추가 닫기 확인 없이 **메인 창**·**보조 창**에서 자동으로 닫힙니다.
- [ ] 롤백된 파일 경로에 대해 **주 편집기 영역** 또는 **보조 편집기 영역**에 열려 있던 `unstaged` **Diff 탭**은 자동으로 닫히고, `staged` 및 `commit` **Diff 탭**은 그대로 유지되며, **폴더 트리**와 **액티비티 바** 변경 배지가 최신 상태로 갱신됩니다.
- [ ] `<App />` 멀티 윈도우 통합 테스트가 개별 `↶` 즉시 롤백(`M`, `D`, `U`, `?`), 미저장 대상 버퍼 확인(`'저장 후 진행'` / `'저장 없이 진행'` / `'취소'`) 및 비대상 미저장 버퍼 무간섭, **보조 창** 공유 버퍼 갱신·삭제 탭 닫기, 열린 `unstaged` **Diff 탭** 자동 닫기를 검증하며, `npm run typecheck`, `npm test`, `npm run build`가 모두 통과합니다.
