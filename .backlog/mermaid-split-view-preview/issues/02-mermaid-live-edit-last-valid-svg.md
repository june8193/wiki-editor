# 02 — Mermaid 실시간 편집 중 직전 정상 다이어그램 유지 및 인라인 오류 배너 표시

**Spec:** [spec.md](../spec.md)

**What to build:** **Mermaid 다이어그램 블록**을 실시간으로 수정하는 도중 일시적인 문법 오류가 발생하더라도, 해당 블록 인스턴스에 직전 정상 렌더링된 SVG가 존재하면 다이어그램을 숨기지 않고 화면에 그대로 유지하면서 간결한 인라인 문법 오류 배너만 함께 표시하고, 문법이 다시 유효해지면 새 SVG로 교체하며 오류 배너를 제거합니다(최초 마운트부터 문법 오류라 정상 SVG가 없는 경우에는 기존 오류 박스와 원문 코드를 그대로 표시).

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 한 번 이상 정상 렌더링된 **Mermaid 다이어그램 블록**에서 후속 코드 수정으로 문법 오류가 발생하면, 직전 정상 SVG(`data-testid="mermaid-svg"`)가 언마운트되지 않고 화면에 유지됩니다.
- [ ] 직전 정상 SVG가 유지되는 동안 블록 내부에 간결한 인라인 문법 오류 배너(`role="alert"`, 오류 메시지 포함)가 함께 표시되며, 이 상태에서는 중복 원문 코드 `<pre>` 블록을 출력하지 않아 불필요한 높이 급변을 유발하지 않습니다.
- [ ] 문법 오류 상태에서 코드를 다시 올바른 문법으로 수정하면 디바운스 후 새 SVG로 교체되고 인라인 문법 오류 배너가 제거됩니다.
- [ ] 최초 마운트 시점부터 문법이 잘못되어 직전 정상 SVG가 전혀 없는 경우에는 기존과 동일하게 오류 박스(제목, 오류 메시지, 원문 코드 포함)만 표시하고 정상 코드로 수정 시 복구됩니다.
- [ ] 라이트/다크 테마 전환 시 유지 중인 다이어그램 SVG도 변경된 테마에 맞게 재렌더링·동기화되며, 모든 단위·컴포넌트 테스트가 통과합니다.
